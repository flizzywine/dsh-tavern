# 结算停止条件一句话：Flash 对照

2026-09-12。结论：**本次没有观察到稳定收益，不建议据此加入正式提示词。** 总 token 下降由单个较长对照样本主导，其余 5/6 配对加句后推理和总输出都增加。

## 条件

沿用 `settlement-estimate-rule-ab.md` 的用户公开阿芙拉 demo、六字段快照（信任初值 18）、稍松戒备/跨日帮忙两个固定正文。每场景各重复三次、交替组别顺序，共 12 次；所有运行从相同初值开始。

两组都包含已采用的“数值不确定时，合理即可，不要求必须精确。”和同次提交协议。实验组末尾仅增加：

> 结算结果符合规则且无明显矛盾时，直接提交，不再反复比较其他可能。

官方 DeepSeek V4 Flash、High reasoning、temperature 0.1、max_tokens 20000。正式结算模块负责投影、工具处理和回执审计，实验 adapter 执行字段更新并隔离落盘；不代表完整浏览器 MVU/DSH provider 链路。原卡只规定信任为 0～100 整数，无唯一正确增量；原卡文件未修改。

## 结果

| 每组六次合计 | 不加停止句 | 加停止句 |
| --- | ---: | ---: |
| 模型请求 | 6 | 6 |
| 输入 token（含缓存） | 9651 | 9759 |
| 推理 token | 2037 | 1732 |
| 总输出 token（含推理） | 3373 | 3099 |
| HTTP 请求耗时合计 | 24.211 秒 | 20.043 秒 |

总推理减少 15.0%，总输出减少 8.1%。推理已包含在总输出中，不可相加；时间受网络/缓存影响，不代表稳定性能。

| 场景 / 重复 | 不加输出 | 加句输出 | 不加推理 | 加句推理 | 不加信任 | 加句信任 |

| 稍松戒备 / 1 | 377 | 426 | 159 | 224 | 28 | 25 |
| 跨日帮忙 / 1 | 1140 | 405 | 859 | 204 | 30 | 30 |
| 稍松戒备 / 2 | 397 | 543 | 160 | 297 | 23 | 24 |

第一组跨日对照确实围绕时间措辞反复选择；实验组更直接提交。但另外五组没有节省。输出中位数为 459 → 504（增加 9.8%），推理中位数 232 → 260.5（增加 12.3%）。作为敏感性检查，排除第一组跨日配对后，其余五组总推理反而增加 29.7%；原始总计和全体样本均保留，未挑选有利结果。

小样本不足以证明该句必然增加 token，也不足以证明它系统性降低成本。没有复现上万 token 循环；当前不建议仅凭这次结果继续叠加这句提示。
