# 多世界书绑定实验

分支：`experiment/multi-worldbook-merge`；基线：`7b879b8`。

## 已确认的行为

- 人物卡可以绑定多本书，书可以被多张卡复用。内置书仍默认绑定；添加不会替换已有绑定。
- 人物卡详情支持添加、上下移动、打开和逐本解绑；世界书库也支持绑定多张卡。
- 第一本文档提供主书名称和书级设置。开局生成一份合并的本局世界书；条目不去重，主书编号保留，附加书只有撞号才重新分配。同优先级的召回保留各书显示顺序，主书排在附加书前。
- 不增加设定、静态初值或动态 EJS 初值的冲突检查。继续使用原有初始化流程，不承诺冲突内容如何协调。界面提示：**多本世界书可能相互冲突，引发异常**。
- 脚本仍只看到一份合并书，通过主书名称或 current 访问。写死附加书名称或冲突编号的脚本可能不兼容；这是本次接受的限制。
- 新开局快照及其脚本修改属于本局，不回写源书。已有快照不随绑定变化。没有快照的旧局在使用多书绑定时，第一次脚本写入会保存本局副本；旧局的单书行为未扩大改造。
- 导出人物卡包含合并后的全部条目。资源重命名、删除会更新所有绑定引用。

## 实现

`.worldbook-bindings.json` 新绑定使用 `{version:2,sources:[...]}`，列表保存顺序；旧的默认、自带书、独立书和未绑定格式继续可读。World Book Library 统一处理追加、排序、解绑和合并；游玩接口继续使用原有单书快照。
