# DSH 0.2.1 统一存档升级验证

日期：2026-10-17。目标宿主：DSH 0.2.1-rc.2；开发分支：`0.2.1版本`。

## 升级流程

替换旧 `legacy-session-migration.js` 和 `conversation-migration.js` 两套入口，统一为 `save-upgrade.js`。启动阶段必须在宿主打开会话句柄之前准备新版日志；界面的「升级存档」核对当前游戏所有关联会话后完成剧情存储转换。已有原生存储但会话尚未升级的游戏不会被误报为完成。任务可重试，运行中重复点击不会重复转换。

- 会话日志：使用宿主历史格式链与完整父子会话信息，识别旧开场白和编辑事件边界，严格恢复后再发布 v4。
- 历史引用：保存旧事件序号映射和剧情轮号，覆盖编辑记录、回退锚点、分支、后台同步边界和撤销回退，不直接改写旧剧情 revision。
- 剧情存储：沿用经过验证的分页转换底层，在共享锁内检查空闲、源版本及完整读回；保留旧文件和旧 revision。
- 发布：校验源文件与会话目录未变化，临时文件同步落盘并读回，再用不覆盖目标的原子链接发布新版。异常日志保留原文件并明确报告失败。

压缩日志逐帧解析，支持跨帧 JSON 行及 UTF-8 字符。没有修改用户已安装的 DSH，也没有把旧文件作为新版进度的回滚副本；升级后的进度只写新版。
