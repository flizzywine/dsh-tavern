# iframe 尺寸契约验证（2026-09-27）

实现使用显式配置：未声明的旧卡保留自动测高、缓存初始高度和可信卡直接改外框高度的兼容路径。新声明支持自然内容、应用视口、固定高度/比例；推荐长内容撑高外框，只有明确限高才内部滚动。卡片默认值和稳定面板覆盖通过原有卡片资源保存/应用。

## 已验证

- `tests/frame-sizing.test.mjs`：真实 Chromium，生产文档构造器和生命周期，opaque-origin sandbox。验证 700px 容器视口、百分比高度链、内部应用滚动、窗口缩放到 450px、moveBefore 移到 350px 容器后输入保留；错误来源/token 的高度消息不改变外框。
- 同一浏览器测试验证比例模式随宽度从 300px 高变为 160px；自然内容从 2500px 异步增长到 4000px，iframe 同步撑高且不启用限高滚动；主动设置 240px 上限后内容可滚动，内容缩短到 100px 时外框收缩并退出限高滚动，没有持续高度反馈。
- 卡片导入/导出保留配置及无关扩展；开场预览携带配置；稳定面板覆盖优先于卡片默认，模板明确声明优先于覆盖。修改其他面板配置不重建当前 iframe。
