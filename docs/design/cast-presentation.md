# 角色演出：对话头像、立绘差分、配音

整体分层见 [从酒馆到 Galgame：四层演出](tavern-to-galgame.md)。

借鉴 [DSH Tavern Galgame](https://github.com/jerryzmtz/dsh-tavern-galgame) 的效果，在 Tavern 本体实现「谁在说话、什么表情、什么声音」这层多模态基础能力，再通过插件接口开放给插件（例如 Galgame 的舞台）。

## 原则

- **普通 SillyTavern 卡直接能用**：不改卡、不改世界书、不要求正文模型改写格式。
- **默认关闭，一个全局开关**：打开后对所有游玩对话下一轮生效。
- **素材沿用 ST 习惯**：主角用卡的 PNG 头像；立绘按 ST 表情包约定（每个角色一个文件夹，文件名就是情绪）。
- **不做**：Live2D、Spine、口型、导演舞台、素材包体系。

## 地基：台词标注

每句台词的说话人和表情，由**后台结算顺带标注**，不让正文模型写格式。

- 结算任务里附一段「本轮台词」：从这一轮正文里按顺序取出引号台词（`“”`、`「」`、`『』`、`""` 等同行成对的引号），编号列出。
- 模型调用 `cast_submit({ lines: [{ n, speaker, emotion }] })`，`n` 是编号，不需要抄原文；`emotion` 取 ST 表情扩展的 28 个情绪名之一（`joy`、`anger`、`neutral`…），方便直接对应 ST 立绘包的文件名。
- 结算工具列表固定在缓存前缀里；是否要标注写在每轮任务文字里，开关不影响缓存。
- 标注结果按「轮次 + 正文版本」保存（与插件的每轮数据同一套存储）：回退、重新生成、编辑后旧标注自然失效，不需要同步；导出、分叉随存档走。
- 只关了姿势、变量结算时，打开台词标注也会运行后台结算。

## 第一步：对话头像

- 一段文字里含有已标注的台词时，这段显示成「头像 + 名字 + 情绪标签 + 原文」的气泡行；旁白段落照常显示。只处理 Markdown 正文，卡片自己的 HTML 界面不动。
- 头像：说话人是卡的角色名时用卡的 PNG 头像；其余人物显示首字圆形头像（颜色按名字固定）。
- 结算完成前正文照常显示，标注到了再换成气泡行。

## 三层：故事、演出数据、呈现

- **故事**（正文、变量、回退、存档）通用，不因演出改变。
- **演出数据**（台词标注、角色素材）也是通用的，只是附在故事上的一份标注，可选、默认关。
- **呈现**才特化：聊天视图照旧；舞台是同一局故事的另一种看法，只读另外两层，不碰游玩流程。缺什么退一步：没有立绘用头像，没有头像用首字，没有标注就按旁白显示。

## 第二步：舞台与角色素材

- **入口**：开了「对话头像」后，顶栏多一个「舞台」按钮，打开右侧栏的「舞台」页。不放在人物卡自己的状态栏里，那是卡作者的界面，每张卡都不一样。
- **小舞台**：显示最新一轮，按台词逐句翻；当前说话人亮、其他人变暗，表情随台词切换。背景暂用人物卡头像虚化。
- **全屏舞台**：同一画面铺满页面，点击或方向键翻页、自动播放、Esc 退出；读到最后一句可以直接在舞台里输入下一轮行动。
- **角色素材**（每张卡一份）：人物名可加别名，头像和 28 个情绪的立绘。导入 ST 立绘包 ZIP（单人 `joy.png`…归给主角；多人 `角色名/joy.png`…按文件夹名），也可逐张上传。文件按内容寻址存放，链接可以永久缓存。
- **动画只用 CSS**：入场、切换淡入、呼吸、说话时轻微上移；系统开了「减少动态效果」时全部关闭。

## 第三步：配音

- **一个全局开关**：「设置 → DSH Tavern → 显示与交互 → 配音」，默认关。打开前要选好渠道并填齐设置。
- **渠道**：浏览器朗读（系统语音，零配置）、OpenAI 兼容 `/audio/speech`（OpenAI、硅基流动 CosyVoice、中转）、GPT-SoVITS（api_v2）、MiniMax T2A v2；插件可用 `speechProvider` 再加。各渠道分别保存设置，Key 存在 DSH 凭据库，改地址必须重填 Key。
- **声音**：每个渠道有默认声音和旁白声音（旁白留空则不念）；每个人物在舞台页「角色素材」里按渠道单独选声音，跟着人物卡走，换渠道不丢。
- **情绪**：gpt-4o 系列把标注的情绪写成语气要求；MiniMax 映射到它的 7 种情绪；插件渠道拿到情绪名自己处理。
- **合成与缓存**：宿主侧合成，按「渠道 + 非密钥设置 + 声音 + 情绪 + 文字」内容寻址存进 `speech-cache/`，同一句只付费一次；浏览器朗读在浏览器里合成，不经宿主。
- **在哪里听**：带头像的台词行有朗读按钮（只念引号里的话）；舞台和全屏舞台有「朗读」开关（每台浏览器记住），翻到哪句念哪句，自动播放时念完再翻页。
- **还没做**：缓存不会自动清理；正文写完自动念整轮。

## 插件接口

已开放（见[插件接口](../plugin-api.md)「演出」与 `registerStageView`）：

- 宿主侧：`getCast({ gameId, turn })` 读某一轮当前版本的台词标注；`onCastAnnotated` 标注保存时通知；`getCastAssets({ gameId })` 读角色素材；`speechProvider` 加配音渠道；`synthesizeSpeech` 按人物声音合成一句。
- 浏览器侧：`getStage`、`watchStage` 读舞台数据；`registerStageView` 换舞台画面，Tavern 保留阅读流程，插件失败时退回内置画面；`speak`、`stopSpeech` 朗读。
