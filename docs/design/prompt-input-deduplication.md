# 新增输入去重

只减少程序即将追加的重复输入，不清理、重排或改写已存在的历史消息。旧轮程序提示、状态及工具调用保持原样，避免逐轮改变历史前缀。

## 正文源文本

展示规则隐藏正文时仍可补入源文本。Context Planner 只解析源文本中的 user/char 身份宏，不重放有副作用的变量宏。Session Adapter 在追加新 Frame 时与实际请求历史最后一条 assistant 文本比较；忽略已知状态栏占位符和首尾空白后完全相同，才省去该项新增贡献。

不以 UI 可见文本或存档快照代替实际请求历史判断。压缩后原文已不在请求中、正文确有差异、未知宏、非纯文本 assistant 等情况继续保留补文。比较不删除 XML、HTML 或任意剧情片段。完整 Frame 与历史消息不变，追加消息的 sections 只包含实际发送的贡献。

## 后台协议

完整本轮任务协议保留在后台系统提示。新增任务消息末尾只提示“按系统提示中的本轮任务规则执行”，不再复述全文。候选与结算均沿用此契约；历史旧协议不清理。工具提交、失败修正、次数限制与成功后的姿势输出均保留。

## 卡片规则不做启发式删减

卡片可能把更新条件、路径约束等放进 XML 教程和示例，无法通用区分“纯格式”和业务规则。因此完整规则原样发送，不针对某张卡或某种模板删减。MVU 工具模式仅在系统协议中明确：通过工具提交，不在回复中输出 XML 变量协议；仍遵守人物卡变量含义、更新条件和校验规则。兼容模式、原卡和世界书不改。

## 验证

- `tests/prompt-redundancy.test.mjs`：真实历史去重、缺失正文兜底、历史消息保留、完整卡片规则保留。
- `tests/background-agent-runner.test.mjs`：实际 Runner 的系统协议与任务消息只出现一份完整任务说明，候选指令、状态、恢复行为不变。
- `node tests/fixtures/foreground-source-size-audit.mjs /path/to/request.json [userName]`：只读回放已捕获的正文请求，断言历史与其他贡献不变；不调用模型。报告字符数，不将其当作 token 节省、缓存命中或速度测量。
