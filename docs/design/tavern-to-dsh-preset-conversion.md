# 外部预设到兼容请求投影协议（草案 0.5）

> 外部预设只参与实验性兼容模式。普通 DSH 游玩和卡片 Agent 不运行外部预设。

## 状态

预设库完整保存用户导入的 `prompts`、`prompt_order`、采样参数和未知扩展。同一时间最多选择一份预设；请求边界直接读取来源文件，不创建条目选择副本。

卡片模式可以引用预设供 Agent 阅读和编辑。引用不等于选择，也不会让当前 Agent 运行预设。用户确认修改并保存后，如果该文件正是兼容模式当前预设，下一轮兼容请求会读取新内容。

## 请求规则

- `prompt_order` 决定参与请求的条目及相对顺序；
- 条目和原生 `extensions.regex_scripts` 沿用来源文件的启用状态；
- `chatHistory`、人物卡、玩家信息、对话示例和世界书 marker 在请求时动态展开；
- 普通提示词正文、role、覆盖规则和相对顺序原样保留；
- 深度注入按 SillyTavern 语义插入历史；
- 最终消息执行 `strict_tools` 角色归一化；
- 正则不进入提示词正文，也不覆盖权威模型原文。

## 选择与文件生命周期

- “使用预设”只保存当前预设路径；
- 删除当前预设时清空当前路径；
- 重命名和删除通过资源图同步全局选择及卡片对话引用；
- 编辑器只修改工作版，导入时保留的原版不变；
- 升级可以迁移旧版当前选择，但不会删除旧配置或用户本地预设。

## 诊断

每次真实模型请求在网络调用前保存完整记录，包括最终有序 messages、预设路径、启用条目、正则、模型、轮次和步骤。诊断记录不进入后续模型上下文。
