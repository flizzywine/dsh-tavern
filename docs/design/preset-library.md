# 预设库

> 核心决定：产品只提供一个“预设库（实验性）”。用户自行导入外部预设；兼容模式选择整份预设运行，卡片模式引用预设供 Agent 阅读和编辑。

## 两种用途

### 兼容模式运行

- 同一时间最多选择一份外部预设；
- 按来源预设的 `prompt_order`、提示词启用状态和原生正则启用状态构造请求；
- 不再提供逐条抽取、条目方案或隐藏运行副本；
- 每轮请求重新读取源文件，编辑后下一轮立即生效；
- 可以停用当前预设。

### 卡片 Agent 编辑

- “编辑预设”新建卡片对话，自动挂载目标预设并追加“修改预设”起始任务；
- 卡片对话中可以继续通过“在对话中引用”挂载其他预设；
- 引用只授予 Agent 读取和编辑权限，不会选择或运行预设；
- Agent 按 JSON Pointer 渐进读取，用户明确确认后才提交最小 `set` 或 `delete` 修改；
- 保存后重新校验 JSON，并保留未知字段。

## 用户界面

右侧面板只注册“预设库（实验性）”。主操作是“导入外部预设”。每份预设提供：

- `使用预设` / `使用中`；
- `编辑预设`；
- 卡片对话中的 `在对话中引用`；
- `导出`、`重命名`、`删除`。

顶部显示当前预设，并在已选择时提供“停用预设”。界面不出现“选择条目”“启用所选条目”或独立方案库。

## 运行边界

- 外部预设只在兼容模式中参与模型请求；
- 普通游玩模式和卡片 Agent 不注入外部预设；
- 卡片 Agent 编辑与兼容模式选择相互独立；
- 删除或重命名预设通过资源图同步更新全局选择和已有卡片对话引用；
- 发布包不自带、也不自动安装第三方外部预设；
- 升级只迁移旧版当前选择，不删除用户本地预设或旧配置文件。

## 请求与日志

兼容模式在请求边界读取当前预设并按 SillyTavern 语义编译消息。正则只影响请求/展示投影，权威模型原文保持不变。每次真实模型请求仍保存完整诊断日志，包括最终消息顺序、预设来源、正则、模型响应和错误。

## 验收

- 用户可以导入并选择一份完整预设；
- 原预设中关闭的提示词和正则保持关闭；
- 修改当前预设后，下一轮兼容请求读取新内容；
- DSH 游玩与卡片 Agent 不注入当前预设；
- “编辑预设”能够新建带目标引用和起始任务的卡片对话；
- 卡片对话可以追加引用预设；
- 产品界面不再出现条目选择或独立方案功能；
- 用户本地预设和旧配置数据不被删除。
