# 变量工具纠错

`mvu_submit_update` 在同一后台 Agent 回合中执行官方 MVU、核验并保存后才返回，不再提前确认“已收到”。Agent 看到失败结果后可以修正参数重交，无须用户点击重试；不保证任意人物卡都能自动修好。

## 契约

- 默认最多三次提交（首次 + 两次修正），格式错误也计数。
- `ok` 表示实际成功；`retryable` 决定是否允许继续，`failures` 和 `runtimeDiagnostics` 包含错误细节。
- `rolledBack` 表示本批变量草稿未提交。失败后返回当前变量，Agent 修正完整 operations 后重交，不能提交空数组冒充成功。
- 首次确实无变化仍允许 `operations: []`。成功后工具撤下；已排队的重复调用返回既有结果，不再次执行。
- 并行工具调用串行处理，避免两批 delta 同时生效。
- 固定版官方 MVU 的 `MESSAGE_RECEIVED` 有 3000ms 节流；失败后的执行重试至少间隔 3100ms，由程序等待，不消耗额外模型调用。首次提交不等待。

## 保存边界

Host Adapter 仍负责隔离变量/消息草稿。结算模块提供保存前核验回调，检查操作的实际差异。部分操作失败时整批变量不落盘，不把成功项重复累加。最终回执只包含实际保存的差异，不展示废弃草稿的变化。

沿用既有差异核验语义，不重新实现人物卡 Schema，也不绕过变量守卫。普通脚本警告不单独判整批失败；未生效项和显式执行异常返回 Agent。缺少确切原因时仍明确说“未观察到对应变量变化”。

超时、浏览器未就绪、目标过期、磁盘保存结果不确定时停止自动重试。世界书写入不属于变量草稿：本次执行若触及世界书写入，失败后停止自动重放，不能宣称它已回滚。任意人物卡脚本自行发起的外部请求不具备事务保证。

成功提交后即使模型断流，也保留已保存的变量回执，不重开整轮模型任务。运行次数上限只约束变量工具，不新增循环模型请求。每次尝试有独立诊断编号，最终 `finished` 记录关联后台 Session。

## 模型输入去重

程序给模型看的变量投影与运行时完整数据分开：标准 MVU 数据（存在对象 `stat_data`）在模型输入中去掉根级 `display_data`、`delta_data` 展示/差异副本及重复的 `schema`；完整结构只在“变量结构”中发送一次。状态与结构采用紧凑 JSON，不改变字符串内的换行、空格或字段含义。未知根字段、`stat_data` 内的同名字段，以及非 MVU 包装的扁平变量保持原样。

参数格式错误和执行校验失败的工具反馈使用同一精简投影。初始结构已在上下文中，不再次重复；运行时返回了不同的有效结构时，反馈携带新的 `variableSchema` 供 Agent 修正。卡片规则、后台策略、提交次数及错误细节不变。

仅模型输入做投影；Frame、官方 MVU 校验、存档、返回的运行时变量和诊断回执仍保留完整数据。不是删除或缩减人物卡变量。

2026-08-31 对本地《离火仙魔录》第二轮已捕获后台请求作只读回放，其他消息、正文、规则和协议不变：消息文本由 72,625 字符降到 27,775 字符，减少 44,850 字符（61.8%）。这是字符数而非供应商 token 数，也没有重新请求模型测量延迟，不能据此宣称等比例加速。复核命令：`node tests/fixtures/mvu-prompt-size-audit.mjs /path/to/request.json`；原始人物卡和请求数据不随仓库提交。

## 验证

- `tests/mvu-tool-retry.test.mjs`：实际 Host Adapter 草稿、部分失败回滚、修正成功、次数上限、参数纠错、并行重复调用、成功后模型失败、过期和不确定结果。
- `tests/mvu-prompt-projection.test.mjs`：首次输入和重试反馈去重、紧凑 JSON 可逆、规则和原始状态不变、扁平/自定义字段保留及新结构回传。
- `tests/background-agent-runner.test.mjs`：失败后工具仍可用，成功或达到上限后撤下，清理不重复。
- `node tests/fixtures/mvu-tool-retry-browser-smoke.mjs`：独立浏览器夹具，官方 MVU + 真实浏览器桥接与 Host Adapter；模型响应由脚本提供，不用付费模型或用户存档。可用 `MVU_SMOKE_ASSET_CACHE` 指定已有静态依赖缓存目录。

浏览器夹具仅模拟 Agent 决策及 MVU 全局设置保存，不模拟变量执行。实测首次位置校验失败、第二次修正成功：`attempts=2`、`writes=1`、`hp=9`（初值 10）。这验证反馈和持久化链路，不代表已经验证所有模型的纠错能力。
