# 酒馆超集兼容层完成度审计

> 审计日期：2026-08-28
>
> 分支：`MVU`
>
> 结论：纯前台 MVU 主链路已可用，超集兼容总方案仍在实施中。

## 当前结论

《灯火阑珊》已在 dsh-tavern 中跑通人物卡初始化、前台模型正文与 MVU 协议输出、Host 变量结算、消息/Swipe 快照、Helper 脚本、动态世界书、变量守卫/Zod 事件和状态栏显示。开场初始化现在会在五个 Helper iframe 全部就绪后，按官方顺序重新结算 15 个 Swipe、105 个事件，再原子替换临时快照；随后刷新生命周期上下文并广播 `CHAT_CHANGED`，避免动态世界书派生状态被覆盖或被版本栅栏拒绝。

固定的本机 SillyTavern 开场记录已经用于第一次变量树差分：选择第 3 个开场、玩家名“王辰”后，DSH 最终变量树与 SillyTavern 基线仅有两个 `Date.now()` 任务创建时间不同，排除这两个易变字段后差异为 0。该证据尚未整理成可移植的仓库夹具，也不覆盖固定模型输出和最终请求，因此总方案仍不能判定完成。

这只证明第二阶段主链路与第三阶段的部分宿主能力可用，不证明已与固定版本 SillyTavern 全量等价。

## 下一个独立实施点
