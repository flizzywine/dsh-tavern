# ComfyUI 场景生图

面向自托管 ComfyUI，不是 Comfy Cloud 接口。Tavern 不安装 ComfyUI、模型或节点，也不修改其全局配置。下述流程已通过本地协议夹具和真实 DSH 子任务/附件测试，尚未连接实际 GPU 实例验收。

## 普通用户

在场景生图设置选择 ComfyUI，填写维护者给的服务根地址，点击「导入工作流」选择 JSON 文件。保存后再手动启用，以后只点输入框上方的「生图」。只导入可信维护者准备并验证过的**单张图片**工作流。

默认无需鉴权；有反向代理时可选用户名密码或 Bearer Token。凭据单独保存，不要写进工作流文件。“localhost”指运行 Tavern 的服务器，不是手机。服务必须能从 Tavern 服务器访问。

导入、保存和启用只检查文件结构，不会偷偷试画。保存成功不代表远端节点、模型、认证、显存或实际出图已经验证。

## 维护者准备

1. 先在目标 ComfyUI 上验证工作流确实能输出一张最终图片，所有模型和节点均已存在。
2. 导出 **API 格式**。画布格式的 `nodes` / `links` 文件不能直接提交。
3. 简单的单 KSampler / KSamplerAdvanced → VAEDecode → SaveImage 路径，正向提示词直接来自 CLIPTextEncode 时可自动识别。种子既可直接填写在采样器的 `seed` / `noise_seed`，也可连接 `Seed (rgthree)` 的第一个输出：保留连接，将新随机种子写入该种子节点的 `inputs.seed`。源字段须为直接填写的安全整数；其他自定义种子节点、计算链或输出位置仍需明确映射。负面分支、模型名、采样参数和尺寸保留；正向提示词被当前画面替换，种子换新，`batch_size` 固定为 1。
4. 复杂工作流提供下述映射封装。不用让普通用户编辑节点或 JSON；维护者一次准备好文件，用户只负责导入。

映射文件格式（字段示意，`prompt` 需放完整 API 节点字典）：

```json
{
  "format": "dsh-tavern-comfy-v1",
  "name": "服务器单图工作流",
  "prompt": {},
  "outputNode": "7",
  "bindings": {
    "positive": [{ "node": "3", "input": "text" }],
    "seed": [{ "node": "5", "input": "seed" }],
    "batch": [{ "node": "2", "input": "batch_size" }]
  }
}
```

- `positive`：必须至少一个，指向字符串输入；同一画面需要多个文本编码器时可列多个。不会用名称搜索或全文替换误改负面词。
- `seed`：可为空；指向整数输入，程序填同一个新随机种子。没有映射时不保证重画会产生不同结果。
- `batch`：可为空；将维护者明确指认的数量字段设为 1。所有名为 `batch_size` 的直接数值输入也设为 1；若由其他节点动态控制则拒绝，维护者须改为单张模板。其他自定义节点的批量或远程付费行为无法仅靠字段名判断，必须提前验证。
- `outputNode`：最终图片输出节点，必须返回恰好一个 `images` 描述符。只提交该节点的依赖图，不执行无关输出分支，不把预览节点的结果冒充最终图。
- 同一输入不能映射到两种用途；映射必须指向输出依赖图中的已存在节点。文件最多 500 KB / 200 节点，拒绝循环、断链、危险字段及显式凭据字段。节点设置应由维护者审查，不把“结构检查通过”当安全沙箱或服务器可用性证明。

## 任务与恢复

每次请求先保存任务 UUID，再提交一次 `/prompt`；该 UUID 用于关联，不作为供应商幂等键。随后只读 `/history/{id}`，取指定输出并从同一服务的 `/view` 下载；鉴权不发送到外部图片地址，不跟随重定向。

收到图片前断线或 Tavern 重启，重试原操作优先查询同一个任务、重新下载并保存，不重复提交工作流。未收到提交响应时查原 UUID 与队列中的 client ID；都找不到也不能证明未生成，保留“结果未确认”，不会自动重发。旧版服务器不保留客户端 UUID 时，若响应丢失且任务已退出队列，可能无法恢复，需维护者查服务器。

查询远端原任务时须保持原渠道地址、工作流与风格配置；避免把原任务编号拿到新服务器查询。执行明确失败或请求明确被拒绝后，用户主动重试才可创建新任务；运行中的网络重试不自动重新提交。已成功图片的「重画」仍是一次新的图片请求。

收到图片后会先在 Tavern 本地持久暂存。附件保存失败显示「重试保存」，直接恢复这份图片，不再访问 ComfyUI；允许在关闭生图、换配置和重启后恢复。该恢复以本地暂存完整为前提，磁盘故障时的限制见[通用生图说明](scene-images.md)。

当前 ComfyUI 的查询恢复、通用本地暂存和「取消生图」已接入。取消中止本次本地等待，不保证服务端停止；之后明确重试仍查询原任务。跨进程完整任务生命周期和历史回收仍在开发中。本版不调用全局 `/interrupt`，不清空队列、不删除共享历史。若尚未本地暂存，服务端历史被清空、服务重启或图片被维护者删除后，原任务不一定还能恢复。
