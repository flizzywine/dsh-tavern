# 场景生图（开发中）

## 可选：复用 dsh-image-gen（最小接入）

在同一个 DSH Profile 安装支持 Studio 接口的 `dsh-image-gen`（本次按 0.3.0 源码接入），在「设置 → 插件 → Image generation」配置云端渠道、模型和 Key。然后打开 Tavern 的「开启场景生图」开关，选择「dsh-image-gen（已安装插件）」→「刷新插件配置」→「保存并启用」。Tavern 不安装或自动切换插件，不复制其 Key，也不改已有自建渠道配置。

此模式读取插件工作台返回的当前云端渠道及默认比例/清晰度；与插件通用设置中的 ComfyUI 选择不是同一个概念，请以 Tavern 显示的渠道和模型为准。当前接入范围为 Google、OpenAI/兼容渠道、Seedream、DashScope 的文生图，不含参考图和 ComfyUI。没有专门的 Grok 适配，不能据此保证 Grok 在兼容渠道中可用。

Tavern 仍负责画面方案、目标轮次绑定和图片展示，图片请求与附件存储交给插件；成功后复用插件附件，不改正文或 MVU。配置只读取本机当前 DSH Host 的固定 Studio 路径，不把 Key 发给该接口。刷新配置不生图，也不代表 Key 已验证。插件缺失、未配置或接口不兼容时禁止启用；开始生成后发现模型/尺寸配置变化则停止，不自动改用其他渠道。

上游 Studio 提示词上限为 2000 字符，超过时明确报错，不截断。不自动重试收费请求；超时或响应丢失仍可能已经生成/计费。插件自己的额外工作区保存遵循插件设置，不由 Tavern 控制。此次验证使用本地模拟 Studio 接口和附件，尚未完成真实供应商出图验收。

## 内置渠道

在「设置 → DSH Tavern → 场景生图」选择一个渠道，按需填写地址与凭据。现已实现 OpenAI／Images 兼容中转、Gemini 原生、Banana／Gemini 聊天生图中转、Grok Images、Seedream／方舟、百炼 Qwen-Image、NovelAI、SD WebUI／Forge、ComfyUI 九种单图协议；均已通过本地协议与 DSH 主流程测试，尚未做真实供应商或 GPU 后端出图验收。九种协议接入不代表完整产品规格已交付，参考图、通用任务生命周期等仍在开发中。

打开顶部滑动开关后展开配置，顺序是「提供商 → API 根地址与 API Key → 测试连接 → 生图模型 → 保存并启用」。官方地址自动填入，风格、尺寸等收在「绘图选项」中。账号可用模型、地域端点可能不同，必要时按供应商配置修改。聊天生图中转需填写自己的地址和模型，不是任意文字聊天接口。各渠道分别保留配置和密钥，切换选项只是预览；点击「保存并启用」后才使用新渠道，不会自动请求图片。选择其他渠道会放弃表单中尚未保存的改动。

「测试连接」最多等待 5 秒，只向填写的根地址发起 HEAD 请求，不跟随重定向、不生成图片、不保存配置。HTTP 401/403 显示鉴权被拒绝；404/405、限流或服务端错误表示网络可达但服务没有返回成功状态；网络错误或超时则显示连接失败。成功仅说明能连上服务，不保证密钥有效、余额充足或模型能出图。改地址后需要重新填写密钥才会用于测试，不会将已保存的旧密钥自动发往新地址。

模型列表与连接测试分开。支持的渠道提供「获取模型列表」，通过只读 GET 获取列表，不试画；列表可能含非生图模型，需自行选择。列表不可用时可手动填写；NovelAI 下拉提供本插件已接入的模型。ComfyUI 继续导入工作流，WebUI 沿用服务端模型。所有配置和模型选择都不会自动发起收费试画。

WebUI／Forge 只需填已开启 API 的服务根地址，程序追加 `/sdapi/v1/txt2img`；本机地址指运行 Tavern 的服务器。默认无需鉴权、512×512，一次一张，模型沿用服务端当前选择，采样参数使用该服务的 API 默认值，不等于复用 WebUI 页面上上次填写的参数。不改服务端全局设置、不安装模型，不调用会中断共享任务的全局 interrupt 接口。可选用户名密码鉴权或反向代理 Bearer Token；两者凭据分开保管，切换鉴权后需重新启用。返回的模型名与种子有提供时记录，缺失时不猜测。

NovelAI 默认官方地址、V5 Full、832×1216、单张；高级设置可换 V5 Curated、V4.5、V4 或 Anime V3 的已接入模型。第三方需支持相同的 `/ai/generate-image` JSON 请求及 ZIP 图片响应，不是任意 OpenAI 中转。V4 及以上把场景和各人的描述分开，V3 组合成一个提示词；优先读取已有标签块与本图调整，不重新抄人物档案。重画换随机种子，同渠道不用再跑文字任务。只采用固定采样参数，不擅自加人物特征、画风或大段负面词；可用风格预设或自填偏好。自定义风格在不同模型下的表达效果仍待实际验收。ZIP 在内存限量读取、校验大小与 CRC，再由 DSH 解码保存，不把压缩包路径写入磁盘。每张成功图片保留实际请求参数（不含密钥）。本插件对 NovelAI 设置每边 64–2048、64 的倍数和总面积 3,145,728 像素的限制，其中单边上限是本项目的资源保护，不是对官方全部能力的声明。

功能默认关闭且隐藏配置。首次打开开关只展开配置，完整保存后才启用；已有完整配置且没有未保存修改时，再次打开直接启用。关闭开关会停用并收起配置，不清空密钥、设置或已有图片。旧配置升级不自动启用；保存和开关操作本身不调用文字或图片模型。

ComfyUI 使用自托管服务根地址与可信维护者提供的单图工作流文件，界面只提供「导入工作流」，不需要编辑 JSON。简单 API 工作流可自动识别；复杂流程用维护者映射文件指定提示词、种子和最终输出。必要部署、节点和模型由维护者负责。任务编号先落盘再提交；收到图片前断线，重试原操作查询并下载原任务，不重新入队。收到图片后保存失败则使用下面的「重试保存」。详细准备、限制和恢复行为见 [ComfyUI 场景生图](comfyui-scene-images.md)。

风格设置只有「风格预设」和选填的「补充描述／标签」。可选默认、日系插画、写实摄影、水彩、水墨或自定义；选预设后也能补充个人偏好。自定义为空按默认处理。保存后跨对话与重启保留，不需每张图重新选择。

当前 Images 渠道使用内置风格表达和用户原始补充短句，不额外调用文字模型翻译。风格块独立持久保存，更换风格后的生图、重画只组合新风格，旧图和人物资料不变；在途任务仍使用点击时的风格。单图「调整」可以临时改变风格，不写回全局设置。换渠道需要其他表达方式时应另做适配，不能把当前行为当成所有渠道通用。

启用后，在输入框上方操作栏点击「生图」，针对当前已完成的最新正文。每个游戏维护一个独立、持久的 DSH 生图子 Agent，首次创建时使用当前对话选定的文字模型；后续复用同一会话，重启后恢复，不与变量结算或其他游戏串用。没有任务时不主动请求模型。它读取目标正文、可确认的该轮姿势、相关已有方案以及上次绘图后跳过的剧情，提交画面方案；人物事实与标签块另行持久保存，不只依赖子代理历史。程序校验保存后才调用图片接口。成功后图片显示在该段正文末尾，点击图片可打开原图，也可以下载。关闭功能后生图按钮消失，已保存的图片与下载仍保留。

- 有额外的文字模型任务和生图费用，不会自动每轮生成。
- API Key 写入 DSH 凭据服务，普通设置文件不存 Key；再次保存时留空保留。OpenAI 沿用 `DSH_TAVERN_IMAGE_API_KEY`；其他渠道使用 `DSH_TAVERN_IMAGE_<渠道大写ID>_API_KEY`，如 `DSH_TAVERN_IMAGE_GEMINI_API_KEY`。WebUI、ComfyUI 的 Basic 密码分别另存于 `DSH_TAVERN_IMAGE_WEBUI_PASSWORD`、`DSH_TAVERN_IMAGE_COMFYUI_PASSWORD`；无鉴权模式不发送已保存凭据。目前不自动读取或挪用已有文字渠道的凭据。
- 不把全卡、世界书、MVU schema 塞入生图任务；不修改原正文、前台 Session 或变量，不把图片自动带进下一轮剧情请求。
- 图片由 DSH 附件服务校验和持久化，绑定到正文版本；刷新后仍可显示。生成中更换/删除目标正文时，不将结果挂到另一段正文。
- 一次一图，图片下提供「重画」「调整」及旧版本翻页；下载、查看说明、删除收进「⋯」。相同表达配置下重画复用原方案，不调用文字模型。调整只带原图方案与一句修改要求，生成新的图片，不修改长期人物方案或剧情，也不是像素级修图。
- 重画或调整失败/取消时旧图仍可读取，保留调整文字。重试同一调整可复用已保存的调整方案。默认五分钟超时；超时、连接中断、5xx、未确认接单的限流或不完整响应标记「结果未确认」，不会自动重发。再次请求需明确确认可能再次计费，确认绑定到那一次原请求，不会替其他新失败授权。
- 整理、生成和保存过程中显示「取消生图」，关闭生图开关后仍可取消。取消只中止当前任务的本地等待，不调用共享服务的全局中断或清空队列，不能保证供应商停止生成或计费。已取消任务不自动发布迟到图片；如果图片字节已收到，可由用户明确点击「重试保存」恢复。ComfyUI 保留原任务编号，明确重试时继续查原任务，不重新提交工作流。
- 请求前失败与明确参数/鉴权拒绝保留具体提示，允许修正配置后手动重试；不把普通 HTTP 错误或没有图片的响应当成成功。界面提示和详细失败诊断分开保存，未知用量不推断为免费。
- 九种渠道收到图片后先持久暂存，再交给 DSH 附件服务。保存失败显示「重试保存」，不再调用文字模型或图片渠道；关闭生图、更换渠道或重启后仍可恢复原图片、模型参数与版本。恢复完成前禁止再次生图或删除版本，避免覆盖待保存结果。
- 暂存已落盘才能保证跨重启恢复。若磁盘本身写入失败，当前进程尽量保留收到的字节，修复存储后可重试；此时重启可能丢失这些字节。缺失或损坏的暂存不会自动改为重新收费生图。成功发布图片后清理暂存，清理失败不影响已保存图片。
- 生成请求标识持久保存，重放同一标识不会再次调用供应商；删除版本也不清除对应请求记录。当前已测试同进程多服务实例的竞争，跨进程与完整任务恢复仍需继续验收。
- 删除只移除当前版本的展示与读取入口，不盲删可能共享的附件字节；附件引用回收尚待实现。关闭功能会隐藏重画与调整，但仍可翻看、下载旧图。
- 人物方案与标签块独立持久保存，按有效正文分支读取历史版本；动作变化不需要重发已有外貌、衣着标签。标签按人物组合，每次图片请求仍使用完整提示词。引用校验只证明引用确实存在，不代表程序能够证明模型的语义判断正确，也不保证画面完全一致。
- 方案格式错误最多允许一次工具反馈修正，此时尚未请求图片。图片渠道失败后，重试复用已保存方案，不再次运行文字任务；Agent 最后一条确认失败不丢已保存方案。
- 尚无参考图能力；人物卡/世界书相关设定提取、跨进程完整生命周期、其他可恢复结果信息及真实渠道验收仍在后续开发范围。

## 设定参考与范围

绘图会读取已就绪的该轮可视变量：只取正文/姿势中明确出现人物的衣着、外观、动作等，以及可识别的地点、天气、时间等场景字段。只读取选中正文版本，不发送整份变量结构、镜像或全角色名单。未就绪、旧轮没有快照、无法识别的字段或身份，继续以正文为依据，不阻止生图、不补用未来变量。

目前采用通用中英文字段筛选，不针对具体人物卡硬编码；不保证理解任意自定义 schema。旧式数组值/说明对、未知数值单位等不会推测。变量片段最多 2,400 字符，并计入 12,000 字符材料上限；字段来源保存在宿主用于校验，不为每个字段重复发送版本摘要。任务开始后冻结材料，随后变量变化不影响本次任务，重画复用原方案。

生图代理缺少人物外貌或地点设定时，可以按当前人物/地点名读取已有的历史设定快照片段。首次请求不会附带整张卡、整本世界书或角色目录；最多查询三次，片段累计最多 4,000 字符，连同剧情共用 12,000 字符材料预算。人物事实保留引用片段与快照版本，不能只用初始设定证明本轮衣着、动作或站位。

可读资料包括既有游玩快照中的人物设定、开场情境，以及正文生成前归档的启用世界书条目（含非恒定条目）。归档是本地保存，不调用模型、不改变前台世界书注入规则；功能尚未启用时也可为以后绘图保留历史依据。相同内容共用归档，正文只保存版本编号。历史轮没有记录就退回已有正文/快照，不读取后来改过的世界书。

文风示例、性格章节及可识别的程序协议不作为绘图参考；条件不明确的条目保守跳过。归档有 2,000 条、500,000 字符限制，超限情况进入诊断，不声称保存了全部资料。片段筛选与来源校验不等于模型语义判断一定正确。按需查询会多一次文字模型请求，重画已有方案不会重读。

## 可选造型参考

在插图「⋯」中选择「用作造型参考」，在图片下方选择人物、查看接收服务，再点「确认使用」。单人图可预选其身份，仍需确认；多人图不预选，不能一次自动绑定所有人。候选只包含该图方案里身份有依据的人物，显示该图的站位、外貌或衣着提示，同名人物附编号区分。不是自动沿用上一张图，未选择也能正常生图；打开选择框和绑定本身不调用模型、不收费。

目前接入 Gemini Interactions 的 `gemini-3.1-flash-image`、`gemini-3-pro-image`、`gemini-2.5-flash-image`。其他渠道及未知模型隐藏新增参考动作；已绑定的图仍可从「管理造型参考」逐人取消。参考图为已保存的 PNG、JPEG 或 WebP，单张最多 8 MiB，每次最多四张；不接受任意外部图片地址。多人参考发送的是整张图，不是自动裁剪；请求附上选中人物的身份与原图方案中的描述提示，要求忽略其他人。实际人物定位仍取决于模型，无法确认时不要绑定。

绑定从操作时的游戏进度开始适用，只发送给本轮方案里对应身份的人物；不会用于更早历史、其他游戏或无效分支。地址、渠道或模型变化需要重新确认授权，否则提示仅沿用文字外貌。关闭功能或切换渠道后仍可取消；排队任务在请求前再检查撤销、原图版本和完整性。请求已经发送后撤销不能收回供应商已收到的图片。

每张成功图片记录实际参考的来源与摘要，重启后保留。重画也服从当前有效授权，不因旧图用过参考就绕过后来的撤销。图片被删除、读取失败或完整性改变时明确提示退回文字；参考图字节不发给文字子代理、不放进日志。参考提示要求按本轮文字描绘服装、动作和环境，不复制旧构图；这只是尽量维护外貌，不保证锁脸，实际画质尚未通过商业渠道验收。

## 生图日志

点击对话上方原有「日志」即可下载，无新按钮。ZIP 中的 `scene-images/diagnostics.json` 包含本游戏的生图尝试、画面材料、方案和最终提示词、渠道请求参数、阶段耗时、可用请求编号及失败；关联的持久生图子 Session 放在 `subagents/`，可查看每次文字请求与工具反馈。失败后重试不会覆盖前次诊断。

不包含生图图片字节或认证请求头；密钥、认证文本和 URL 查询会尽力脱敏，但材料可能包含私人剧情，分享前请检查。文字费用以子 Session 实际用量为准，图片接口没有提供的用量记为“未提供”，不是零费用。阶段耗时是壁钟时间，可能含排队或中断等待。

每游戏最多保留 100 次尝试、总计 2 MiB；单次详情超过 128 KiB、阶段或 HTTP 事件超过 100 条时明确标记裁剪。旧版没记录的故障不能追溯补出。日志盘写入失败不触发重新生图；异常退出可能只留下最后已记录阶段，结果未确认仍需按界面提示处理。

## 实现与许可

借鉴 `shanliuling/dsh-image-gen` 的 `src/openai-compatible.ts`，固定提交 `0a1bb6d4ad0adb0e676a1193d098bd4c4589d167`。保留了 MIT 版权许可：`tavern-plugin/lib/vendor/dsh-image-gen-LICENSE`。

只移植兼容接口的请求/响应思路，没有安装整套插件。下载返回图片 URL 时不转发生图 Key，不跟随重定向；第三方下载须为解析到公网 IPv4 的 HTTPS 地址，用户明确配置的同源本地服务例外。生成和下载响应有字节上限，最终图片由宿主完整解码校验。

绑定状态独立保存在 Tavern 数据目录的 `scene-images/`；待保存图片也在此目录私有暂存，不随状态查询返回。成功图片字节归 DSH 附件服务管理，不是临时供应商热链。正文回退或切换不会修改图片记录；只有与当前正文版本匹配的记录可读。

## 验证边界

自动测试覆盖默认关闭、旧配置迁移、显式启用、未启用/正文生成中的后台请求拒绝、保存不收费、接口请求、base64/URL 返回、凭据不转发、大小/格式限制、独立子 Agent 工具执行、重复点击、失败重试、正文版本绑定与刷新恢复。

`tests/scene-image-native.test.mjs` 使用本机 DSH 的真实 Agent loop、工具和附件校验落盘，文字模型返回及生图 HTTP 服务由测试夹具提供。`tests/fixtures/scene-image-browser-smoke.mjs` 在此基础上挂载产品正文 renderer、按钮和设置组件，用浏览器验证图片位置、失败提示和恢复。

这些测试不消耗用户额度，也不等同于某个商业生图供应商的实测。实际画质、模型名/尺寸兼容及供应商审核行为仍需使用者自己的接口确认。

完整生命周期、多渠道与参考图按照[完整规格](specs/scene-illustration.md)继续开发；本页只描述已实现部分，验证进度见[交付清单](specs/scene-illustration-delivery.md)。
