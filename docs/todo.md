## P2：人物卡专属 UI 工具

正则是兼容层，不能根治横线、块头或字段缺失等掉格式问题。长期方案是在人物卡导入或准备阶段生成并缓存专属 UI Adapter：

- [ ] 分析人物卡的正则、HTML 模板和字段协议，生成结构化 schema 与专属 UI 工具；模板只生成一次。
- [ ] 前台主 Agent 只生成纯正文，不再输出状态块、HTML、分隔符或其他 UI 协议。
- [ ] 正文完成后启动独立 UI 任务，只提交本轮结构化变量，并调用人物卡专属工具。
- [ ] 工具校验失败时限次重试 UI 任务，不重新生成正文；结果绑定剧情 revision。
- [ ] 不同人物卡使用不同 schema，但统一展示接口，并支持差量更新。
- [ ] 过渡期保留正则兼容；专属工具稳定后，正则只作为模板来源。
