## 2026-09-01：ComfyUI 工作流与原任务恢复

- 新增 ComfyUI 自托管渠道，地址与可选 Basic/Bearer 认证独立保存；界面只有工作流文件导入，没有 JSON 编辑器。简单 API 图按单采样器的正向 CLIPTextEncode 与唯一 SaveImage 识别；复杂图由维护者提供显式映射，详见[使用说明](../comfyui-scene-images.md)。只提交选定输出依赖图，替换指定正向提示词、种子和单图数量，保留模型、负面词与其他参数。未知节点语义不冒充自动识别。
- 按[固定版本官方证据](../research/comfyui-image-protocol-2026-09-01.md)实现 `/prompt` → `/history/{id}` → `/view`。任务 UUID 在 POST 前落盘，收到真实 ID 后再保存；同 ID 不是幂等键，断线后不重发 POST。支持查原历史/队列恢复，错误历史即使 completed=false 也终止。只接收指定输出的唯一图片；下载留在配置同源并认证，不使用任意返回 URL、不跟随重定向。
- ComfyUI 的任务编号和状态进入持久记录；Tavern 重启、下载或附件保存失败后重试原操作查询同一任务，保留已保存方案，不重复文字整理和图片提交。恢复需要原渠道/工作流/风格配置；结果不明时不猜测未收费。页面轮询只返回工作流名称/摘要，不每次发送完整图。通用本地暂存、取消、跨进程完整生命周期尚未完成。

## 2026-09-01：NovelAI 非流式生图

- 已实现独立 NovelAI 配置、官方默认 V5 Full（832×1216）和同协议第三方根地址；接入 V5、V4.5、V4、Anime V3 的已核实模型标识。后台固定单图参数，不增加采样器面板、不导入其他插件的大段质量/负面词，不做自动收费重试。
- 依据[官方协议与前端核验笔记](../research/novelai-image-protocol-2026-09-01.md)使用普通 JSON→ZIP 路径，不混用流式 MessagePack。V4 以上从已冻结的场景块、人物块及本图风格分别构造 base/character captions；V3 组合成单段。人物分组按稳定身份、不按姓名；本图换装读取调整后的块，不覆盖回旧档案。文字任务获得对应渠道的简短表达规则，不把全部供应商文档塞进提示词。
- ZIP 只在内存读取，限定压缩/解压大小、条目数、文件边界和唯一图片，支持 stored/deflate/data descriptor，校验图片 CRC；拒绝损坏包、加密包、路径穿越、伪造小尺寸解压包。最终仍交 DSH 附件服务解码。实际请求体、种子、模型存入成功图片版本，不包含密钥。
- 全套自动回归 1032 项通过、0 跳过。新测试覆盖 HTTP 路径、鉴权、角色分组、同名隔离、单图调整覆盖、模型差异、随机种子、坏包/限额/错误脱敏；真实 DSH loop 通过新协议取得 ZIP 图片、保存附件、重启读取，前台无新增消息。服务测试验证人物方案确实传到协议层，重画不再次运行文字 Agent。
- 浏览器测试宿主检查默认地址/模型/尺寸、独立密钥、先保存再启用、图片出现、重画和重启：保存启用 0 次请求；首次累计 2 次文字/1 次图片，重画累计 2 次文字/2 次图片，前台新增消息 0；重启保留两版本，无浏览器错误。测试图仍是本地纯色夹具，不是 NovelAI 真实生成或画质证据。最后加入的后台表达提示与 ZIP 边界收紧由自动测试覆盖，不改变已验证的 UI。
- 真实 NovelAI/第三方授权出图、参考图与风格语义效果未验证；ComfyUI、完整任务恢复/取消、相关素材提取和日志仍在完整开发范围内。DSH 已有渠道的地址/凭据引用方案尚待用户确认，不擅自借用文字渠道密钥。

## 2026-09-01：重画、单图调整与图片版本

- 每张成功图片持久保存方案快照、请求标识、实际提示词与无密钥配置。重画读取选中版本；同表达配置下完全跳过文字 Agent。单图调整使用 `submit_image_adjustment`，只读取原方案与本次要求；替换/清除对应块，绝不回写人物方案文件。跨表达转换校验完整覆盖，禁止转换时改变画面事实。
- 图片列表保留各版本、说明与下载地址。新请求运行或失败时旧图继续可读，左右按钮切换版本；关闭功能隐藏生成操作，保留浏览和下载。失败调整恢复原修改文字，服务重启后仍能重试；同一已保存调整的图片重试不重复调用文字 Agent。
- 请求标识入盘后重放不重复生图；前端网络异常保留请求标识，普通 HTTP 页面不依赖 `crypto.randomUUID`。同进程不同服务实例不能抢占仍在运行的任务；切换正文版本不会把结果挂到新正文，切回可读取原图。跨进程、PID 复用等完整恢复边界仍待后续验证。
- 删除目前是移除该版本的展示/读取入口并保留墓碑，不盲删可能共享的附件字节，也不清除已收费请求的去重记录。参考关系及物理附件回收待后续实现。

- 浏览器使用生产 renderer、dock、设置和真实 DSH loop，文字/图片响应仍是本地测试夹具：首图累计 2 次文字/1 次图片，重画累计 2 次文字/2 次图片，调整累计 4 次文字/3 次图片，前台新增消息始终为 0。验证旧图翻页、重启保留版本、关闭隐藏生成入口、新图失败保留旧图及调整文字；失败后重启重试仍是累计 4 次文字请求。查看过实际渲染，测试图为纯色占位，不作为画质证据。
