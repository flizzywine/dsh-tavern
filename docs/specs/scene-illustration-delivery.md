## 2026-09-01：显式启用与输入框上方入口

- 后台：旧配置缺少 `enabled` 时关闭；先保存完整配置才能启用，部分保存不会丢其他字段；并发保存串行。关闭或前台生成中拒绝新任务，已保存图片仍可读取。
- 前台：主按钮注册在原有 `conversation.input.dock` 操作栏，正文 renderer 不再放生成按钮；读取真实规划/生成/保存阶段；保存后单独启用，未保存的配置不能直接启用。
- 测试：`scene-illustration.test.mjs` 覆盖上述后台行为；`play-controls-chat-snapshot.test.mjs` 验证实际 dock 的目标轮次、Chat/Session 选择和卡片模式隔离；本机真实 DSH Agent loop + 附件测试通过。
- 浏览器：使用生产 renderer、生产 dock 注册和设置函数，测试宿主仅提供会话元数据、脚本文字模型和本地图片 HTTP 接口。保存与启用时调用数均为 0；点击后 2 次文字请求（工具提交及收尾）、1 次图片请求、前台 0 条新增消息；关掉后按钮消失但图片、下载保留；重启仍可见。390px 窄屏下图片与操作栏未撑出正文，页面可滚动，无浏览器错误。
- 这不是完整部署的 Desktop/CLI 端到端验收，不证明商业渠道可用，也不代表后续重画、调整、取消等尚未实现流程已经通过。整个规格仍在开发中。

## 2026-09-01：方案与标签的持久化主流程

- 新增 `scene-plan.js`，按游戏、正文有效历史和表达版本保存人物事实版本、标签块及画面方案；同一个原子写入发布一致版本，不逐字段写半成品。人物事实不含渠道标签，换表达配置不改变相同事实的版本。
- 子代理工具改为 `submit_scene_plan`，只提交有变化的字段、标签及必要来源引用。宿主验证字段、重复身份和原文引用，允许一次格式修正；成功保存后才由宿主单独请求图片。保存成功不依赖 Agent 最后一条确认成功。
- 通过 `scene-plan.test.mjs` 验证：只改动作时其他标签版本不变、清除不残留、场景不连续时不继承旧动态信息、同名人物分别持久化、未来/其他分支不串入、过期提交拒绝、切换表达不改人物事实版本。
- `scene-illustration.test.mjs` 增加实际主流程测试：格式修复发生于付费请求前，失败图片复用方案，历史正文不借最新姿态，两次绘图之间的剧情进入输入。只取目标及上次方案之后的正文，以完整段落预算裁剪，记录缺失和字符预算（不冒充 token）；裁剪后不能确认连续性。
- 全套回归 976 项通过，包含本机真实 DSH Agent loop / 工具 / 附件测试；测试宿主浏览器验证方案提交→图片生成→展示，仍为 2 次文字请求、1 次图片请求、前台无新增消息。供应商和文字模型返回仍使用本地夹具，不是商业渠道或真实语义/画质验收。
- 未完成项仍包括：相关原始卡片/世界书设定提取、重画与调整、风格、多渠道、参考图、图片版本浏览、取消与恢复、完整日志导出。以上不因基础模块通过测试而标为完成。

## 2026-09-01：重画、单图调整与图片版本

- 每张成功图片持久保存方案快照、请求标识、实际提示词与无密钥配置。重画读取选中版本；同表达配置下完全跳过文字 Agent。单图调整使用 `submit_image_adjustment`，只读取原方案与本次要求；替换/清除对应块，绝不回写人物方案文件。跨表达转换校验完整覆盖，禁止转换时改变画面事实。
- 图片列表保留各版本、说明与下载地址。新请求运行或失败时旧图继续可读，左右按钮切换版本；关闭功能隐藏生成操作，保留浏览和下载。失败调整恢复原修改文字，服务重启后仍能重试；同一已保存调整的图片重试不重复调用文字 Agent。
- 请求标识入盘后重放不重复生图；前端网络异常保留请求标识，普通 HTTP 页面不依赖 `crypto.randomUUID`。同进程不同服务实例不能抢占仍在运行的任务；切换正文版本不会把结果挂到新正文，切回可读取原图。跨进程、PID 复用等完整恢复边界仍待后续验证。
- 删除目前是移除该版本的展示/读取入口并保留墓碑，不盲删可能共享的附件字节，也不清除已收费请求的去重记录。参考关系及物理附件回收待后续实现。
- 自动回归 984 项通过、0 跳过，包含真实 DSH loop 的生图→重画→调整→重启读取。`scene-image-adjustment.test.mjs` 覆盖事实不变的表达转换、块清除、未知人物拒绝与旧方案迁移；`scene-image-controls.test.mjs` 覆盖 HTTP 页面请求标识和丢失响应后的重复提交。
- 浏览器使用生产 renderer、dock、设置和真实 DSH loop，文字/图片响应仍是本地测试夹具：首图累计 2 次文字/1 次图片，重画累计 2 次文字/2 次图片，调整累计 4 次文字/3 次图片，前台新增消息始终为 0。验证旧图翻页、重启保留版本、关闭隐藏生成入口、新图失败保留旧图及调整文字；失败后重启重试仍是累计 4 次文字请求。查看过实际渲染，测试图为纯色占位，不作为画质证据。
- 本阶段浏览器为桌面宽度；完整窄屏交互、多设备和商业渠道仍未验收。剩余项以本清单顶部及渠道表为准，不将这一阶段视为整个规格完成。

## 2026-09-01：风格预设、自定义与独立风格块

- 设置新增默认、日系插画、写实摄影、水彩、水墨、自定义六项预设及一个选填补充框。原始补充文字不改写，部分配置保存不丢已有补充；空自定义按默认表达处理。保存与启用都不调用模型。
- `scene-image-style.js` 独立维护带选择摘要、模板版本和表达配置的持久风格块；Images 渠道可直接使用内置标签与原始补充短句，不额外做一次文字翻译。对标签词表有限制的其他渠道仍须专门适配，不宣称任意渠道都无需转换。
- 每张图冻结风格版本与配置；在途任务不受之后设置变化影响。换风格重画不重做人物与场景块，旧图提示词不改变。临时风格以单图覆盖保存，不写回全局设置或人物文件；重画这张图可保留覆盖，用户变更全局风格后以新选择为准。跨表达转换校验保留临时风格事实，只改表达。
- 全套 989 项测试通过、0 跳过，包含真实 DSH loop 的预设风格重画与 `submit_image_adjustment` 单图风格提交。新增测试覆盖持久复用、配置校验、空自定义、配置变更时冻结在途任务、部分保存、单图覆盖隔离和跨表达校验。修正测试宿主的清理顺序：先结束全部服务实例，再删除测试目录，避免后台收尾与测试清理竞争。
- 浏览器验证设置控件、保存后调用数为 0；生成水彩图累计 2 次文字/1 次图片，切换水墨重画累计仍为 2 次文字/2 次图片。实际请求只替换风格后缀，原图仍保留水彩表达。这些是本地夹具下的路径验证，不证明商业模型画质或对风格的语义遵循。
- 其他渠道、参考图、完整任务恢复、相关卡片材料提取和日志导出仍在范围内，未完成。

## 2026-09-01：六种云端协议与独立配置

- 新增 `scene-image-channels.js`，分别构造 Images、Gemini Interactions、聊天图片中转、Grok、Seedream、Qwen 请求；每次只请求一张。提取图片结果，不把 Gemini 思考内容或普通文字链接当作结果；下载复用现有鉴权隔离、来源与大小限制，最终由 DSH 附件服务解码。
- `scene-image-settings.js` 按渠道保存地址、模型、尺寸与比例。旧版平铺配置保留为 OpenAI 配置，显式空值和原有风格不丢失。密钥仍由 DSH 凭据服务保管，不进入普通配置或返回给前端；只读预览不改变当前渠道，不复用其他渠道的密钥。保存不同渠道后关闭生成入口，需要再显式启用。
- 设置界面增加渠道选择，仅显示该渠道字段；官方地址和参数默认折叠，中转显示必要输入。保存、启用无文字/图片请求。请求开始时在配置写锁下捕获渠道和密钥，随后换渠道或旋转密钥不会把新密钥发到旧地址；每张图片保存无密钥配置，表达版本也区分渠道。
- 自动回归 1007 项通过、0 跳过。新增本地 HTTP 协议测试覆盖六种请求体、鉴权、base64/URL 结果、畸形响应和未知协议；配置测试覆盖预览、独立密钥、重启、并发保存、迁移和在途冻结。真实 DSH Agent loop + 附件测试逐一走通六种协议，模型与图片响应仍是本地夹具，不是供应商实测。
