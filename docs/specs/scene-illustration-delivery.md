- 已收到的单张图片先写入私有持久暂存，再交给 DSH 附件服务；暂存绑定原请求，包含图片校验摘要与无密钥生成参数。发布成功才清理，清理失败不撤销成功。附件已经保存但发布失败时保留附件引用，恢复无需再存一份附件。
- 失败显示「重试保存」，原生成入口禁用；关闭功能后仍保留恢复入口。恢复不读取当前密钥、模型或风格，不运行 Agent、不提交图片请求，保持原图和原版本。并发恢复与重复点击不生成重复版本；暂存缺失或校验失败时停止，不静默重新收费。
- 服务重启会识别已暂存但未发布的结果，即使上一条任务记录仍停留在生成阶段。磁盘彻底写入失败时只能尽量在当前进程保留字节，不能保证重启可恢复；完整磁盘故障不是可承诺消除的数据丢失风险。
- 自动测试覆盖附件写入、发布、暂存和清理失败，缺失/损坏暂存，重启、关开关、换模型、并发恢复、原参数保留、恢复入口与费用隔离。九种渠道逐一通过本地 HTTP 响应→真实 DSH 子 Agent→模拟附件故障→关闭→重启→真实 DSH 附件保存，恢复过程中无新增文字和图片请求。
- 当前工作树完整回归 1,072 项通过、0 跳过；`git diff --check` 通过。该总数包含同时合入的会话初始化重构测试，不全部属于生图改动。
- 浏览器使用生产 renderer、dock、设置与真实 DSH loop，文字/图片接口仍为本地夹具：失败后显示「重试保存」及禁用的「图片待保存」；关闭功能、重启后恢复成功，累计仍为 2 次文字/1 次图片请求，前台新增消息 0；查看实际页面且浏览器无错误。这不是商业渠道或完整 Desktop/CLI、移动端验收。
