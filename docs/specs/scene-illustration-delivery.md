## 2026-09-01：显式启用与输入框上方入口

- 后台：旧配置缺少 `enabled` 时关闭；先保存完整配置才能启用，部分保存不会丢其他字段；并发保存串行。关闭或前台生成中拒绝新任务，已保存图片仍可读取。
- 前台：主按钮注册在原有 `conversation.input.dock` 操作栏，正文 renderer 不再放生成按钮；读取真实规划/生成/保存阶段；保存后单独启用，未保存的配置不能直接启用。
- 测试：`scene-illustration.test.mjs` 覆盖上述后台行为；`play-controls-chat-snapshot.test.mjs` 验证实际 dock 的目标轮次、Chat/Session 选择和卡片模式隔离；本机真实 DSH Agent loop + 附件测试通过。
- 浏览器：使用生产 renderer、生产 dock 注册和设置函数，测试宿主仅提供会话元数据、脚本文字模型和本地图片 HTTP 接口。保存与启用时调用数均为 0；点击后 2 次文字请求（工具提交及收尾）、1 次图片请求、前台 0 条新增消息；关掉后按钮消失但图片、下载保留；重启仍可见。390px 窄屏下图片与操作栏未撑出正文，页面可滚动，无浏览器错误。
- 这不是完整部署的 Desktop/CLI 端到端验收，不证明商业渠道可用，也不代表后续重画、调整、取消等尚未实现流程已经通过。整个规格仍在开发中。
