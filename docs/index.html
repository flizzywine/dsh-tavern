THE FIELD GUIDE / 完整功能

想用的时候，
它就在这里。

不用一次学完。
按你眼下想做的事，展开看看。

01

导入人物卡，开始游戏

选角色、选开场，写下第一句话

  • 导入 SillyTavern PNG / JSON 人物卡。
  • 预览多条开场白，选择喜欢的一条。
  • 设置玩家称呼，后续也可以修改。
  • 同一人物卡创建多个独立游戏。
  • 未绑定剧本时自由游玩；绑定剧本后，新游戏自动按剧本推进。
  • 无需导入外部预设，使用内置设置即可开始。

首次使用仍需安装 dsh-tavern 并配置模型服务。

02

行动、重写与剧情指导

故事的方向，始终可以由你决定

  • 自由输入角色行动、对白和剧情要求。
  • 查看独立的人物行动候选与场景变化建议。
  • 点击候选填入输入框，修改后再发送。
  • 重新生成候选，或附上具体要求重新生成。
  • 一键重写当前正文，或填写意见后重写。
  • 回退当前回合，尝试另一种行动。
  • 添加、查看与删除持续生效的剧情指导（Guide）。

回退和重写针对当前回合，不等于完整的任意历史节点分支管理。

03

剧本、状态与长局连续性

有主线，也有可以找回的前文

  • 绑定小说、剧本或故事大纲，按进度参考附近片段。
  • 查看剧本进度与当前参考内容，保留自由行动。
  • 后台总结人物姿势，右侧查看场景信息。
  • MVU 人物卡后台结算变量，状态栏常驻右侧。
  • 查看结算状态，失败时单独重试。
  • 世界书按规则提供当前相关的背景。
  • 按需检索当前游戏的历史正文，读取命中轮次附近原文。
  • 通过上下文压缩入口协调前台与后台压缩。

状态栏依人物卡能力而定。检索和压缩有助于保持连续性，不保证模型永不遗漏细节。

04

高级功能：可复用的长期偏好

需要跨局复用偏好时，再了解

  • 从右侧栏“用户画像”进入访谈，建立长期偏好。
  • 原始回答、分析与已确认结论分开保存。
  • 查看实际生效的偏好文本、偏好维度和回答依据。
  • 直接修改偏好，或交给卡片 Agent 继续调查。
  • 跨人物卡复用；仅在右侧栏设置“新游戏默认启用”。
  • 默认关闭，游戏开场准备不显示画像选项。

由你主动建立、确认并开启。开关只影响以后新开的游戏；当前游戏保持开局时的画像版本。

05

剧情生图与造型参考

这一幕，值得留下来

  • 手动为目标剧情生成插画，不会每轮自动生图。
  • 根据正文与可用人物、场景资料整理画面。
  • 直接重画，或附上修改意见再画。
  • 浏览同一段剧情的图片版本，打开大图。
  • 日系插画、写实摄影、水彩、水墨及自定义风格。
  • 按渠道设置尺寸、分辨率或画面比例。
  • 在支持的渠道中，将图片绑定为指定人物的造型参考，也可取消。
  • 查看进度、取消生图、失败重试；保存失败时单独重试保存。
  • 配置渠道、测试连接，部分渠道可读取模型列表。

渠道包括 OpenAI Images 及同协议中转、Gemini、Gemini 聊天兼容中转、Grok、Seedream、Qwen-Image、NovelAI、ComfyUI、SD WebUI / Forge。具体模型与功能依渠道而定，不能把任意中转都视作兼容。

需要自行配置，实际生成可能收费。造型参考需确认向目标服务发送图片，不保证锁脸；ComfyUI / WebUI 连接已有服务，不代为安装模型或节点。

06

通过对话制作、修改和调试

从一个想法，到一张可以玩的卡

  • 空白开始，讨论人物、情境与故事设定。
  • 从小说、剧本和素材中制作人物卡。
  • 阅读、分析和修改现有人物卡。
  • 通过对话修改世界书、剧本和预设。
  • 引用多个资源，放进同一次创作对话。
  • 转换为独立 MVU 版本，将状态栏展示与正文生成分离。
  • 将正文、正则或美化问题交给卡片 Agent 调试。
  • 保留导入原版，编辑工作版；可让 Agent 恢复人物卡原版。

Agent 与你讨论修改内容，再按确认范围写入。转换和调试不意味着任意人物卡都能自动修好。

07

四个资源库，集中管理

人物卡 · 世界书 · 剧本 · 预设

  • 人物卡：导入、查看、编辑、导出 JSON、重命名文件与删除。
  • 编辑角色描述、性格、情境、开场白和对话示例等字段。
  • 管理人物卡与世界书、剧本的绑定关系。
  • 查看卡内正则、Tavern Helper 脚本和 MVU 相关资源。
  • 世界书：统一管理独立与卡内世界书，导入导出、编辑条目与开关。
  • 剧本：导入 TXT、Markdown、JSON、EPUB 素材，查看和编辑工作版。
  • 剧本重命名、删除、引用到工作台，绑定或解绑人物卡。
  • 预设：导入、选择、编辑、导出、重命名与删除。

人物卡内直接导入剧本的入口支持 TXT、Markdown、EPUB。卡内扩展的查看能力，不代表所有第三方脚本均可运行。

08

为游玩选择文风与写作规则

想调整时，再打开预设库

  • 导入 SillyTavern 预设，调整文风、叙事方式与写作规则。
  • 编辑提示词、正则和可切换条目的启用状态。
  • 把预设交给卡片 Agent 阅读和修改。
  • 查看、编辑内置系统提示词，单项或整套恢复默认。
  • 导入和导出系统提示词。
  • 通过卡片 Agent 分析样文文风，按需保存为可复用 Skill。

不导入外部预设也能直接玩。预设服务游玩正文，后台 Agent 不运行预设；导入的酒馆预设在 DSH Tavern 中应用，效果可能与原酒馆不同。文风提炼已有能力，完整可视化文风库尚未提供。

09

保存故事与处理日常问题

继续、导出、更新，都有去处

  • 游玩历史与卡片工作台历史分开管理。
  • 继续、重命名或移除对话。
  • 导出纯对话 TXT，只包含玩家与角色正文。
  • 导出 Session、MVU 与生图相关日志，方便反馈问题。
  • 用户数据持久保存，提供安装与更新流程。
  • 在界面检查更新。

日志可能包含私人剧情和附件信息，分享前请检查。程序更新会保留用户配置与自定义内容，重要数据仍建议自行备份。

10

模型、联网与开放扩展

留给需要更多控制的你

  • 通过 DSH 配置前台模型服务。
  • 后台选择独立模型，或在开局时跟随前台。
  • 可选开启联网搜索，前后台能力在新游戏开局时固化。
  • 通过高级工作台能力创建 Skill、自定义工具与插件。
  • 保留 DSH 插件组合能力，用户扩展与程序文件分开存放。
  • Windows / macOS 桌面入口，Windows / macOS / Linux 命令行运行。
  • Android 实验性运行方案。

模型与平台基础能力由 DSH 提供。高级扩展的保存、当前运行和重启后加载是不同阶段；第三方资源支持需以实际行为为准。

你可能还想知道

这是可以直接在线玩的网页吗？

这里是产品介绍页。实际游戏运行在你安装的 dsh-tavern 中；模型服务需自行配置，此网页不接收你的 API 密钥或游戏内容。

一定要先懂世界书、MVU 和预设吗？

不需要。先导入喜欢的人物卡并开始游玩。世界书负责提供背景，MVU 用于部分人物卡的状态管理，预设用于调整写作规则，都不应成为开始游戏的必修课。

所有酒馆人物卡和插件都能直接使用吗？

支持人物卡、世界书、预设、正则美化和部分脚本能力，但不承诺完整复刻所有酒馆插件。依赖特殊接口的资源，实际效果可能不同。

故事很长以后，还能记住前面的事吗？

系统可以按需检索已经发生的剧情原文，也提供上下文压缩。它们帮助维持连续性，但不能保证模型永不遗漏或记错。

截图与我安装后的界面不一样？

页面使用项目已有的演示截图，部分按钮名称与布局可能早于当前版本。功能说明依据当前代码整理，最新使用方式以实际安装版本为准。
