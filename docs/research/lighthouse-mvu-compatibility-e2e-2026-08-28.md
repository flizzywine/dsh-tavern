> 验收日期：2026-08-28
>
> dsh-tavern 分支：`MVU`
>
> 验收提交：`8cd125a`

## 结论

《灯火阑珊》已经能够在 dsh-tavern 的纯前台兼容模式中完成一轮真实运行：人物卡初始化 MVU 状态，前台请求携带变量快照，模型同时输出正文和标准变量补丁，Host 将补丁结算到当前消息及 Swipe，随后显示正则与状态栏读取新状态并重新渲染。

这证明当前实现已经形成可运行的 MVU 主链路，但不等于完整复刻 SillyTavern、MagVarUpdate、ST Prompt Template 和 Tavern Helper。没有完成固定输入下的 SillyTavern 差分验证，因此当前不能标记为“完整支持”。

本轮模型输入和输出具有随机性，只证明该次真实链路可运行；它不是同输入、同输出的差分基准。

## 可观察证据

### 1. 人物卡资产

人物卡中检测到五个 Tavern Helper 脚本入口：

1. `MVU`
2. `灯火阑珊-变量结构`
3. `灯火阑珊-动态世界书管理`
4. `开场白索引`
5. `变量守卫`

卡内还有发送侧变量清理、变量更新显示美化和状态栏加载正则。

### 2. 初始化与 Swipe

- 开场消息包含 15 个 Swipe。
- 15 个 Swipe 均建立了独立变量快照。
- 每个快照包含 `stat_data`、`schema`、`display_data`、`delta_data` 和 `initialized_lorebooks`。
- 某条开场白存在 YAML 缩进错误时，仅该 Swipe 产生诊断，其他开场白仍可使用。

### 3. 最终请求

本轮真实模型请求记录为 `mtcp19k9-b80d6eb1-dbe2-45e5-9c39-8e0ee1046e5c`：

- 请求模式为 `sillytavern`；
- 最终装配为 3 条消息；
- 发送内容约 8.4 万字符；
- `{{format_message_variable::stat_data}}` 已被实际 YAML 替换；
- 请求中包含 `世界时钟` 等当前 MVU 状态；
- 请求中没有遗留 EJS 标记；
- 本卡本轮没有 EJS 模板，因此 EJS 求值次数为 0。

### 4. 回复结算

前台模型在正文后输出 `<UpdateVariable>` 和 JSON Patch。兼容运行时成功把变更写入当前助手消息的变量快照，包括：

- `世界时钟/时辰`：`子时` → `丑时`；
- `本尊/行踪/当前区域`：更新为 `神州·青石古道·晨雾岔口`；
- 当前处境与可参与机遇同步更新。

状态栏远程 UI 随后继续通过 Helper bridge 写入派生字段，说明消息 iframe 到 Host 的变量 mutation 链路已经实际工作。这不能证明五个独立人物卡 Helper 脚本已经获得常驻执行环境。

### 5. 显示结果

- 完整变量更新没有以原始协议裸露给用户，而是被显示正则折叠为“天道推演”。
- 《灯火阑珊》状态栏成功加载。
- 状态栏显示更新后的地点、危险度、时代和时段。
- 正文、MVU 结算和状态栏 UI 可同时存在，未互相覆盖。

默认隔离 iframe 会拒绝卡片脚本直接访问父页面，控制台因此出现一条 `SecurityError`。状态栏仍可加载和读取 Host 提供的变量；需要父页面同源权限的功能暂不开放。

## 当前兼容矩阵

| 能力 | 当前等级 | 说明 |
| --- | --- | --- |
| `<initvar>` 与开场 Swipe 快照 | 受限支持 | 真实卡 15 个 Swipe 已建立快照；错误 Swipe 可局部隔离，尚未完成官方 MVU 全量差分 |
| 标准 MVU 补丁结算 | 受限支持 | 本轮 JSON Patch 已结算；支持核心操作和失败隔离，尚非官方 MagVarUpdate 整包运行 |
| 下一轮变量宏注入 | 受限支持 | `format_message_variable` 已在真实最终请求中展开，Helper 全部宏/API 尚未补齐 |
| ST Prompt Template / EJS | 受限支持 | 核心模板、变量和控制流在 QuickJS 中执行；《灯火阑珊》本轮未使用 EJS，完整上游 API 仍有缺口 |
| 发送侧与显示侧正则 | 受限支持 | 本轮变量宏、变量更新折叠和状态栏替换均工作；尚未与固定 SillyTavern 版本全量差分 |
| Tavern Helper 消息/变量桥 | 受限支持 | 消息 iframe 中的状态栏可读写消息和聊天变量；独立人物卡 Helper 脚本宿主及广泛世界书、生成、取消 API 尚未补齐 |
| 卡片专属动态世界书 | 不支持 | 只能检测脚本入口；当前没有常驻执行该人物卡脚本，也没有提供 `updateWorldbookWith` |
| 变量守卫 | 不支持 | 只能检测脚本入口；Host MVU 尚未把 `COMMAND_PARSED`、`VARIABLE_UPDATE_ENDED` 交给常驻人物卡脚本 |
| 状态栏与远程 CG | 受限支持 | 默认隔离下可加载 HTTPS 资源和 UI；直接访问父页面被拒绝 |
| MVU 额外模型解析 | 不支持 | 当前按已确认方案坚持纯前台 MVU |
| SillyTavern 同输入差分 | 不支持 | 尚未捕获同版本、同输入、固定模型输出的请求、事件和 UI 对照 |
