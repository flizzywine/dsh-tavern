## 结论

《灯火阑珊》已经能够在 dsh-tavern 的纯前台兼容模式中完成一轮真实运行：人物卡初始化 MVU 状态，前台请求携带变量快照，模型同时输出正文和标准变量补丁，Host 将补丁结算到当前消息及 Swipe，随后显示正则与状态栏读取新状态并重新渲染。

这证明当前实现已经形成可运行的 MVU 主链路，并能常驻执行本卡的变量结构、动态世界书、开场白索引和变量守卫脚本。它仍不等于完整复刻 SillyTavern、MagVarUpdate、ST Prompt Template 和 Tavern Helper；没有完成固定输入下的 SillyTavern 差分验证，因此当前不能标记为“完整支持”。

## 验收环境

- 人物卡：本机导入的《灯火阑珊》，不提交人物卡和 CG。
- 外部预设：`Kemini Dramatron 陨落的天才 v1.26`。
- 前台模型：Google Gemini 3.7 Flash。
- 测试动作：依次发送 `向前一步，观察四周。`、`我先停在路边，向赶车少年拱手问路。`、`我婉拒搭车，继续徒步前往临安坊市。`。
- 运行模式：兼容模式，纯前台 MVU；没有后台变量模型。
- 自动化测试：`668/668` 通过，`git diff --check` 通过。

本轮模型输入和输出具有随机性，只证明该次真实链路可运行；它不是同输入、同输出的差分基准。

状态栏远程 UI 随后继续通过 Helper bridge 写入派生字段，说明消息 iframe 到 Host 的变量 mutation 链路已经实际工作。
