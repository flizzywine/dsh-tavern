# DSHA 内嵌酒馆窗口实测（2026-09-11）

## 改动

酒馆工作台在 DSHA 内打开带工具栏的窗口，支持刷新、直接打开原入口和关闭。安装流程自动包含入口组件，无需用户另外部署代理或手动填写地址。

本机代理由入口插件管理，只监听回环地址，使用随机端口和独立鉴权 Cookie；HTTP 和 WebSocket 均检查访问凭据与来源。代理负责获取当前酒馆登录态，不重复发送写入请求；插件卸载时关闭监听和连接。

## MuMu 实测

使用本机已有 MuMu 和已安装的 DSHA，DSH 版本为 `0.1.2-rc.1`。在原有 Tavern `v1.6.0 / ad83eb2` 测试安装中替换本次入口组件；这次没有重新从零安装整个项目。

- 从 DSHA 侧栏打开内嵌酒馆，无需手动登录或输入地址。
- 打开公开示例“灯塔小镇·雨夜来信”的旧存档，历史正文及 MVU 状态正常显示。
- 用已有模型配置 DeepSeek-V4-Flash High 发出一轮真实请求，正文生成完成；界面显示本轮正文用时 8 秒，随后后台结算完成、变量更新 1 项。此时间仅为本次测试结果。
- 点击刷新、关闭后重新打开，最新正文和变量状态仍然存在。
- 点击“直接打开”，成功进入原酒馆页面。
- 更新最终代理文件并使用 DSHA 启动页的“重启”，再次进入内嵌酒馆，存档和变量状态恢复正常。
