# 文档站：本地预览与文字维护

`docs/index.html` 现在是纯文字文档站。左侧只有四个产品部分：酒馆生态兼容、游玩模式、卡片模式、高级功能。中间按主题阅读，右侧为本页导航；帮助与维护单独提供入口，不作为第五个产品分类。

包含完整清单的 100 个功能与指南主题，不把它们宣传为 100 个独立产品功能。正文是供审阅的文字初稿，尚不等于全部功能都经过真实模型和供应商验收。

旧宣传页保留在 `docs/product.html`。新文档正文不使用旧截图、不放图片占位；文字定稿后再拍当前界面。旧宣传页与原有社交分享图不在本轮截图更新范围内。

## 本地启动

在仓库根目录运行：

```sh
pnpm docs:dev
```

这会生成静态页面，并通过 Python 3 在回环地址提供预览：<http://127.0.0.1:4173/>。只监听本机，不发布到公网。若已有此端口的文档预览服务，直接复用，不要重复启动。

文字或目录修改后，重新生成并刷新浏览器：

```sh
pnpm docs:build
```

无需安装新的网页框架或依赖。JavaScript 用于切换文章、搜索、主题和移动端目录；全部正文已生成在 HTML 中，关闭 JavaScript 仍可按顺序阅读。主题偏好只保存在本机，不上传数据。

## 内容在哪里维护

- `docs/feature-inventory.md`：功能盘点、标题、入口与支持边界。
- `docs/manual/navigation.mjs`：四部分顺序、组内目录、概览页正文。
- `docs/manual/topics.mjs`：各主题的介绍、操作、结果、注意事项和相关链接。
- `docs/manual/build.mjs`：生成器；不要手动修改生成后的 `docs/index.html`。
- `docs/assets/manual.css`：文档布局、浅色与深色主题、移动端排版。
- `docs/assets/manual-state.js`、`manual.js`：搜索、文章路由和交互。

一个主题可以在多个相关目录中链接，但只有一篇正文。每个主题使用稳定地址，例如 `/#b07`（正文重写）、`/#d10`（后台人物设计）；浏览器前进、后退和直接打开链接都使用这些地址。搜索支持正文关键词，以及多个空格分隔的关键词。

## 验证

```sh
pnpm test:docs
```

检查生成结果一致、四部分顺序、100 个主题覆盖、静态资源和锚点、无旧截图、默认关闭的功能边界、搜索与路由规则，以及旧宣传页的保留情况。这些自动检查不等于浏览器视觉验收或实际游戏能力验收。
