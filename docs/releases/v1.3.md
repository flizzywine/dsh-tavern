## 主要更新

### 新增场景文生图

- 可以根据当前剧情手动生成插图：由文字 Agent 结合正文、人物设计和已有画面资料整理画面，再交给所选生图模型生成图片。
- 支持 Grok、OpenAI Images 及兼容中转、Google Gemini、Gemini 聊天兼容中转、NovelAI、Seedream、Qwen-Image，以及自建 SD WebUI / Forge、ComfyUI 渠道。不同渠道的参数和能力按各自协议适配，不保证任意中转通用。
- 生图模块基于 `shanliuling/dsh-image-gen` 维护版本内置，无需另外安装插件；渠道、API Key、模型、画面比例与风格在 Tavern 设置中统一配置。
- 提供只读连接与鉴权检查，以及支持渠道的模型列表获取。测试连接不会试画、不调用生图接口；鉴权通过不代表已验证出图权限或余额。
- 支持风格预设、补充绘图描述，以及直接重画或带意见重画。复用已有画面方案，减少重复整理人物资料。
- 画面方案按人物、场景分步提交，减少超长参数出错；校验失败时反馈具体错误位置，每个任务最多允许 3 次修正。这不等于自动重试付费生图。
- 后台会等待图片生成并保存后再确认成功；失败时保留服务返回的错误原因，并隐藏密钥等敏感信息，方便定位问题。
- 图片与对应正文版本绑定，保留生成版本；完善失败重试、图片保存恢复与重复请求保护，避免旧任务的图片挂到已替换的正文上。
- **默认关闭，手动开启后使用。** 关闭时保留配置、密钥和已有图片；已有的手动开关状态继续保留。实际生图可能产生供应商费用。

### 新增用户画像

- 卡片 Agent 新增“建立用户画像”起始任务，通过分批提问了解内容偏好、叙事风格、互动方式和不希望出现的内容。
- 区分问卷记录、分析草案和用户确认的结论；画像须经用户确认后保存，可跨人物卡复用。
- 右侧栏新增用户画像专栏，可查看、修改、手动开启或关闭，并跳转到建立画像的任务继续调整。
- 开启后，将已确认偏好的精简摘要放入新游戏的稳定前缀，不反复注入整份问卷。人物卡设定与本轮明确要求优先于长期偏好。
- 画像修改用于以后新开的游戏，不回写已有游戏的稳定前缀。

## 其他功能

### 长期剧情回忆

- 前台与后台 Agent 都可按需检索当前对话的历史正文，回忆人物、事件、承诺、物品来源和久远伏笔。
- 检索结果包含对应轮次，也可读取指定轮次及附近原文；不跨对话检索，不额外建立向量数据库。
- 历史内容只用于回忆已经发生的细节和剧情，不得当作当前场景重新演绎。未调用工具时，不自动向上下文追加历史正文。

### 可选联网搜索与独立后台模型

- 设置中新增“开启联网搜索”，默认关闭；开启后，前台和后台 Agent 共用联网搜索能力，按任务需要调用。
- 可为后台单独选择模型，供候选项生成、MVU 和姿势结算共用，不必与前台正文模型相同。
- 联网能力与后台模型在新游戏开局时确定，修改设置不影响已有游戏；增加后台模型信息展示，方便确认配置。

## 修复与体验改进

- 修复后台结算失败或重启中断后的恢复流程，为未完成结算提供可重试的失败状态，避免残留“结算中”状态导致无法继续。
- 修复生成过程中点击“回退本轮”干扰后续回退的问题，并在回退失败时恢复原有状态。
- 开场白不再显示正文重新生成按钮，避免触发“没有可重新生成的玩家输入与正文组合”。
- iframe 内文字跟随 DSH 字号设置变化，不对整页做缩放，也不因调整字号重新运行人物卡脚本。
- 修复相关工具 Schema 适配、只读密钥复用与配置保存问题，完善生图配置未完成时的提示。
- 合并生图模型选择和手动填写入口，精简图片操作区，保留可带意见的“重画”。
- 补齐更新器测试的网络隔离和生图界面测试数据，消除原有测试失败。

## 升级提示

- 更新后重启 Tavern 并刷新浏览器页面，以加载新的后端和界面代码。
- 旧生图配置如提示待迁移，请在设置中检查后点击“保存并启用”；迁移和保存本身不会生成图片。
- 部分非开场白场景下的“没有可重新生成的玩家输入与正文组合”仍在排查，已补充配对过程的结构化诊断日志。若再次遇到，请在报错后导出诊断包协助定位。
- 本版开放的是场景文生图及相关配置，不包含“联网调查后自动写入世界书”的后台研究功能。
