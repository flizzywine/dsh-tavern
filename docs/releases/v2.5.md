# DSH Tavern v2.5 变更记录

从 **v2.4 到 v2.5 共 430 个提交**，其中包含 15 个合并提交和 109 个自动 runtime manifest 提交。统计范围为 `v2.4..b4848ab8`，详见[完整提交清单](v2.5-commits.md)。v2.5 于 10 月 5 日晚重新发布到最新提交，新增内容见下方「重新发布新增」。

**这一版重点改善日常游玩、人物卡兼容和安装更新。**

Guide 可以保存成方案反复使用，世界书支持全局启用。改人物卡的工具和 Skill 全部重做：卡片当文件直接改，工具只做格式校验，新增问答式新建人物卡，MVU 在原卡上进行；卡片 Agent 获得更完整的本局上下文。MVU 新增变量回灌，前台写正文时能看到上一轮变化的变量，转换时能保留更多原卡的状态栏与交互。场景配图的 NovelAI 支持大幅增强：提示词控制、多接入点、画师串库和采样参数。手机布局、后台失败恢复和更新流程也有一批修复。

## 重新发布新增（10 月 5 日晚）

**压缩上下文**

- 修复剧情模式手动压缩一点就失败、界面却显示「could not produce a smaller summary」的问题（#148）。压缩失败时，提示里附上真正的原因，不再只显示 DSH 的笼统文案。
- 前台压缩默认提示词改为八段结构化摘要：剧情脉络、人物档案、关系网、世界与设定、物品与资源、伏笔与约定、当前情况、用户意志。自定义过的提示词不受影响。
- 压缩时最近 10 轮剧情保留原文，附在摘要之后；连续多次压缩也始终保留最近 10 轮。保留的原文最多占模型窗口的 25%，轮次很长时少留几轮；不足 10 轮时提示无需压缩。
- 预设前段改为写入对话轨迹。用了预设的对局，压缩请求的开头和前台请求一致，可以命中服务商的前缀缓存；切换预设后，旧预设不会残留。「请求上下文」界面仍会单独标出预设前段。
- 修复两个模型请求钩子互相转发、直到内存耗尽的问题（#146）。模型请求日志只保留最近 30 轮原文，写盘不再阻塞模型请求。

**卡片工作台**

- 去掉「挂载」概念：像改代码一样，可以按路径直接修改任意人物卡；@ 某张卡只表示这条消息要处理它。
- 不再预置「你是工作台助手」的假对话和开场欢迎语；「卡片 Agent 系统指令」默认留空，入口保留。

**游玩台账**

- 恢复游玩台账，改为玩家手动整理的备忘录：标题旁常驻「更新游玩台账」按钮，只在点击时调用后台模型，内容不进入后续游玩。

**界面与显示**

- 状态面板新增「放大」按钮，整页全屏显示，上方独立顶栏放「退出大屏」，不遮挡卡片自带的按钮。
- 已选定的深浅配色优先于跟随系统，手机锁屏回来不再被翻成深色。
- 状态栏运行诊断合并写入，不再每秒改写对话存档；预设列表按文件内容缓存解析结果。

**安装与更新**

- 应用内更新不再永久卡在「等待安全停止」：残留的安装锁和遗留的「进行中」记录，会按安装时的同一规则自动解除，转为可修复安装。
- 安装和更新的最后一步会核对运行依赖是否装全，缺包时判定失败并回滚。
- Windows：作业宿主按 PATHEXT 解析命令，修复 Desktop 下 `node` 报 ENOENT；启动失败时也会回应停止请求，不再锁死安装目录。DSH Tavern 使用独立的应用 ID（Setup7）。
- 插件安装改为复用宿主自带的 Web 组件（#152）。

新增的[项目范围说明](../scope.md)写明了做什么、不做什么：此后以维护人物卡可玩性为重心，固定在已适配的 DSH 版本上。

## Guide 与全局默认设置

- 新增独立 Guide 库：将本局指引保存为一份方案，在其他游戏中选择加载；支持方案重命名和逐条编辑。
- Guide 区域提供长期偏好与人物卡入口，方便将跨游戏的个人喜好、故事专属设定分别放到对应位置。
- 统一使用 Guide 名称。除正文和候选项外，MVU 后台变量结算也会参考本局 Guide，例如“好感度涨得慢一点”。
- 新增开局默认设置，可预先配置玩家称呼、状态栏位置、后台结算及联网搜索、场景配图开关。
- 新增卡片工作台默认模型，可与前台、后台模型分别设置。
- 新增全局隐藏上下文注入和思考过程的显示设置；长期偏好面板简化展示。

## 改人物卡：工具与 Skill 重做

- 改卡思路改为“卡片当代码文件改”：卡片 Agent 直接编辑卡片，工具只负责格式校验，不再限制改法。原来的草稿、转换、外观设计等专用工具，以及外部定义存储和整卡指纹全部移除。
- 卡片校验新增 MVU 格式检查：各开场 initvar 能否解析、字段是否一致、`[mvu_update]` 规则、状态入口与面板正则、面板脚本语法、面板引用路径、`$` 替换陷阱，报告出错位置与修法，不执行卡片脚本。
- MVU 在原卡上进行：新建卡直接启用 MVU，转换不再生成底卡和副本两张卡；变量初值、更新规则和面板直接从卡片文本读取，任何手改都合法，卡片拷到别处也能继续编辑。面板可自由使用样式和脚本，并提供可直接改的面板模板。
- 新增「新建人物卡」问答任务（create-card Skill）：逐题确认角色、玩家身份、世界与开场，可选 MVU 与前端美化，确认后创建并校验；对话中的 HTML 代码块显示为静态草图预览。
- edit-card、card-to-mvu Skill 按新方式重写，写明卡片文件结构，模型不必先探索格式。
- 世界书工具接受 `keys`、`key`、`disable` 等 SillyTavern 常用写法，未知字段明确报错，不再静默丢弃关键词。

## 世界书、人物设计与卡片管理

- 独立世界书支持“全局生效”，开局时与人物卡绑定的世界书一起加载，方便跨卡复用公共设定。
- 世界书库新增搜索，简化为最新／最早排序；新增分步召回说明，解释常驻条目、关键词触发与生效时机。
- 后台人物设计写入世界书库并同步当前游戏，后续出场可以按关键词召回。已有的人物设定优先复用，避免重复创建同名档案。
- 人物设计发布保留其他条目、用户修改的正文及触发设置；保存校验失败会显示具体错误。
- 酒馆状态面板增加本局人物卡和世界书详情入口；记忆面板可在不同对话中查看、编辑对应人物卡的记忆。
- 删除人物卡时可选择是否一并删除游玩记录；批量删除会逐卡显示关联记录数量。

## 卡片 Agent 与稳定上下文

- 人物卡自带系统指令放入稳定的会话上下文，减少被混入每轮动态内容的情况。
- 绑定人物卡的新卡片 Agent 会话会获得人物卡基本信息、系统指令和常驻世界书参考；开启长期偏好时，将已确认的偏好作为系统上下文提供。
- 修复控制面板中的提示词覆盖未应用到卡片 Agent 的问题；停用新改卡会话沿用前台角色人格的实验，统一使用卡片 Agent。
- 自助调试 Agent 可以读取更完整的实际游玩上下文，便于排查正文、变量、世界书和显示问题。
- 卡片 Agent 修改世界书等资源后，右侧资源库自动刷新；修复开启长期偏好时发送空用户消息的问题。
- 前台会话首次提供可查询的变量目录，帮助 Agent 找到变量路径；动态变量值仍通过工具按需读取。

## MVU 转换与变量结算

- **变量回灌**：每轮回复前把上一轮变化的变量最新值提供给前台，减少正文里时间、地点、数值与状态栏前后不一致；可在开局默认设置和本局设置中关闭。
- 脚本型原状态栏新增协议适配：变量按原卡需要的文本协议供给原视图，保留原有布局、栏目和交互，无需一律改成基础面板。
- 原状态栏更新后保留玩家所在分页；修复面板变量已更新但显示未自动刷新的问题。
- 转换时只移除候选项相关内容，保留手机、开场主页等无关美化与脚本，避免转换后丢失原卡功能。
- 转换生成的 MVU 卡关闭“值＋描述”两项数组约定，列表整体替换按 JSON Patch 语义执行，修复列表被套进第一项、字段错位和类型错误。
- 变量提交增加字段及列表元素的形状校验；不符合原结构时反馈给后台 Agent 修正，避免错误数据直接进入状态栏。
- 后台结算期间的卡内脚本变量写入纳入当前结算；酒馆负责结算时，卡内官方 MVU 不再自行发起额外模型解析。
- 修复基础面板使用根路径字段时的删除、提交错误，以及编辑正文后重试结算使用过期轮次的问题。

## 酒馆助手脚本与开场兼容

- 补全一批 Tavern Helper 接口，包括消息负索引和筛选、变量读取与删除、消息／iframe 标识、可见脚本按钮查询及错误处理。
- 改善 `generate`、`generateRaw` 的上下文、取消和事件适配。卡内文本生成可使用实际角色、预设、世界书与历史，取消或退出后会清理对应请求。
- 补全正则格式化、Markdown 显示、单消息刷新、只读宏及消息 iframe 的事件和初始化等待接口。
- 受信任卡片脚本可通过 `retrieveDisplayedMessage` 和消息渲染事件改写已显示的正文，支持依赖消息显示层的美化；显示改写不自动覆盖保存的正文。
- 共享脚本与消息 iframe 支持有边界的 `/pass`、`/return`、`/findentry` 等只读命令管道；不支持的命令明确报错，避免请求一直挂起。
- 开局准备页将以 `/trigger` 结束的有效管道作为开局操作，支持 `/send`、`/sys` 等组合；`/pass`、`/echo` 直接应答，不再误触发开局。
- 修复开场页面重写文档后输入控件丢失、开场插件设置未正确保留，以及模板字符串中的 jsDelivr 地址被错误截断的问题。
- 正则规则尊重 `disabled: true` 和 `enabled: false`；明确重载资源时刷新普通显示缓存，避免禁用规则后旧显示仍残留。
- 修复部分状态栏（如临江 HUD）整块隐藏只剩黑底、嵌入模式下面板被截断，以及刷新状态面板后黑屏的问题。
- 支持 `{{roll: d8}}` 等酒馆骰子写法，关键词触发的世界书条目中的骰子宏也会掷出。

这些是针对酒馆助手接口和人物卡脚本的兼容改进，不代表完整复刻 SillyTavern。模拟流式事件在全文生成完成后发出；依赖顶层 `#chat` 等私有页面结构的脚本仍可能需要适配。具体范围见 [Tavern Helper API 兼容说明](../tavern-helper-api-coverage.md) 和 [命令兼容说明](../slash-command-compatibility.md)。

## 场景配图：NovelAI 支持增强

- NovelAI 新增正面提示词、官方质量与负面预设、段落顺序与权重、固定种子；设计来自 PR #140（感谢 @zeaggx-collab）。
- NovelAI 支持多个接入点（官方站与自定义渠道各存一份 Key）、命名画师串库（可附质量词、负面词和预览图）及采样器、噪声表等参数；账号已有生成在进行（429）时自动退避重试。
- 生图 Agent 从整段正文挑最有画面感的一幕，不再固定画结尾；按构图自动选择横图、竖图或方图，并可为每张图追加专属负面标签。
- 生图设置按服务、模型与画面、画师串、提示词、生成参数分区，窄屏单列显示。

## 界面与手机体验

- 统一右侧页面、全局设置、酒馆状态和变量回执的排版，简化次要操作；侧栏、首页、浏览器标题和图标统一使用 DSH Tavern 品牌。
- 新增“无玻璃”材质并设为默认，透明度默认归零，减少背景滤镜开销；全局写作 Skill 列表默认折叠。
- 改善手机聊天控件、软键盘视口和向上展开的菜单，修复输入区裁切操作菜单的问题。
- 开局准备页控制在一屏内，长开场预览内部滚动，开始游戏按钮始终可见。
- 用户气泡、AI 正文和前端美化内容跟随字体大小设置，修复手机端正文未同步字号的问题。
- 修复人物卡浮层跨会话残留、全屏结束后控件不同步、侧栏固定状态面板仍留下正文占位按钮，以及隐藏首个历史楼层时分页入口消失的问题。
- 修复嵌入面板不断变高和指定尺寸下内容溢出被裁切的问题。
- Tavern 陶土皮肤跟随原生深浅偏好，深色用户不再每次启动被按回浅色（PR #143，感谢 @TwilightRainDev）。

## 失败恢复与会话同步

- 模型拒绝回答或内容审核拦截时给出更明确的提示，帮助区分模型响应和酒馆运行错误；被拦截后可撤回输入或回退上一轮。
- 修复正文生成中途报错后会话停止刷新的问题；生成尚未完成时，回退菜单提示等待完成。
- 修复后台会话重建后未重新注册工具、首次后台模型失败后无法正确回退重试的问题。
- 前台提交在保存时原子读取最新模板输入，修复连续快速发送时的模板并发冲突；时间线时间戳不再让原本可兼容的并发写入互相冲突。
- 统一客户端会话读取、重试和退出清理，避免旧请求、迟到错误或超时结果覆盖新会话状态，改善切换会话和重新连接后的刷新。
- 分叉按钮根据会话事件实时判断可用位置，避免视图缓存过期后入口状态不准确。

## 性能与内部维护

- 世界书条目、预设编辑器、人物设计详情和请求上下文按展开情况加载；隐藏资源库页签延后刷新。
- 缓存世界书目录摘要，卡片缩略图不再携带整张人物卡数据并支持 ETag，减少资源列表的重复读取与传输。
- 复用未变化的卡片列表和历史投影，减少每轮结算后的完整会话列表刷新、子代理目录重复请求及侧栏重绘。
- 合并共享主题监听，减少纯文字、颜色和动画变化触发的字体重测与高度扫描；内容测高采用一次自顶向下遍历。
- 拆分客户端功能模块及服务端工具、路由和生命周期逻辑，整理文档与验证工具，并精简重复测试。

这些改动减少界面与系统处理开销；模型生成速度仍取决于模型、上下文和网络，本记录不承诺固定耗时或帧率。

## 安装与更新

- Windows 安装包支持系统代理下载，统一下载重试与停滞检测；失败提示显示具体安装步骤和原因，升级日志保持纯文本。
- Windows 包管理改用 Desktop 自带 Electron 和 pnpm，减少单独下载 Node 的步骤；修复 Unicode 快捷方式、非 ASCII 安装路径及旧安装脚本缺少辅助文件的问题。
- 更新流程统一管理安装任务和子进程，处理超时、取消与中断恢复；取消或强制结束后由更新器完成回滚。
- 命令行版先在暂存目录完成新版本安装，最后切换；切换前记录恢复信息，减少安装失败破坏原有程序的风险。
- 下载清单必须与请求的提交一致；更新时清理新版本不再提供的旧程序文件。发布清单后自动刷新 jsDelivr 安装入口缓存。
- 更新检查允许单个来源暂时不可达，并使用备用来源；采用 CDN 结果时提示可能存在缓存延迟。
- 未安装 `dsh-web-mobile` 的宿主跳过对应补丁，修复 `ERR_PNPM_UNUSED_PATCH` 安装失败。
- 分阶段安装不再卡在 pnpm 的 `node_modules` 清理确认；安装步骤不再等待控制台输入，交互提示会立即报错而不是静默挂起（#141）。
- 支持 pnpm env 等版本管理器安装的 Node，修复「无法定位 npm CLI 包」（#142）。
- 残留安装锁自动回收，Ctrl+C 中断后可在同一窗口立即重装；Windows 下安装锁的瞬时占用错误会重试。
- 服务启动等待上限由 30 秒放宽到 120 秒，首次启动较慢时提示仍在初始化。

## 更新说明与验证范围

- DSH 核心仍固定为 `0.1.5-rc.2`，推荐 Desktop `2.0.13`；更新后重启服务并刷新页面。
- 实验性的 silly 模式已停用；人物卡、世界书、正则和脚本兼容继续在 DSH 游玩模式中提供。SillyTavern 插件不能直接安装，DSH 插件仍可按各自要求使用。
