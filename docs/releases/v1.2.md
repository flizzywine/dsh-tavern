## 主要更新

### 更省 Token，更高缓存命中率

- 重构前台、后台与卡片 Agent 的上下文注入：稳定内容固定在前缀，每轮只追加必要的任务信息。
- 人物卡、世界书、玩家信息等长期内容不再每轮重复注入；高级能力改为按需加载。
- 精简 MVU 变量结算输出，移除无用分析文本，减少后台 Token 消耗。

### 后台任务统一使用工具提交

- 候选项生成、MVU 变量结算等后台任务改为结构化工具调用，不再依赖模型手写 JSON 或特殊文本格式。
- 工具提供格式校验与明确回执，失败后可以针对错误修正重试。
- 后台 Agent 保持稳定前缀和完整工具目录，切换任务时不再反复更换系统提示词。

### 新增“人物卡转 MVU”

- 卡片模式新增“把人物卡转成 MVU 版”起始任务，可直接选择人物卡并启动转换 Skill。
- 将容易掉格式的正文状态栏转换为独立 MVU 状态栏，状态栏不再依赖模型每轮正确输出格式。
- 转换时会移除人物卡自带的候选项输出，避免与 DSH Tavern 的候选项功能重复。

### 新增后台人物设计

- 后台 Agent 可以按需加载人物设计 Skill，为即将登场、可能登场或需要补全的重要人物建立完整设计；优先复用已有角色，避免无意义地批量创建人物。
- 人物档案按姓名保存在当前对话中，同一张人物卡的新对话可以形成不同的人物设计，不会互相污染。
- 设计会结合人物卡的 MVU 变量模板，完整覆盖身份、性格、外貌、行为与说话风格、关系、默认形象和剧情潜力等信息，再映射为符合当前卡结构的变量；必填字段不再保留“未明确”等占位值。
- 人物设计只服务于后台结算和状态展示，不注入前台正文 Agent，避免额外上下文限制文字生成。

### 重构正文重新生成

- 取消多 Swipe 剧情分支；保留“一键重新生成正文”和“带意见重新生成正文”。
- 前台正文与后台状态结算现在组成一个完整 Round：上一轮未完成前，不能开始下一轮、重新生成或回退。
- 重新生成会同时重做正文和后台结算；全部成功后才整体替换最后一轮，失败时继续保留旧正文和旧状态。
- 修复重复结算、正文替换错位、模型上下文缺失以及前后台结果乱序等并发问题。

## 兼容性与体验改进

- 扩充 Tavern Helper 宿主能力，完善普通人物卡脚本、插件设置、世界书读写和对话插件数据持久化。
- 修复 MVU 在服务重启后未就绪、结算无法接续、状态栏不刷新和旧后台 Session 工具协议残留等问题。
- 改善 iPhone 等移动端的人物卡 iframe 滚动，恢复内外两层自然滚动。
- 更新检查优先使用 jsDelivr，并保留 GitHub Code 下载路径，改善国内网络下的安装与更新体验。
- 日志导出现在同时包含 Session、MVU 执行与兼容性诊断，方便定位人物卡和后台任务问题。

## 架构与稳定性

本版大幅重构了剧情时间线、前后台协调、候选任务、会话初始化、人物卡脚本生命周期、预设库、启动与更新流程。Story Timeline 成为唯一剧情权威，前台 Session、后台 Agent、状态栏和界面只作为执行者或投影，减少多份状态互相覆盖造成的随机故障。

文生图功能仍在开发中，本版不开放入口。
