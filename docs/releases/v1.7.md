# v1.7 发布记录

发布日期：2026-09-12。以下为 v1.6 以来的主要变更。功能提交整理范围为 `v1.6`（提交 `b9ecaa0`）至 `21a0941`，另包含本次版本号与发布文档更新。

本次主要新增多世界书绑定、自动上下文压缩、人物卡批量删除和安卓内嵌窗口；优化后台结算调用，补齐交互式开场与脚本兼容，并改善生图、安装和故障排查。

## 人物卡可以绑定多本世界书

- 已绑定的世界书按顺序列出，点击书名打开；列表下方通过“＋ 新增绑定”继续添加，不替换已有绑定。
- 支持上下移动、逐本解绑；同一本世界书可以被多张人物卡复用。
- 新开局将各本书合并为本局快照，第一本作为主书。附加条目编号冲突时重新编号；本局脚本修改不写回源书，已有快照不随绑定变化。
- 导出人物卡包含合并后的世界书条目；资源重命名、删除会同步处理绑定引用。
- 修复普通无脚本卡开局未保存世界书快照，以及直接输入第一轮时漏掉开场关键词召回的问题。

多本世界书可能相互冲突，引发异常。系统不自动协调设定或变量初值冲突；写死附加书名称或冲突编号的脚本可能不兼容。

## 支持自动上下文压缩

- 默认仍为手动压缩；可在设置中选择“每 N 轮”或“上下文达到 X%”自动压缩。
- 自动压缩等待本轮后台结算结束，再联合整理前台与剧情后台。已提交的玩家消息保留，无需重发。
- 重写同一轮、候选生成、工具调用和生图不重复计入剧情轮数；生图、手机、卡片工作台不跟随剧情联合压缩。
- 部分失败时可只重试失败的一侧；修复隔离 Agent 环境下压缩预设的解析问题。

固定故事背景与原始记录保留，但压缩摘要可能遗漏细节，不等于无损记忆或备份。

## 后台结算减少多余工作

- 姿势与变量提交不再强制先后顺序，允许模型在同一次回复中完成两个独立工具调用。
- 临时后台任务完成所需提交后直接结束，避免额外请求模型确认“已完成”。
- 工具使用约定集中放入工具自身说明，减少任务提示中的重复协议；数值不确定时允许符合规则的合理估计，不要求反复追求精确。
- 人物设计默认关闭；后台工作开关及联网偏好可在后续任务边界应用到已有游戏。
- 可以从对话控制区手动停止后台工作；修复非 MVU 结算、候选任务的后台会话绑定，以及候选面板重新挂载后的状态同步。
- 退出自动玩家台账实验，移除自动工具与任务，保留已有记录。

这些调整旨在减少多余步骤，不承诺所有卡片都达到固定的 token 降幅。相关 Flash 对照与连续游玩记录见 `docs/experiments/`。

## 交互式开场与人物卡兼容

- 准备页支持更多依赖 Tavern Helper、MVU、EJS 的交互式向导与旧式开局提交，开局时保留准备阶段填写的变量。
- 交互式卡片可使用更大的开场预览；关闭预览时清理脚本弹窗。开始失败时显示具体初始化阶段。
- 修复卡片替换整个 HTML 文档后 RPC 监听丢失、脚本被 JavaScript 代码围栏包裹后无法执行等问题。
- 补充旧式按钮事件、世界书排序调用、角色名称与正则权限等宿主适配，改善依赖宿主 jQuery／jQuery UI 的浮窗组件。
- 限制 MVU 初始化提示等待时间，批量保存排队提示，避免初始化长时间阻塞；媒体下载不再拖住开场脚本准备。
- 修复 Google 工具声明中的 MVU 操作类型，以及缺少早期变量快照时当前楼层基线恢复的问题。

以上是已处理的兼容路径，不代表任意第三方卡片或插件都能完整运行。

## 卡片管理与阅读体验

- 游玩历史按人物卡分组；人物卡库和选择器支持批量删除。
- 卡片工作台保存修改后增加校验，新保存的绑定及时反映到侧栏。
- 损坏或不可读的人物卡不再拖垮整个资源库与历史列表；保留在工作台修复的入口。
- 正文颜色可在设置中选择，保持 Markdown 渲染方式；修复通用剧情标签包裹后段落丢失、文本围栏中的完整 HTML 文档显示等问题。
- 改善卡片面板独立性、固定 iframe 状态和高度约束；修复开场 Markdown 链接影响侧栏的问题。
- 世界书支持搜索条目，并区分实际生效的设置与仅保留的兼容字段。
- 模型错误提示更简洁，可按对话关闭；调整系统提示词列表和人物卡导入区域的间距。

## 生图改进

- 生图 Agent 的 system 增加开局人物卡、常驻世界书和已确认长期偏好，保留独立生图职责。历史配图仍以目标轮次材料为准，不注入最新动态世界书。
- 增加可关闭的大图预览，避免正文展示投影影响场景图片。
- 开放渠道支持的更多生图参数与高级设置，并修复能力信息重建问题；具体可用参数取决于渠道。
- 放宽 ComfyUI 配置请求大小限制；服务返回空 base64 时可以回退读取图片 URL。

## 安装、安卓与诊断

- CLI 使用独立的 DSH 运行环境与数据目录，复用健康且版本匹配的私有运行时；支持选择安装目录。
- 安装时检查宿主 DSH 版本是否匹配，完善固定版本、安卓安装与更新说明；修复 pnpm 11 国内源配置及 Git worktree 更新器的版本识别。
- 安卓支持通过带鉴权的内嵌窗口打开 Tavern。
- 诊断导出增加人物卡脚本、世界书、生图操作阶段及有界性能摘要；模块依赖加载失败时提供更明确的提示并保留网络诊断。
- 静态资源下载取消本机／私网地址及 DNS 私网解析拦截，改善代理 Fake-IP 和私网资源兼容性。此变更扩大了服务端可访问地址范围，并非只豁免某个代理网段；HTTPS 与 URL 凭据限制仍保留。
