# DSH Tavern v3.1 变更记录

从 **v3.0 到 v3.1 共 851 个提交**，其中 216 个是自动生成的运行时清单提交，20 个是合并提交，其余 615 个是功能与修复。统计范围为 `v3.0..b2aba8c7`，详见[完整提交清单](v3.1-commits.md)。发布打包提交（APK 版本号与本文档）不计入统计。

**这一版重点：文风联想、分卷剧情压缩，以及长存档与重新生成的稳定性；Android 同时正式提供内置 3.1 源码快照的独立 APK。**

## 支持范围调整

- 桌面端只支持官方 **DeepSeek Harness**，不再支持社区版与 DSH NEXT。
- Android 统一提供独立 APK 安装入口。
- 使用 DSH 0.1.5 的用户继续使用 `stable` 分支；当前版本的安装与应用内更新跟随 `main`。

## Android 独立 APK

- 本次随版本重新打包 3.1 APK：`versionName 3.1.0`、`versionCode 30100`，内置酒馆 3.1 源码快照、pnpm 依赖与 pnpm 运行时，覆盖安装旧包即可，不要卸载以免丢数据。
- 签名与此前的独立 APK 相同，可直接覆盖升级 3.0.1 包；同包名的旧版 v2.1（DSH 0.1.5）签名不同，仍需先导出存档与人物卡再导入。
- 下载 [dsh-tavern-android-release.apk](https://github.com/flizzywine/dsh-tavern/releases/download/v3.1/dsh-tavern-android-release.apk)，SHA-256 见同目录的 `dsh-tavern-android-release.apk.sha256`。

## 文风联想

- 新增文风联想：每轮正文完成后，后台根据人物卡、长期偏好和当前场景，提供一段约 100～300 字的范文，供下一轮写作参考。
- 不限名家名作，可按题材参考轻小说、网络小说等作品；范文不要求是原文，有对应作品时附上书名和作者。
- 新游戏默认开启，可在全局默认设置或本局设置中关闭。
- 在酒馆状态中查看范文，支持「换一段」，也可以填写选段要求。
- 选段提示词放入系统提示词管理，可自行修改。
- 修复重新生成时使用错误轮次的参考，以及会话尚未加载时换选失败的问题。
- 修复长状态栏挤掉正文的问题：先清理明确的状态面板和变量协议，再截取正文首尾用于联想。

## 剧情压缩与记忆检索

- 剧情摘要改为分卷保存，生成新卷时保留旧卷，避免同一段剧情被反复压缩。
- 旧卷超过预算时，只合并最老的几卷为前情总览，较新的卷保持原样。
- 调整摘要提示词，按事件保留关键条件、数值变化、细节和必要原话，并提示模型按轮次回查原文。
- 记忆检索结果列出各关键词命中的轮次，摘录围绕命中位置展开。
- 导入的聊天记录不必先续玩，即可压缩上下文；未打开的游戏也能恢复会话后压缩。
- 修复 DSH 0.2 上剧情压缩提示词未生效、「正文走工具调用」导致压缩失败，以及模板同步改写压缩检查点的问题。

## 长存档性能

- 打开长存档时按窗口加载历史，不再自动一路加载到开头。
- 优化回合准备、后台任务、世界书更新、模板同步和插件通知，减少读取、复制和写入整份历史。
- 玩家发送新输入时，取消尚未完成的文风联想与世界书预筛，优先处理当前回合。
- 模板显示同步在回合与后台任务进行期间暂缓，减少与正文生成争用。
- 存档整理延后到本局空闲 10 分钟后执行，减少对下一轮的阻塞。
- 新开局减少世界书副本和重复投影；复用未变化的提示词、脚本解析结果及模板资源。

## 重新生成、编辑与回退

- 重新生成统一为一个入口：不填意见重新生成，填写意见则在当前正文基础上改写。
- 最后一条玩家输入支持直接编辑；失败轮保留输入，可原地修改后重试或撤回。
- 玩家消息增加分叉入口。
- 修复重新生成后正文空白、整轮消失、旧正文与新正文并排，以及连续重新生成后旧副本堆积的问题。
- 修复重新生成误裁前面的历史、回合编号跳号，以及生成期间玩家输入被隐藏的问题。
- 修复变量结算把已处理正文换回模型原文，进而导致重复回复的问题。
- 修复带工具调用的轮次无法撤销回退，以及回退、编辑后撤销入口消失的问题。
- 编辑正文或重新结算时，可以中止正在进行的下一轮预备，不再直接拒绝操作。
- 过期的重试错误合并显示，支持统一隐藏；恢复正文底部的复制按钮。

## 配图与画廊

- 场景配图改由随附的 `dsh-tavern-image` 插件提供，本次随附版本为 **3.0.2**。
- 生图插件接入 Tavern 的统一插图卡，进度、取消和失败信息直接显示在正文中。
- 重画可选择沿用提示词，或根据玩家意见重新整理提示词再画。
- 配图设置增加总开关，在线服务与本地部署分开排列，外观跟随 DSH 主题。
- NovelAI 渠道新增对话格式支持。
- 画廊按游戏分组，统一展示插件图片和早期 Tavern 原生插图。
- 生图插件增加整包数据导入导出，优化角色服装编辑；空角色库备份不会直接清空现有角色库。
- 修复取消生图后任务卡住、重复显示重试入口，以及切换游戏时误删其他游戏图片的问题。
- 保留旧插图的查看能力，清理已删除游戏遗留的部分插图记录。

## 预设、人物卡与世界书

- 酒馆预设、系统提示词和长期偏好合并到「预设」标签页。
- 系统提示词支持多套方案，可切换和删除，切换后全局生效。
- 支持将酒馆预设、系统提示词方案和长期偏好组合导入导出，导出时可选择内容。
- 人物卡统一使用一个导出入口：有角色素材时导出 CHARX，有封面时导出 PNG，否则导出 JSON。
- 人物卡封面可通过卡片工作台工具制作。
- 顶栏世界书按钮改为快捷面板。
- 进行中的游戏默认在下一轮自动采用世界书库内的改动，可在设置中关闭。
- 酒馆状态增加当前楼层的 MVU 变量编辑器。
- 修复无开场白人物卡无法开局，以及卡片脚本写回世界书时不接受字符串条目编号的问题。

## 显示与手机操作

- 新增「正文排版」设置，可调整字号、行间距和字间距；玩家消息与角色正文统一跟随正文字号。
- 新增 HTML 渲染深度设置，限制同时渲染人物卡界面的历史轮数，减轻长对话负担。
- 顶栏快捷入口可自定义；手机顶栏最多显示 3 个快捷入口，其余收进菜单。
- 修复手机顶栏按钮消失、右侧栏被输入区遮挡和内嵌页面右侧留白的问题。
- 支持从手机右缘向左滑动打开右侧栏。
- 修复卡片脚本聚焦隐藏输入框时意外弹出键盘，以及原生选项无法填入 DSH 输入框的问题。
- 工具调用生成的长正文完成后停留在开头，方便阅读。
- 修复卡片脚本接管正文、或正文走内联 HTML 渲染时引号失去高亮的问题。
- 修复正则深度限制未按各楼层生效，以及预设显示正则未进入模板渲染路径的问题。

## 存档与恢复

- 存档包升级为第 2 版，按内容去重回退历史，减少长局导出体积。
- 导出时将场景图片转换为 WebP，进一步减小存档包。
- 存档包上限提高到压缩后 256 MB、解压后 1 GB；超限时显示各部分占用。
- 启动时找回磁盘上存在、但索引中遗漏的存档。
- 修复重复回合号、中断压缩和回合结束后追加回复造成的部分会话日志损坏。
- 改善旧存档升级兼容性，允许跳过无法升级的后台会话与回退快照。
- 升级失败时可导出诊断文件；日志结构诊断会去除正文，便于反馈问题。

## 插件安装与开发接口

- 设置中支持粘贴 GitHub 地址安装酒馆插件，也可上传 ZIP 安装。
- 支持检查更新、启用和停用插件，并提示需要刷新或重启的操作。
- 插件页可只读查看已安装的旧版 Profile 插件。
- 新增插件级数据读写接口，保存不属于某一局的配置。
- 浏览器接口第 4 版新增历史插图查询和游戏名称查询。
- 第 5 版新增 `registerIllustrator`，让生图插件使用 Tavern 的统一配图界面；插图卡自定义操作支持确认提示。
- 修复插件首次并发安装、备份重名，以及旧新包名迁移时重复安装的问题。
- 更新插件开发文档与发布规范。

## 安装与更新

- 源码按运行清单增量下载，复用已有依赖和下载缓存；锁文件及依赖补丁未变化时跳过重复安装。
- 侧栏展示实际更新阶段，以及依赖安装的已装、复用和下载计数。
- 下载增加超时处理，网络停滞时失败并回退。
- 桌面安装自动创建一次酒馆快捷方式；快捷方式可直接打开已处于酒馆模式的官方桌面。
- Windows 切换 Profile 时自动请求托盘程序正常退出。
- 修复 Windows 目录链接类型错误、旧依赖残留，以及停止进程判断不可靠等安装问题。
- 修复默认端口被占用、陈旧 PID 和多个安装实例之间的启动识别问题。
- Android APK 内置首装依赖；同版本覆盖安装不再重复安装酒馆，中断的安装可在下次启动补齐。
- 新 APK 可用内置快照离线升级旧安装，避免反复联网下载。
- 3.1 APK 内置提交 `b2aba8c7` 的源码快照；覆盖安装后首次启动直接用内置快照离线升级源码，不需要再等一次联网更新。

## 升级说明

- 已安装用户可通过应用内检查更新获取代码更新。
- 社区版与 DSH NEXT 用户需改用官方 DeepSeek Harness。
- 预设显示正则修复适用于新生成的模板展示。旧楼层已保存的模板快照不会自动重跑，以免重复执行人物卡脚本。
- 桌面端在应用内检查更新；Android 下载本页的 3.1 APK 覆盖安装。
- 本次发布包含一个重新打包的 Android APK，桌面端代码与 v3.1 标签一致。
