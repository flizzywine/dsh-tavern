# 剧情导演

在酒馆右侧开一页导演对话。你只需要说出想要的感觉，比如「节奏慢点，矛盾别这么快爆发」。导演结合角色和近期剧情自行编排，将剧情、节奏、文风写成本局 Guide。安排准备好就生效，可以继续聊天调整。

导演根据当前安排每 1–4 轮调用一次本局后台模型复盘。展开「当前 Guide」可查看在用安排。点「暂停」会停用 Guide 和复盘，之后可以恢复。

## 安装

此插件需要支持 `tavern.guideSource` 的 Tavern。把本目录打成 ZIP，在「设置 → DSH Tavern → 插件」选择「上传 ZIP」，按面板提示刷新或重启。进入任意游玩对话，打开右侧「＋ → 插件 → 剧情导演」。
