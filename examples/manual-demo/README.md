# 灯塔小镇：文档公开演示素材

这里的人物、故事、世界书、预设和剧情大纲为产品文档专门创作，均为虚构，不来源于用户的私人资料或第三方人物卡。素材以 CC0 方式提供，可自由使用、修改与分享。

`resources.mjs` 导出可导入的 V3 人物卡、世界书、预设和剧本。截图使用独立 DSH Profile，不读取个人设置、模型密钥、对话或人物卡。界面由实际 DSH Tavern 渲染，演示正文及状态是预先编写的样例，不代表模型质量测试。

截图基于 DSH 0.1.2-rc.1 / DSH Tavern 1.3.0。重新截图时应记录新的版本与日期；不要复用其他运行环境里的用户数据。

2026-09-03 已按全部 100 个文档主题逐项配图，包括操作入口、编辑表单、后台记录和失败处理。一个界面涉及多个相关主题时共享对应画面；不同操作分别采集，不用一张概览图代替所有功能。截图尽量保留左侧历史、中间对话和右侧面板的上下文。早期截图边缘的翻译悬浮按钮不是 Tavern 功能。

正文生成、候选项、历史检索、变量结算、人物档案和插画使用 `model-server.mjs` 的本地预写响应驱动实际应用；没有调用外部文字模型或付费生图服务。图片中的 DEMO 是 `image-fixture.mjs` 生成的原创几何图，不是真实模型出图质量样本。未发送的修改请求明确标为草稿。截图采用无报错的正常状态；故障处理章节配正常操作入口，异常方法由正文说明，不伪造成功结果。

`character-design.mjs` 提供原创人物档案与对应测试卡；`seed-profile.mjs` 提供虚构偏好及回答，只允许写入独立临时样例目录。不要把这些问答称为真实用户画像。

## 重新采集

1. 创建独立临时 DSH Home/Profile，单独安装当前版本；只导入本目录样例。不要复制私人配置、密钥或历史。
2. 运行 `node examples/manual-demo/model-server.mjs`。服务仅监听 `127.0.0.1:3183`，不会代理到外部供应商。
3. 文字模型使用 `http://127.0.0.1:3183/v1`，模型 `lighthouse-demo`，密钥填无效占位值 `demo-not-a-real-key`；前后台均明确选用该模型。先核对地址再发送。
4. 插画演示只用同一本地地址的 OpenAI Images 接口。`POST /__fixture/image/success`、`pending`、`error` 分别模拟完成、等待及失败；其他渠道仅展示设置，不发送请求。
5. 浏览器实际点击、输入和查看工具结果后截图。不得改写 DOM 伪造结果；保存原始浏览器图像，逐张核对内容与图注。完成后关闭演示生图开关。
6. 运行 `node docs/manual/build.mjs` 和 `pnpm run test:docs`，检查 100 个主题无缺图、链接有效。

运行 `node docs/manual/build.mjs` 会把可直接导入的 JSON 和剧情大纲同步生成到 `docs/examples/manual-demo/`；文档首页提供下载。人物卡已内置 MVU 规则，不要直接用独立世界书替换；如需并用，请先在工作台合并条目。

维护位置：`docs/manual/feature-captures.mjs` 逐项维护 100 个主题的图片、说明和尺寸，`screenshots.mjs` 管理通用图片及来源版本；`docs/images/manual/` 保存原始浏览器截图。更新时只操作独立样例环境，不复用个人环境，也不修改 DOM 来伪造运行结果。
