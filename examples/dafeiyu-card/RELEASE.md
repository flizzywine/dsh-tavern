# 大肥鱼 · DSH 人物卡样板

大肥鱼是 DSH 人物卡（`.dshcard`）的样板卡：**一个文件导入就能玩**，不用另装插件、不用手动配素材。它用来展示新卡格式能装下什么，不追求复刻原项目的全部演出。

> **需要 DSH Tavern v3.0 或更高版本**（适配 DSH 0.2.1，安装见 [README 快速开始](https://github.com/flizzywine/dsh-tavern#快速开始)）。稳定版（DSH 0.1.5）不支持 DSH 人物卡，导入会失败。已安装的，先在酒馆里检查更新到最新：较早的版本会把 `.dshcard.png` 当成普通图片人物卡导入，没有插件和素材。

## 怎么玩

1. 安装或更新到 DSH Tavern v3.0 或更高版本（见上）。
2. 人物卡库 → 导入人物卡 → 选 `大肥鱼.dshcard.png`，导入后刷新页面。它带封面，系统和聊天软件里显示成一张图片；转发时请发「原图」或当文件发，被压缩过的图片只剩封面。
3. 第一次用舞台：在「舞台设置 › 基础设置」里打开「对话气泡」和「舞台」（全局开关，默认关闭）。
4. 用大肥鱼开一局，点聊天顶部的「舞台」进入全屏舞台（F12 切换，Esc 打开菜单）。

## 这张卡展示了什么

- **一个文件装下一整套**：人物卡（兼容 Character Card V3）、4 个素材包（人物立绘与表情、背景、背景音乐、音效）、推荐预设和开局设置。卡里没有插件代码：舞台由 Tavern 按卡绑定的素材包来导演和绘制。
- **舞台**：场景背景、按台词情绪变化的全身立绘、场景下方的对白框，逐句翻页、朗读，背景音乐可一键静音。
- **台词标注**：每句台词标出说话人和情绪，正文里显示对应表情的头像。
- **开局即好看**：导入后开新局，默认用卡里带的预设和推荐设置。
