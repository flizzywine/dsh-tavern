# 航空状态栏转 MVU：第一张实卡样本

> 当前结果：导入、初始化、真实后台结算已通过；自动刷新暴露了宿主公共缺陷，尚未完成端到端验收。刷新页面可看到正确变量。暂不将本例固化为 Skill。

## 范围

用户同意以《东淫航空》为参考，去除色情内容，建立独立测试副本「云际航空·MVU测试版」。这是内容净化后的适配实验，不是原卡无损转换，不修改原卡或原有游玩记录，也不在此时编写通用 Skill。

原卡状态输出位于 `post_history_instructions` 的 `stats tickbubble` 区块，要求模型每轮末尾写代码块；没有 Helper 脚本或 MVU 初始化。新样本重写了设定、开场和指令，保留航空场景和普通档案字段，删除色情字段、旧示例、远程媒体和邀请链接。新增航班、乘客安全带、在场人物和任务，用于覆盖变量更新场景；没有推定好感度数值、体力或自动计时公式。

源卡的许可证名称与链接不一致，说明已保留在 creator_notes 中；本样本先供本地验证，不据此宣称取得公开再分发许可。

## 文件与职责

- `card-source.mjs`：可读的初值、规则和卡片组装函数；仅构造对象，不改用户文件。
- `status.html`：固定、只读的状态视图，不加载外部媒体，不生成剧情，不更新变量。
- `card.json`：可导入的 V3 卡，包含内嵌世界书与完整视图，无需旁文件即可使用。
- `../../tests/airline-mvu-example.test.mjs`：导入导出、规则分流、显示/历史隔离、右侧视图提升的回归测试。

修改源后应同步生成 card.json，并运行测试检查两者一致。

## 已确认的转换方法

1. 世界书 `[initvar]` 条目提供初值；禁用普通注入，官方 MVU 仍读取该条目初始化。本样本已在真实新对话验证。
2. 世界书 `[mvu_update]` 条目提供更新规则，由 DSH 分到后台，不进入正文的常驻世界书上下文。
3. 使用官方 MVU 从初值生成的 Schema。本例不需要额外 Zod 库或变量结构脚本；不能把额外脚本当作所有 MVU 卡的必需品。
4. 人物、任务使用 `$meta.extensible` 和模板；固定根字段不开放任意扩展。否则新人物/任务很容易被默认的封闭结构拒绝。
5. 开场白仅含一个状态入口。显示正则将入口替换为固定 HTML，promptOnly 正则将其从模型历史移除；模型不需要每轮输出入口。
6. 视图首次调用 `Mvu.getMvuData()` 后，由现有 Host 提升到右侧持久状态面板。监听 MVU 与消息事件更新，不重复生成模板，不轮询，不写入变量。
7. 状态文本用 `textContent` 写入 DOM，避免正文中的标签成为可执行 HTML。
8. 背景状态来源是本轮正文与当前快照，不是用户打算做什么；无依据的看法保留未知。未知年龄用 0 作数据哨兵，展示为“未明确”，故事角色均为成年人。
