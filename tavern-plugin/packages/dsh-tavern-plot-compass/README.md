# dsh-tavern-plot-compass（剧情罗盘插件）

为 **DSH Tavern** 提供今期 / 中期 / 长期多路线剧情推演、盲盒防剧透、多轮脑暴对话、自动节拍核对、候选项路线角标联动与一键分叉试玩的独立插件。

## 主要功能

- **三跨度多路线规划**：围绕人物卡设定、近期剧情与世界书未触发暗线，推演**今期（2–5 轮）**、**中期（5–20 轮）**与**长期（终局蓝图）**多条不同风格的路线，支持针对某一长期/中期方向继续向下拆解。
- **点亮软引导与微调**：点亮任意跨度的路线后，自动向后续对话与候选项注入克制的剧情软引导；支持「只铺垫 / 自然推进 / 尽快引爆」推进节奏及手动微调引导语，并保留对局侧游离空间，不会强行按头走线。
- **盲盒防剧透模式**：开启盲盒后遮罩剧透详情与终局揭示，仅保留标题、方向标签与世界内预兆风声，并可对单张卡片临时查看剧透。
- **多轮脑暴对话**：可在面板中直接与罗盘灵感助手讨论剧情点子；仅在明确同意采纳时改写路线卡片，或手动点击「应用为今期 / 应用为全局」。
- **自动核对进度与归卷/按楼演进**：每轮结算后自动对照近期正文与场景事实核对今期节拍/中期里程碑完成情况、探测偏离归档，支持自定义每隔 N 楼自动全层刷新及上下文归卷（`context-compacted`）后自动演进。
- **候选项联动与一键分叉**：为后续候选项提供路线角标（`routeTags`），并支持从当前回合一键分叉出平行存档并点亮指定路线。
- **独立模型选择**：按对局选择「跟随后台 / 跟随前台 / 独立模型（含推理强度）」。

## 安装方式

### 1. 作为独立插件安装在 DSH Tavern 中

本仓库运行时零第三方 npm 依赖（`dependencies` 为空），支持在 DSH Tavern 的插件管理中直接通过 GitHub 仓库导入，或在 DSH 配置目录中安装本包并应用 `cordis.patch.yml`。

### 2. 开发与测试

```bash
# 重新生成浏览器端产物 client.js
npm run build

# 校验 client.js 与源码一致
npm run build:check

# 运行单元测试
npm test
```
