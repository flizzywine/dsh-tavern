# 角色与服装设计规范

> 参考用户提供的「设计师角色设计」世界书整理。
> 要改规则就直接改这个文件，插件每次设计都会重新读它。

## 总原则

- 只描述**静态外貌特征**。不写表情、不写动作、不写姿势 —— 那些在出图时按当前场景单独分析。
- 全部使用英文 tag（danbooru / Stable Diffusion 风格），用英文逗号分隔。
- 人物每块控制在 10 个 tag 以内，服装每块 20 个以内。
- 显著或难生成的特征用权重强调：`((tag))` 中等、`(((tag)))` 强、`(tag:1.5)` 精确权重。
- 同一部位最多 1~2 个加权 tag，不要整块都加权。

## 年龄与幼态（最重要的修正）

- **年龄段是角色设定的一部分，必须照实写**：`loli` / `young girl` / `teenager` / `young woman` / `mature woman` / `milf` 都可以出现在「五官外貌」和「五官外貌背面」里。
- **绝对禁止把年龄写进「负面」**。负面是「这个角色身上不该出现的东西」，不是「年龄审查」。
  - 一个 loli 角色的负面**绝不能**出现 `loli` / `child` / `young girl` / `flat chest` / `petite` —— 那会直接把角色特征压掉，等于画不出来。
- 「角色特征」这一块只写气质与画风相关属性（innocent / seductive / cold / gentle / elegant …），不要在这里写年龄。

## POV 视角规则（重要）

**正面和背面是互斥的** —— 一张图只会调正面或背面其中之一，所以：

- 两个视角都能看到的共有特征**两边都要写**（头发、体型、腿型、年龄段）。
  - 正面：`long black hair, ((ice blue eyes)), pale skin, young woman`
  - 背面：`long black hair, nape, pale skin, young woman`
- 每个视角只写该视角看得见的：
  - 正面：眼睛、鼻子、嘴巴、正面五官、胸部正面轮廓。
  - 背面：后脑勺、发型背面、脖子后面、耳背、背部、肩胛骨、腰、臀部背面。
  - **背面绝不能写**：眼睛、鼻子、嘴巴、胸部、乳头、正面的项链挂饰。

## SFW / NSFW 区别（重要）

**SFW 块**用于穿衣场景，会和服装一起调用：

- **禁止任何裸露相关 tag**（`bare back`、`bare shoulders`、`nude`、`naked`、`undressing` 等）。
- 这些 tag 会让服装画不出来（衣服穿不上）。
- 只写穿衣状态下能体现的身体轮廓：体型（petite / slender / curvy）、胸部轮廓（flat chest / medium breasts / large breasts）、肩宽、腰线、腿型（long legs / thick thighs）。

**NSFW 块**用于赤裸场景，单独调用：

- 可以用裸露相关 tag。
- 写脱掉衣服后才看得见的身体细节：胸部大小形状、乳头颜色大小、生殖器、臀部、肛门、纹身伤疤位置。
- 背面块只写背面能看到的（`bare back`、背部线条、肩胛骨、臀部、肛门），**不写胸部和正面生殖器**。

## 字段结构

设计角色时按下面的结构输出，用 `<人物>` 包起来；设计服装用 `<服装>`。

```
<人物>
中文名称: 角色的中文名
英文名称: 英文译名（一般用翻译而不是拼音，日常中文名除外，如 xiao ming）
角色特征: 气质属性（innocent / seductive / cold / gentle / elegant / tomboy 等），只写与绘图气质有关的
五官外貌: 【正面】发型、发色、瞳色、脸型、肤色、年龄段
五官外貌背面: 【背面】发型背面、后脑勺、脖子后面、耳背 + 年龄段（不写眼鼻嘴）
上半身SFW: 体型、胸部轮廓、肩宽（穿衣可见，禁裸露 tag，不写动作）
上半身SFW背面: 肩膀轮廓、腰部线条、背部轮廓（体型要重复写，禁裸露 tag，不写胸部）
下半身SFW: 腿型（禁裸露 tag）
下半身SFW背面: 臀部轮廓、腿部背面（腿型要重复写）
上半身NSFW: 胸部详细（大小、形状）、乳头（颜色、大小）、正面可见的纹身/伤疤/痣
上半身NSFW背面: bare back、背部线条、腰、肩胛骨、背部纹身伤疤（不能写胸和乳头）
下半身NSFW: 生殖器官、正面可见的纹身/痣
下半身NSFW背面: 臀部详细、肛门、臀部纹身痣（不能写正面生殖器）
负面: 这个角色「身上」不该出现的东西 —— 只写外来的、不属于这个角色的异物
      （例如眼镜、胡子、纹身、首饰、和这个角色气质完全相反的服装元素）
      🚫 绝对不要写年龄、体型、身高相关的词（loli / child / petite / flat chest / young girl 等）
</人物>
```

```
<服装>
服装名称: 这套衣服叫什么（名字要含直观特点、性别、用途、分类，例如「脏的男士工作服」「少女粉色系内衣」）
上衣: 上身穿的东西（材质、颜色、款式、领口、袖长）
下装: 下身穿的东西（裤/裙、长度、材质、颜色）
鞋袜: 鞋子与袜子（共有物品，背面也要写）
配饰: 饰品、包、发型配件（只写该视角看得见的）
整体: 这套衣服的整体印象（可选，例如 formal / casual / lingerie set）
背面: 背面视角额外可见的细节（后背开口、系带、裙摆背面）
</服装>
```

设计多个人物时，按「人物1 → 人物1的服装 → 人物2 → 人物2的服装」的顺序输出。

## 质量检查清单

生成后逐条检查：

- [ ] **负面里有没有年龄词？**（有就删 —— 这是最严重的错误）
- [ ] SFW 块有没有混进裸露 tag（bare / nude 等）—— 有就删掉
- [ ] 正面和背面是不是都只写了各自看得见的东西
- [ ] 共有特征（头发、体型、腿型、年龄段）是不是两边都写了
- [ ] 是不是只有静态外貌，没有表情和动作
- [ ] 显著特征有没有用权重强调
- [ ] 人物每块是不是在 10 个 tag 以内

## 常见错误

```
❌ 负面: child, loli, flat chest        ← 如果角色本身是萝莉，这条把角色压没了
❌ 上半身SFW: bare back                 ← SFW 禁裸露，衣服会穿不上
❌ 五官外貌背面: long black hair, blue eyes   ← 背面看不到眼睛
❌ 五官外貌: long black hair …（背面没写头发）  ← 共有特征两边都要写
❌ smiling / standing                   ← 表情和动作不属于静态外貌
✅ 五官外貌: long black hair, ((sapphire blue eyes)), pale skin, young woman
✅ 五官外貌背面: long black hair, nape, pale skin, young woman
✅ 上半身SFW: petite, slender body, medium breasts
✅ 上半身NSFW背面: bare back, slim waist, shoulder blades
```
