这里的「画风」就是你自己的 ComfyUI 工作流

每一张图都交给本地 ComfyUI 画，用哪一份工作流就在这里选。列表里带 正在使用 的那份就是当前画风。

怎么换画风，三种办法：

  1. 在这页点某一项的「换成这个画风」——立刻生效。
  2. 在游戏里改插件的「模型」下拉：选 V4.5 完整版 或 V5 完整版，各对应下面的哪一份由「插件里选这个时」那一栏决定。
  3. 把新工作流 JSON 丢进 workflows 文件夹，再点右上角「查找新工作流」。

不用动 Tavern 的设置。工作流是插件自己的东西：换画风就在这一页点，或把新的工作流 JSON 丢进 workflows 文件夹。
