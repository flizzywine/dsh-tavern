# 人物库填写规范

人物库存在插件的 `definitions.json` 里，设置页「人物库」那一页能改。这个 skill 讲的是**每条该写什么**。

## 什么时候读

- 用户让你给人物库添角色
- 用户让你改某个角色的外观 tag
- 出图时角色特征老是不对，怀疑是 traits 写错了

## 字段对照

规范里用中文名，人物库里用英文 key，两者一一对应：

| 规范里的名字 | traits key | 用在哪 |
|---|---|---|
| 角色特征 | `feature` | 只给规划模型挑表情动作，**不写进画图提示词** |
| 五官外貌 | `face` | 正面镜头 |
| 五官外貌背面 | `faceBack` | 背面镜头 |
| 上半身SFW | `bodySFW` | 正面、穿着衣服 |
| 上半身SFW背面 | `bodySFWBack` | 背面、穿着衣服 |
| 下半身SFW | `lowerSFW` | 正面、穿着衣服 |
| 下半身SFW背面 | `lowerSFWBack` | 背面、穿着衣服 |
| 上半身NSFW | `bodyNSFW` | 正面、赤裸 |
| 上半身NSFW背面 | `bodyNSFWBack` | 背面、赤裸 |
| 下半身NSFW | `lowerNSFW` | 正面、赤裸 |
| 下半身NSFW背面 | `lowerNSFWBack` | 背面、赤裸 |
| 负面 | `negative` | 这个角色身上不该出现的东西 |

## 角色级字段

traits 之外，一个角色条目还有这些字段，含义与 `definitions.json` 里的 key 一致：

| 字段 | 写什么 |
|---|---|
| `name` | 中文名，调用时按它找角色 |
| `match` | 命中别名，逗号分隔 |
| `enabled` | 停用后不在人物库里返回 |
| `note` | 给模型看的补充说明，可空 |
| `outfits` | 这个角色自带的服装，内嵌七块 tag，可空 |
| `outfitRefs` | 另外引用公共服装库的套装，存 id 或名字 |
| `defaultOutfit` | 默认服装，存公共服装库那套的 id；空着就退回 `outfits` 里标了 `default` 的那套 |

设置页人物库那一页有下拉框直接选 `defaultOutfit`，不用手填。它只决定 `read_character` 给出的「默认服装」是哪一套，不自动拼进提示词——这一张穿什么仍由画面决定。

## 三条最容易犯的错

**年龄词写进负面。** 这是最严重的错误。负面是「不该出现的东西」，不是年龄审查。一个体型娇小的角色，负面里写 `petite`、`flat chest`、`small frame`，等于把这个角色的核心特征直接压掉，画出来会变样。

**SFW 块里写裸露词。** `bare back`、`nude`、`naked`、`undressing` 这类词出现在 `bodySFW` 或 `lowerSFW` 里，会让衣服穿不上——画出来是该穿衣服的场景却光着。SFW 块只写穿衣状态下能看出的轮廓。

**正面和背面不分。** 两个视角是互斥的，一张图只会调其中一个。共有特征（头发、体型、腿型、年龄段）**两边都要写**；眼睛、鼻子、嘴巴、胸部、正面挂饰**只能写在正面块**；背面块写后脑勺、脖子后面、耳背、背部、肩胛骨、臀部和肛门。

## 写法要点

- 只写**静态外貌**，不写表情、动作、姿势——那些出图时按场景单独写
- 全英文 danbooru tag，英文逗号分隔
- 每块控制在 10 个 tag 以内
- 显著或难生成的特征可以加权：`((tag))` 中等、`(((tag)))` 强、`(tag:1.5)` 精确权重
- 同一部位最多 1~2 个加权 tag，不要整块都加

## 完整规范

`references/design-rules.md` 是原文，包含每个字段的详细说明、示例、以及生成后的质量检查清单。写正式条目之前读它。

注意：原文里提到 `<人物>` / `<服装>` 包裹格式，那是给 `dsh-tavern-image` 的导入器用的。这里不导入，直接把内容填进对应字段即可，不要保留包裹标签。
