# 人物与服装资料规范

只记录用户已确定的可见外貌、服装与身份特征。分视角保留资料，出图时按本张镜头取用，不把正面与背面同时写进一张画面。

## 写法

自然语言渠道使用简短完整描述；标签渠道使用其支持的标签及权重。不要把所有资料统一改成英文标签，不改变用户已建立的年龄、体型或衣着事实。动作、表情与场景在每次生图时单独描述，资料库主要保存稳定特征。

## 字段

人物使用现有人物库的 `name`、`match`、`traits` 与 `outfits`。`face` 记录正面可见的头面部，`faceBack` 记录后脑勺和发型背面；身体分视角字段只填相应视角实际可见的内容。保留未编辑的字段及参考图，不猜测空白部位。

服装使用 `upper`（上衣）、`lower`（下装）、`shoes`（鞋袜）、`accessory`（配饰）、`full`（整套说明）、`back`（背面补充）、`negative`（该套需要排除的元素）。描述材质、颜色和款式，用户未指定的留空。

`referenceImage` 是人物或独立服装图，`characterOutfitImage` 是某个人穿该套服装的成套图。保持图片标识与所属人物、服装一致；不要手写磁盘路径代替图片标识。

## 保存

在共用人物库页面编辑，或先读取工作台 API 最新对象及 `revision` 后通过保存接口修改。遇到冲突保留草稿、重新读取、核对后再保存。修改人物时不清空通用服装，修改服装时不覆盖人物；保留人物卡绑定、默认标记及已有参考图。
