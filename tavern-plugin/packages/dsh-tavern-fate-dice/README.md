# dsh-tavern-fate-dice（命运之骰 2.0）

面向 DSH Tavern（插件 API v8+）的纯粹真骰行动检定、AI 四源角色能力推演与叙事阻尼器双向联动插件：

- **定位纯粹、边界清晰**：与酒馆原生的「剧情罗盘」（负责短/中/长期剧情路线规划）、「叙事阻尼器」（负责合理性与数值惯性刹车）各司其职——**命运之骰专注用密码学真随机数裁定每一次冒险尝试的真实成败（大成功 / 成功 / 代价成功 / 失败 / 大失败）**。
- **进驻「插件区」极简双页工作台 × 每轮对话尾部实时胶囊**：通过 `tavernUi.registerPanel` 注册常驻侧栏面板（「检定与能力」+「检定设置」两页，独立纵向滚动适配桌面与手机竖屏，全设置项配备 `?` 点击展开说明）；纯原生 DOM 真骰胶囊挂在每轮对话的尾部（story 视图的 `.dsh-tavern-story-row-actions`，原生对话或旧宿主回退楼层顶栏），流式生成期间即可实时呈现定难与骰点，点击就地展开命运点与重投面板；窄屏手机与触屏设备上胶囊自动收成**一枚骰子图标**（`mask` 绘制，随成败色调变色，语义交给 `title`/`aria-label`），点开仍是完整裁定小窗，把消息区宽度全留给正文。
- **AI 四源动态角色能力推演（零手动填表）**：每次检定自动结合【角色卡/玩家人设 + 当前启用世界书 + MVU 实时变量 + 近期正文】评定主角能力与状态加减值（支持 `2d6 / d10 / d20 / d100` 四骰制自动等比换算），并在后台结算时通过 `fate_dice_profile_sync` 随受伤、突破或装备更替自动演进角色能力画像。
- **WebGL2 HDR 3D 投骰舞台（6 款主题）**：原生 `#version 300 es` 渲染管线 —— `RGBA16F` 浮点 HDR 离屏目标 + 双 Kawase Bloom + ACES 色调映射，四通道法线雕文雕刻骰面；主题含「星穹秘法 / 时停棱镜 / 焚天熔炉 / 赛博超频 / 水墨剑心 / 虚空星噬」。全局复用单一离屏 GPU 管线、落定后自动 `0%` GPU 休眠省电；默认主题在 **✦ 逆命重投 / 🔥 孤注一掷 / 👁️ 暗骰** 时智能切换专属光效；手动重投与自由投掷支持**长按按钮聚能蓄力**（松手爆发甩出，移出按钮无损取消）；无 WebGL 环境自动降级为 2D 极简闪现。
- **投骰演出稳居对话视口正中央、横向 100% 占满、与胶囊彻底剥离**：决策模型一给出本轮的判定结果（`live-roll` 广播即刻触发，无需等待流式 DOM 楼层插入），立刻在 `document.body` 上锚定当前对话滚动容器（`[data-conversation-scroll]`）起一枚**横向 100% 占满整个对话区、纵向稳居对话视口正中央**的独立 WebGL2 宽银幕剧场（绝不受刚生成楼层 28px 空高度挤压或流式滚动牵连）：天际裂隙与双轨流光尺自中心拉开入场 → 两侧大翼展 `0.58x` 慢镜抛入中央星盘并进入落地凝滞慢镜 → 落定瞬间盖落主题印章并点亮底部裁定铭牌定格 2.45s → 天际光轨回缩并沿水平中线合拢消散（全程约 6.2s）；尾部胶囊只保留常驻读数、详情与重投入口，自己不再自动播任何动画。动画设置关为 `none`/`compact`、`prefers-reduced-motion`、无 WebGL2 时自动跳过演出，胶囊读数照常给出。
- **胶囊跟着每一轮走**：检定胶囊不再停在输入栏上方，而是挂在该轮对话的尾部操作行里，滚动回看旧楼层时每层都能就地点开裁定弹窗（定难、骰点、五档结论、命运点与重投闭环）。
- **叙事阻尼器单趟合并提问 × 双向配额联动**：复用「设置 › 叙事阻尼器」中的决策模型（未配置时自动展示醒目三步引导）；开启叙事阻尼器时合并为**单趟请求**（零额外延迟，共享 R18 三级语义分级脱敏），读取阻尼四维状态修正检定 DC，并在真骰出点后反向解锁或收紧阻尼器的推进档位与 MVU 变量配额。
- **失败时暂停发送（发前逆命）**：「检定设置」新增一档开关，开启后只要本轮真骰掷出「失败 / 大失败」，正文请求会**先被按住不发送**——屏幕中央弹出「骰已落定 · 正文还没发送」小窗，当场选 **✦ 逆命重投（-1 命运点）**、**🔥 孤注一掷（0 点，败则恶化大失败）** 或 **接受命运**；选择完宿主重投后正文才真正开始生成，坏运气不会先写成一段再被推翻。可限定「失败与大失败都暂停 / 仅大失败」，等待时长 10/18/24 秒可选，倒计时结束自动按原骰点发送（宿主提示词组装上限 30 秒，绝不卡死）；暗骰不参与暂停以免剧透。
- **防重新生成刷骰 ×「✦ 命运点 + 🔥 孤注一掷」代价重投**：同一楼层 `turn` 且玩家行动文本未变时，点击酒馆「重新生成」将**强制复用首次已结算的真骰结果**并自动向叙事阻尼器重新同步该档位配额。手动重投严格执行**四重硬限制**（每楼层限 1 次、仅限最新楼层、暗骰禁重投、已成功禁刷上限），并提供双轨代价博弈：消耗 1 点 **✦ 命运点**（开局 `2/3`，坦然接受 1 次大失败或累计 2 次失败不重投自动回充 `+1`）稳妥逆命重投，或选择零消耗高风险的 **🔥 孤注一掷**（失败强制恶化为`大失败`，翻盘成功亦必注入挂彩/透支叙事代价）。

## 安装

内置插件随 DSH Tavern 加载。检定功能默认关闭。在「插件 → 命运之骰 → 检定设置」打开「启用命运之骰」后，聊天和「酒馆状态」会显示检定入口。

### 方式一：一键导入安装包（推荐）

在 GitHub 仓库下载源码包或 Release ZIP，并在 DSH Tavern 的「设置 → 酒馆插件 → 导入插件」中选择导入即可。

### 方式二：手动克隆到用户插件目录

```sh
git clone https://github.com/bigmalove/dsh-tavern-fate-dice.git <dataRoot>/plugins/dsh-tavern-fate-dice
```

刷新酒馆页面后，先在「设置 › 叙事阻尼器」配好决策模型与 API Key，即可在右侧「插件」卡片区打开 **命运之骰** 使用。
