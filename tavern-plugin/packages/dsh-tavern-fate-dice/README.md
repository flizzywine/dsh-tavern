# dsh-tavern-fate-dice（命运之骰插件）

面向 DSH Tavern（插件 API v8）的原创动态检定与真随机掷骰插件：

- **AI 毫秒快判 + 本地真骰**：复用宿主 `decisionJudge` 接口（叙事阻尼器决策模型，无需阻尼器拦截开关开启）在发送前评估是否需要检定、难度档位（5 档）、情景修正与暗骰倾向；本地以 `node:crypto` `randomInt` 投掷真骰，零额外主模型回合。
- **R18 送审语义分级脱敏**：开启脱敏后自动经宿主执行词表置换 → 动作尺度骨架 → 纯结构节拍摘要三级脱敏与安全拒绝降级重试，避免成人内容场景被远端输入过滤拦截。
- **多规则支持**：内置 `2d6`（叙事渐进，推荐文字 RP）、`1d20`（经典跑团阶梯）、`1d100`（百分阈值），支持 MVU / 变量字段整数修正提取与叙事基调配置。
- **移动端优先与非阻塞动效**：输入栏顶部零占位实时掷骰揭示条（与主模型首字生成并行）、一键「🎲 骰盘」底栏抽屉（发前预览微调 / 自由公式投掷）、每轮折叠检定徽章（暗骰支持点击揭晓）与酒馆状态页统计。

## 安装

将本目录整个复制到你的 DSH Tavern 用户插件目录：

```sh
<dataRoot>/plugins/dsh-tavern-fate-dice/
```

或打包为 `.zip` 在 Tavern「设置 → 酒馆插件」中导入安装。如修改了 `src/client/main.js`，请运行：

```sh
node build.mjs
```
