# 剧情导演

在酒馆右侧开一页导演对话。可以先说个大概，比如「想让失踪案影响同伴之间的关系」。也可以和导演一起聊定跨场景的剧情总纲。

总纲保存在本局导演的计划中。每轮结算后，导演对照总纲和最新正文，重新判断当前值得关注的剧情方向。交给写作者的 Guide 最多一句，具体情节、节奏和文风由写作者与玩家决定。点输入栏里的「当前 Guide」可以查看方向，也可以暂停 Guide 和复盘。

点输入栏右侧的模型名可以为本局导演选模型，侧栏对话和自动复盘都会使用它。默认跟随酒馆后台模型。

## 打开

剧情导演随 DSH Tavern 安装，在「设置 → DSH Tavern → 插件」可停用。进入游玩对话后，从右侧「＋ → 插件 → 剧情导演」打开。
