# 剧情导演

在酒馆右侧开一页导演对话。你只需要说出想要的感觉，比如「节奏慢点，矛盾别这么快爆发」。导演结合角色和近期剧情自行编排，将剧情、节奏、文风写成本局 Guide。安排准备好就生效，可以继续聊天调整。

长期纲要保存在本局导演的计划里。交给写作者的 Guide 只包含眼下的剧情、节奏和文风。采用长期纲要时，每轮结算结束后导演调用本局后台模型复盘，按实际进展调整下一步。短期安排每 1–4 轮复盘。点输入栏里的「当前 Guide」可展开在用安排，面板里的「暂停」可以停用 Guide 和复盘。

## 打开

剧情导演随 DSH Tavern 安装，在「设置 → DSH Tavern → 插件」可停用。进入游玩对话后，从右侧「＋ → 插件 → 剧情导演」打开。
