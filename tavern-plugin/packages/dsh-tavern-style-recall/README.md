# 文风参考

从剧本库选择一本小说，作为正文的文风参考。所有人物卡共用设置，功能默认关闭。

先在右侧栏「剧本库」导入小说，再从「插件管理 → 文风参考」选书。也可以从游玩对话右侧栏「＋ → 插件 → 文风参考」进入。切换「启用」会立即保存。单独更换或解除小说绑定时，点「保存全局设置」。

每轮用当前输入和前情做 BM25 关键词匹配，把最高分的一段原文交给正文模型。同分时从并列片段中随机取一段，全书零分时从全书原文中随机取一段。选段无需调用模型。自由游玩、剧本游玩和纯净写作均可使用。

已经启用小说选段的设置会沿用。原来选择自行联想的玩家升级后会看到开关关闭，已绑定的参考小说仍可直接使用。
