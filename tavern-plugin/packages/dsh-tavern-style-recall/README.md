# 文风联想

为整个酒馆选择一种文风联想方式。所有人物卡共用全局设置，功能默认关闭。升级前的按卡绑定保留在插件数据中，需要重新选择一本全局参考小说。

打开「设置 → 文风联想」，选择方式，勾选「开启文风联想」并保存。也可以从游玩对话右侧栏「＋ → 插件 → 文风联想」进入。

- **从剧本库选段**。先在卡片工作台的「剧本库」导入小说，再选择一本。后台 Agent 结合当前输入和前情挑选最多两段原文供正文模型参考。支持自由游玩、剧本游玩和纯净写作。后台选段失败或超时后，正文照常生成。
- **前台自行联想**。正文模型结合本轮场景联想一段范文，再继续写作。可以设置文风偏好，并在插件面板查看本局最近的范文。这种方式用于原生自由游玩，耗用前台模型的额度。

两种方式均以本局设定和已发生的情节为准。原有剧情剧本可以同时使用。清空小说可解除绑定，小说资源重命名后可在此重新选择。
