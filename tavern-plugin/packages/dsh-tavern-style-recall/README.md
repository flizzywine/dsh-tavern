# 文风联想

把剧本库里的一本小说设为人物卡的写法参考。绑定保存在本机的插件设置里，同一张卡的游玩记录共用。可以同时使用人物卡原有的剧情剧本。

1. 在卡片工作台的「剧本库」导入小说。
2. 打开这张卡的游玩对话，在右侧栏「＋ → 插件 → 文风联想」选择参考小说，勾选「开启文风联想」并保存。
3. 发送下一轮输入。后台模型根据当前输入和前情，从候选原文中挑选最多两段。正文模型只参考句式、视角、对白、节奏和描写，人物与情节继续以本局为准。

启用后每轮最多加一次后台模型请求，选段等待上限为 20 秒。剧本移除、后台模型不可用或没有合适选段时，正文照常生成。清空小说可解除绑定。人物卡文件或小说资源重命名后，可在这里重新选择。

插件随支持 `scriptLibrary: 1` 的 Tavern 版本安装，每张卡默认关闭。支持 Tavern 原生的自由游玩、剧本游玩和纯净写作。SillyTavern 兼容请求沿用其自身的上下文组装。
