# 文风联想

为整个酒馆选择一种文风联想方式。所有人物卡共用全局设置，功能默认关闭。升级前的按卡绑定保留在插件数据中，需要重新选择一本全局参考小说。

打开右侧「插件管理 → 文风联想」，也可以从游玩对话右侧栏「＋ → 插件 → 文风联想」进入。打开「启用」会立即保存并应用当前配置。关闭「启用」立即停止联想。只调整配置时，点「保存全局设置」。

- **从剧本库选段**。先在右侧栏「剧本库」点「导入小说或剧本」，再在文风联想里选一本参考小说。每轮用当前输入和前情做 BM25 关键词匹配，只把最高分的一段原文交给正文模型。最高分相同就从并列片段中随机取一段，全书零分时从全书原文中随机取一段。选段阶段无需调用模型。支持自由游玩、剧本游玩和纯净写作。
- **后台自行联想**。正文生成前，本局后台模型根据人物卡、最近两轮剧情和本轮输入联想一段范文，程序把范文注入本轮正文请求。可以设置文风偏好，并在插件面板查看本局最近的范文。耗用本局后台模型的额度，失败或超时时正文照常生成。原先的「前台自行联想」设置会沿用为此模式。

两种方式均以本局设定和已发生的情节为准。原有剧情剧本可以同时使用。清空小说可解除绑定，小说资源重命名后可在此重新选择。
