# dsh-tavern 启动器

把启动器装进 DSH NEXT 的日常 `desktop` Profile，然后在「设置 → 酒馆启动器」点击「安装酒馆」。启动器会创建独立的 `tavern` Profile，并让 DSH 从 GitHub 的 `plugin-market-next` 发布分支安装酒馆。完成后，在「桌面设置 → Profile」选择 `tavern`。

启动器会显示安装状态和版本。已有源码版酒馆或同名冲突时，需要先检查该 Profile。日常 Profile 仅加载启动器的设置页。

这是独立的 DSH 插件包 `dsh-tavern-launcher`。市场可以从本仓库的子目录安装，或使用打包后的 `.tgz`。
