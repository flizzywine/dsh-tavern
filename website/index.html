02 / 卡片工作台

创造你自己的人物卡

不用懂卡片字段，告诉 Agent 哪里不喜欢、想改成什么样，它先给方案，你确认后才写入。

  • 从零写卡从小说、设定或一句灵感，开始塑造人物。
  • 边玩边改人物卡、世界书、预设，一起调整。
  • 自助调试把本局记录交给 Agent，定位卡片问题。
