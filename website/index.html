02 / CREATE

你的想法，
就是改卡的起点。

不用先学会一整套字段。用对话告诉 Agent，你想创造怎样的人，或把哪里改得更合心意。

  • 从零写卡从小说、设定或一句灵感，开始塑造人物。
  • 边玩边改人物卡、世界书、预设，一起调整。
  • 自助调试把本局记录交给 Agent，定位卡片问题。
