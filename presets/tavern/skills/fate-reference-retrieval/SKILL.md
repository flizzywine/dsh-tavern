# Fate 参考资料使用纪律

这是当前正文 Agent 的轻量证据纪律，不是独立研究 Agent，也不要求每轮检索。

## 先用已经在上下文里的东西

先读取当前 MVU、本局已发生正文、本轮世界书、人物卡和当前剧本参考。它们已经能支持本轮时直接写，不为了“更完整”继续查资料。

只有一个具体缺口会改变本轮人物行为、机制判断、日期或事件位置时，才使用当前 Agent **已经拥有** 的读取工具：

- 本局过去是否发生、见过、被告知或调查过：`tavern_recall_history`。
- 剧本模式下需要核对当前绑定剧本附近的原文：有 `tavern_read_script` 时按当前问题读取。
- 本地上下文仍不足，且本局允许联网：有 `web_search` 时再补证。

不要假定存在未暴露给当前 Agent 的工具，不猜文件路径，也不要求新增资料管线。

## 查询要窄

一次只核对当前疑点。优先使用人物、地点、事件、能力或辨识度高的短语作为锚点；结果明显不对应当前人物、版本或阶段时，不因为它排在第一就采用。

查到足以回答当前问题的证据就停止。不要为了补全百科、人物履历或整条时间线无限展开，也不要把检索过程写进正文。

## 证据不会自动变成剧情事实

原作、外部资料和其他路线用于校准当前写作；它们不能覆盖本局已经发生的 IF 分歧，也不会自动让角色知道秘密。资料支持什么精度，就只采用什么精度；冲突或缺口交给 `fate-adjudication` 保持为推断或未知，角色是否知道交给 `fate-cognition` 判断。

## 文风参考

当前剧本参考与现场高度相近时，可以借鉴叙事距离、句段节奏、动作与感官顺序、对白密度和信息揭示方式。借鉴写法不等于强行复原原作事件或把本局拉回原路线。
