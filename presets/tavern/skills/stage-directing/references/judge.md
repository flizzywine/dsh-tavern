# 智能判断

界面位置：舞台设置 › 基础设置 ›「舞台模式 ›」→「判断模型」。

## 它做什么

每轮导演开始前，对"未命中触发词的绿灯素材"逐条询问判断服务："这条素材适合本轮剧情吗？"，概率达到阈值的按概率从高到低补入候选，每类最多 `capPerKind` 条。蓝灯和命中触发词的绿灯不占名额，关灯的素材永不提问。人物当前穿着和默认服装不参与判断。判断失败、超时或没有配置时，只按触发词召回，不会随机补位，也不重试。

发给判断服务的只有最新一轮正文和素材的名称与使用情景；不发送玩家输入、旧轮次、变量、世界书或完整人物卡。

## 配置

`tavern_stage_read judge` 读取当前配置、revision 和凭据状态；`tavern_stage_patch judge` 保存，属于全局设置，每次写入宿主都会弹出确认。

| 字段 | 说明 |
| --- | --- |
| `provider` | `unset`（默认，不发任何请求、零费用）、`jev`、`openai`、`openai-compatible` |
| `model`、`baseUrl` | 模型名；`baseUrl` 只用于 OpenAI 兼容，需要支持 Decisions 协议，只提供 chat 接口的代理不能用 |
| `keyName` | 凭据名称，例如 `OPENAI_API_KEY`。工具只保存名称并显示是否已配置，不接收密钥本身。密钥由用户自己填：「判断模型」的「API Key」里直接粘贴密钥（保存在本机凭据里，不回显），或填已有凭据的名称 |
| `threshold` | 0–1，默认 0.6；调高补位更少 |
| `capPerKind` | 每类最多补入的条数，默认 8 |
| `timeoutMs` | 默认 1500 毫秒 |
| `enabled` | 关闭时等同未配置 |
| `preamble` | 附加在问题前的说明，默认空 |

## 费用

设置了提供方以后，每轮导演都可能产生一次按量计费的判断请求；OpenAI API 费用不包含在 ChatGPT 订阅里。配置前把这一点告诉用户。想省钱时，先用触发词把常用素材调好，比开智能判断更可控。

## 测试连接

`tavern_stage_patch judge-test` 会发出一次真实的极小请求，可能收费。只在用户要求测试时调用；宿主会弹出付费确认。结果里的 `mayHaveCharged` 原样告诉用户。失败时按返回的错误给出修法（凭据未配置、地址不对、超时），不要自动重试。

## 例子

用户："绿灯素材总是用不上，帮我开智能判断，用 OpenAI。"
→ 说明会按轮计费 → 读取 judge 配置 → 告诉用户"这是全局设置，会影响所有卡片：智能判断提供方改为 OpenAI，模型和凭据名称为……" → 写入（宿主确认）→ 回读并查看凭据状态；未配置时请用户在「判断模型」的「API Key」里粘贴密钥。用户同意后再测试连接。
