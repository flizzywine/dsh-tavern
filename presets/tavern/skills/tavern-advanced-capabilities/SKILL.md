# Tavern 高级能力

在用户要求创建或修改 Skill、通用工具、Cordis 插件等扩展时使用。它提供持久位置和加载约定，不限制 Agent 组合当前已有的 Shell、文件与 Tavern 工具。

## 扩展位置

系统提示词提供的 Tavern 资源根目录以 `resources` 结尾。其父目录是持久数据目录：

- 自创工具和插件代码放在同级 `tools/`；
- Cordis 持久加载清单是同级 `tools.cordis.yml`；
- 自创 Skill 放在同级 `skills/`，优先使用 `tavern_save_skill` 保存。

这些目录不在程序安装目录内，Tavern 更新不会覆盖。程序源码、内置 preset 和内置 Skill 目录只供程序自身维护，不保存用户扩展。使用文件工具时先根据系统提供的绝对资源根目录解析目标绝对路径，不猜测主目录或安装位置。

## 临时与持久能力

- Cordis 动态插件适合临时检查或扩展当前 Runtime，可以注册工具或界面，进程重启后消失。
- 需要重启后保留的自创工具，把代码及依赖放入 `tools/`，并在 `tools.cordis.yml` 中追加加载条目。相对模块路径以清单所在目录为准；先读取现有清单，只追加或修改目标条目，保留其他未知条目。
- 典型加载条目包含唯一 `id`、相对于清单的模块 `name` 和 `config`。不要把动态加载成功误报为已经持久安装。
- Skill 只保存可复用的方法和配套资源，不借此扩大本次任务的写入授权。

## 验证与报告

写入后检查目标路径、文件格式、模块入口和清单引用。动态能力必须完成一次实际加载或调用，才能报告当前可用。持久工具只有在 DSH 重启后的新工作台中确认工具可见并实际调用后，才能报告已持久加载；只完成文件写入时，说明已经保存、仍需重启验证。

历史中的临时工具没有可恢复源码时，不声称已经恢复。最终区分保存位置、当前 Runtime 是否可用，以及重启后是否已验证。
