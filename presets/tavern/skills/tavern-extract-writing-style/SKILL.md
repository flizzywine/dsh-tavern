# 提炼文风

把样文中的稳定表达规律转成可执行的原创写作规则。结果服务于人物卡准备、开场白、对话示例和素材改写，不自动修改人物卡。

## 阅读

先确认样文路径与目标用途。长文本先查看规模和结构，再抽取具有代表性的片段；样本不足以支持某项判断时标为不确定，不用单句偶然现象概括整套文风。

## 提炼

从实际文本证据归纳以下维度中确实存在的部分：

- 叙事视角、距离与信息揭示方式
- 句长、停顿、段落密度和节奏变化
- 动作、感官、环境、心理与解释的配比
- 对话长度、潜台词、人物声线和叙述衔接
- 意象、修辞、幽默、情色或暴力内容的表达强度
- 场景推进、情绪累积和高潮收束方式

把角色姓名、世界设定、专有名词、具体情节和口头禅与风格规律分开。用户引用作者或作品时，以可观察特征组合出原创规则，不要求模仿某位作者的独特表达。

## 产出

先给出简短分析，再形成文风 Skill 草稿：

- `name`：建议以 `tavern-style-` 开头
- `description`：一句话说明效果和适用场景
- 正文：适用场景、写作规则、节奏调节、完成前检查

规则应能直接指导生成，避免只有“细腻”“高级”“有氛围”等不可检验形容词。必要时用一两个自写微型例子澄清规则，不复制样文句子。

用户明确要求保存时，先通过 `skill` 加载 `tavern-create-skill`，再按它的规则调用 `tavern_save_skill`。仅分析文风时停在分析结果，不创建文件、不修改人物卡。
