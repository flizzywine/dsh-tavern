# 常见任务

每项先给用户自己点的最短路线，再写你能用工具做什么（读哪篇参考）和常见坑。所有路线都假定这张卡已经开了舞台（[开舞台](setup-quickstart.md)）。

## 给人物配立绘和声音

- 界面：舞台设置 ›「人物」点头像，打开这个人物的编辑页（形象、生图、声音）；「人物」末尾的虚线「＋」新建人物；也可以在「已有人物」里直接选一个。设置向导第 2 步是同一页。
- 工具：人物、服装与差分见[人物](asset-figures.md)，应用内生图见[应用内生图](asset-generation.md)，声音见[给人物配声音](voice-figure.md)，语音服务见[配音后端](voice-backend.md)。
- 常见坑：
  - 素材包是共享的：改一个包里的人物，所有用这个包的卡都会变。只想改这张卡，就改它的本卡素材包，或先复制包再改（[包与绑定](asset-packs.md)「只改这张卡的素材」）。
  - 人物的「触发词」就是它的名字和别名：把正文里常用的叫法都加进去，例如「林澄」「小澄」。

## 换皮肤

- 界面：只换这张卡：进舞台后点控制栏的齿轮「设置」›「画面」›「本卡皮肤」，这个选择随卡导出。所有没指定皮肤的卡：舞台设置 › 舞台模式 › 皮肤「默认皮肤」。
- 工具：本卡皮肤写 `card` 补丁的 `defaultSkin`，默认皮肤写引擎的 `dialogueTheme`（全局，写前说明影响），见[开关与皮肤](setup-switches.md)。可选：内置 `classic`（经典）、`crt`（显像管）、`aero`（千禧晴空），以及当前卡可用包里的皮肤条目；安装或修改皮肤条目见[皮肤条目](asset-skins.md)。
- 常见坑：包里的皮肤只有在包对这张卡生效（本卡或全局）时可用；不可用时先退回默认皮肤，再退回「经典」。整个酒馆界面的 .css 界面皮肤不是舞台皮肤，改它看 tavern-plugin 的 interface-skin 参考。

## 只给这张卡开一个功能

- 基础设置：对话气泡、配音、舞台模式、自动素材四个开关有本卡层，在 舞台设置 › 基础设置 每一行右侧的开关标签选「本卡开启」或「本卡关闭」。BGM、音效、环境音、物品、演出组合没有开关，跟随舞台模式。
- 模组：只有手机这类对很多卡都通用的模组有玩家开关，在 舞台设置 ›「模组」那一行用同样的标签选。检定、数据删除、文字演出、计时器没有开关，由卡（或它的皮肤）声明才启用，写法见[卡声明的引擎接口](mod-card-declared.md)；舞台设置的「模组」区只在声明了它们的卡上列出这一行，写明是卡还是皮肤声明的。模组的安装和卸载在 侧栏首页 ›「舞台装置」›「舞台引擎」›「模组」。
- 工具：工具能写基础设置的全局开关（引擎 `stageToggles`）和卡里的模组声明；本卡开关和手机的开关请用户在界面里选。模组的本卡设置值见[模组](mods.md)。
- 常见坑：
  - 生效顺序是 本卡关闭 > 全局开启 > 本卡开启 > 全局关闭。在某张卡上选「全局开启 / 全局关闭」会清掉这张卡自己的选择，并改动所有卡。
  - 功能生效但本轮没有可用条目时不运行，也不给导演发它的说明（舞台上还留着它的状态时只保留维持或停止所需的一句）；物品要先在素材包里有条目，计时器要有「倒计时」条目。
  - 模组的执行授权与开关无关，打开开关不会扩大权限。

## 导入 Live2D 模型

- 界面：侧栏首页 ›「舞台装置」›「舞台引擎」›「运行库」先装运行库，再在人物编辑页的「模型」视图「导入模型」。
- 工具和常见坑：见 [Live2D 与 Spine](asset-live2d-spine.md)。

## 带素材分享这张卡

- 界面：舞台设置 ›「素材包」›「导出」，勾选要带的包，再点「导出」得到卡 ZIP。
- 工具和常见坑：见[分享人物卡](sharing.md)。

## 设置开场画面

- 界面：设置向导第 3 步，或舞台设置末尾折叠的「开场设置」。
- 工具：见[开场画面](setup-openings.md)。登场人物为空就是空舞台，不会自动补主角。
