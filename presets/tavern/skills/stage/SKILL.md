# 舞台功能

本 Skill 只负责选路：判断需求属于哪一步，再用 `skill` 加载对应的子 Skill。它本身不解锁工具，配置工具随子 Skill 一起出现。只做介绍时回答用户该用哪项，不声称已经配置。「舞台」通常指 galgame 舞台。

## 按步骤选子 Skill

| 步骤 | 用户想做的事 | 子 Skill |
| --- | --- | --- |
| ① 开启与设置 | 给卡开舞台、设置向导、开了看不到画面；四态开关（对话气泡、配音、舞台模式、BGM 等）；开场画面与人物站位；选用皮肤；字体和阅读控制 | stage-setup |
| ② 素材库 | 素材包的绑定与启用；人物（形象、服装差分、Live2D/Spine、应用内生图）；配音（第一次配好、配音后端、人物声音、克隆、读音、没声音排查、通用声音与旁白）；背景、CG、音乐音效、皮肤条目与触发词；安装和导出素材包 | stage-assets |
| ③ 导演 | 导演模型、可用演出、演出风格、素材的导演说明与服装使用情景、智能判断、导演提示词预览 | stage-directing |
| ④ 模组 | 已安装模组（骰子、手机、文字卡、计时器等）的开关、授权、设置值和变量来源 | stage-mods |
| ⑤ 卡页面 | 卡自带的舞台页面（标题页、开场页、地图、状态等）及其打开方式 | stage-status-panel |
| ⑥ 分享 | 导出或导入带素材包的人物卡 ZIP | stage-sharing |

相邻能力：做 DSH 卡文件、`.dshcard` 卡包或迁移旧 galgame 卡用 create-dsh-card；卡片文字、开场白正文、世界书、正则用 edit-card；MVU 变量用 card-to-mvu；编写新插件或模组代码用 tavern-plugin；某一轮游玩记录里的异常用 debug-card。

## 一次配完整张卡

用户问「怎么把一张普通卡做成舞台卡」时，先按 stage-setup 的「开舞台」给最短路线。不想改原卡时，先在人物卡库「另存副本」（「保存字段」会直接改原卡；副本与原卡共用素材包）。

替用户配完整演出时按依赖顺序推进，每一步加载对应子 Skill：素材包与绑定 → 人物与服装 → 开场画面 → 配音 → 导演与模组。前一步得到的包 ID、人物引用和 revision 是后一步的输入，所以顺序不能颠倒。某项没有可用素材时跳过并告诉用户缺什么，不为凑齐功能制造空条目。

完成标准：每一步都由对应子 Skill 回读确认；最后请用户进舞台发一轮消息看效果，没看过游玩页时只说「已保存」。
