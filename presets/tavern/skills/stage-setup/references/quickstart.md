# 开舞台

用户问"怎么给这张卡开舞台"时，按下面的顺序给最短路线；用户卡在某一步时，用后面的排查表。

## 最短路线（用户在界面里点）

1. 打开这张卡的一局游戏，右侧栏顶部「＋」→「本局」里的「舞台设置」。
2. 页面显示「这张卡还没有舞台设置」时，点「启用舞台（对话气泡）」。这张卡的「对话气泡」和「舞台模式」都变成「本卡开启」，聊天顶栏出现「舞台」按钮。带舞台的卡（卡 ZIP、`.dshcard`）导入时已经是本卡开启，不需要这一步。
3. 点「基础设置」标题旁的「设置向导」，三步：
   - 「挑选素材」：勾选已装素材包里的人物、背景、音乐等，点「创建本卡素材包」，选中的条目复制进一个只给这张卡用的本卡素材包。素材库是空的时，这一步有「下载官方精选素材」。
   - 「自定义角色」：点卡里识别出的角色名，选「已有人物」（用它的形象和声音），或在新人物页填名称与触发词后「生成形象」（应用内生图，按次付费）、「创建人物」。
   - 「开场画面」：给每条开场白选背景、时段、BGM 和登场人物，最后点「完成」。
4. 点聊天顶栏的「舞台」或按 F12 进入舞台，发一轮消息。正文写完后由导演安排背景、人物、BGM 和演出；开场白的画面来自开场画面，不经过导演。

没有绑定任何素材包的卡第一次进入舞台时，会自动打开设置向导（每张卡一次）。之后要再用，点「设置向导」按钮。

舞台设置一页从上到下是：基础设置 → 模组 → 素材包 → 人物 → 开场设置 → 提示词（后两项默认折叠）。

## 排查：开了却没有画面

按顺序查，前一项不成立就先解决它。

| 现象 | 查什么 | 怎么改 |
| --- | --- | --- |
| 聊天顶栏没有「舞台」按钮 | 这张卡的「对话气泡」是否生效 | 舞台设置 › 基础设置「对话气泡」选「本卡开启」 |
| 进了舞台只有文字框 | 「舞台模式」是否生效（它需要对话气泡） | 基础设置「舞台模式」选「本卡开启」 |
| 有背景没人物，或什么素材都没有 | 素材包对这张卡是否生效 | 舞台设置 ›「素材包」›「管理」，包要是「本卡」或「全局」；「关闭」的包导演看不到 |
| 某个人物不出场 | 人物灯和触发词 | 绿灯人物只在正文写到它的名字、别名或触发词（或智能判断认为相关）时提供给导演；要每轮可用就改蓝灯（stage-assets） |
| 一直没有演出或报错 | 导演模型 | 设置 ›「舞台」›「舞台模型」›「导演模型」，默认跟随前台；导演模型必须支持工具调用。本局设置里可以只给这一局换 |
| 刚发完消息画面没变 | 导演还在编排 | 等导演完成，舞台会接上 |
| 没有配音 | 语音服务 | 基础设置「配音 ›」行尾的 ⚠ 写明「配音插件未启用」或「没有可用的语音服务」；服务和密钥在「配音后端」里配，人物的声音在它的「声音」里选（stage-assets）。「配音」四态开关须生效；配音页设置「通用声音」和「旁白」，没有单独指定声音的角色使用通用声音，选「不配音」则不发声 |
| Live2D 人物显示成静态图 | 运行库 | 设置 ›「舞台」›「运行库」装 Cubism Core 和 pixi-live2d-display（见[常见任务](tasks.md)） |

BGM、音效、环境音、物品、演出组合都需要舞台模式生效；舞台模式没生效时这些行是灰的。入场演出不在这里，是每张卡的开场设置（默认无）。

## 代用户做

- 「启用舞台」和本卡开关只能由用户在界面里点，工具写不了。先读 `tavern_stage_read({request:{action:'card'}})`：`bindings.extension` 没有 `assetBindings` 时这张卡还没有舞台设置，请用户按第 2 步启用；`bindings.extension.stage.enabled` 为 `true` 表示对话气泡和舞台模式是本卡开启。
- 设置向导也只能在界面里操作。用户要你代劳时用工具做同样的事：复制条目到本卡用的包并绑定、新建人物和改触发词（stage-assets）、写开场画面（[开场画面](openings.md)）。
- 全局开关（例如让所有带舞台的卡默认开舞台）可以用工具写，写法见[开关与皮肤](settings.md)。
- 每一步写入后回读确认，最后请用户进舞台发一轮消息看效果；没看过游玩页时只说"已保存"。
