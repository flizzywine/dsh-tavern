# 常见任务

每项先给用户自己点的最短路线，再写你能用工具做什么（加载哪个 Skill）和常见坑。所有路线都假定这张卡已经开了舞台（[开舞台](quickstart.md)）。

## 给人物配立绘和声音

- 界面：舞台设置 ›「人物」点头像，打开这个人物的编辑页（形象、生图、声音）；「人物」末尾的虚线「＋」新建人物；也可以在「已有人物」里直接选一个。设置向导第 2 步是同一页。
- 工具：人物、服装与差分、应用内生图、声音和配音后端都用 stage-assets，按它的参考篇做。
- 常见坑：
  - 素材包是共享的：改一个包里的人物，所有用这个包的卡都会变。只想改这张卡，就改它的本卡素材包，或先复制包再改（stage-assets）。
  - 人物的「触发词」就是它的名字和别名：把正文里常用的叫法都加进去，例如「林澄」「小澄」。

## 换皮肤

- 界面：只换这张卡：进舞台后点控制栏的齿轮「设置」›「画面」›「本卡皮肤」，这个选择随卡导出。所有没指定皮肤的卡：舞台设置 › 舞台模式 › 皮肤「默认皮肤」。
- 工具：本卡皮肤写 `card` 补丁的 `defaultSkin`，默认皮肤写引擎的 `dialogueTheme`（全局，写前说明影响），见[开关与皮肤](settings.md)。可选：内置 `classic`（经典）、`crt`（显像管）、`aero`（千禧晴空），以及当前卡可用包里的皮肤条目；安装或修改皮肤条目用 stage-assets。
- 常见坑：包里的皮肤只有在包对这张卡生效（本卡或全局）时可用；不可用时先退回默认皮肤，再退回「经典」。整个酒馆界面的 .css 界面皮肤不是舞台皮肤，改它看 tavern-plugin 的 interface-skin 参考。

## 只给这张卡开一个模组或功能

- 界面：舞台设置 ›「模组」每一行右侧的开关标签，选「本卡开启」或「本卡关闭」；基础设置里的配音、BGM、音效、环境音、物品、演出组合用同样的标签。模组的安装和卸载在 设置 ›「舞台」›「舞台模组」。
- 工具：工具只能写基础设置的全局开关（引擎 `stageToggles`）；模组开关和本卡开关请用户在界面里选。模组的本卡设置值可以用 stage-mods 写。
- 常见坑：
  - 生效顺序是 本卡关闭 > 全局开启 > 本卡开启 > 全局关闭。在某张卡上选「全局开启 / 全局关闭」会清掉这张卡自己的选择，并改动所有卡。
  - 开关开着但本轮没有可用条目的功能不运行，也不给导演发它的说明（舞台上还留着它的状态时只保留维持或停止所需的一句）；物品要先在素材包里有条目。哪些模组需要素材条目、哪些开着就能用，见 stage-mods 里各模组的说明。
  - 模组的执行授权与开关无关，打开开关不会扩大权限。

## 导入 Live2D 模型

- 界面：设置 ›「舞台」›「运行库」先装运行库，再在人物编辑页的「模型」视图「导入模型」。
- 工具和常见坑：见 stage-assets 的 Live2D 与 Spine 参考。

## 带素材分享这张卡

- 界面：舞台设置 ›「素材包」›「导出」，勾选要带的包，再点「导出」得到卡 ZIP。
- 工具和常见坑：用 stage-sharing。

## 设置开场画面

- 界面：设置向导第 3 步，或舞台设置末尾折叠的「开场设置」。
- 工具：见[开场画面](openings.md)。登场人物为空就是空舞台，不会自动补主角。
