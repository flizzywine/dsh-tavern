# 常见任务

每项先给用户自己点的最短路线，再写你能用工具做什么（加载哪个 Skill）和常见坑。所有路线都假定这张卡已经开了舞台（[开舞台](quickstart.md)）。

## 给人物配立绘和声音

- 界面：舞台设置 ›「人物」点头像，打开这个人物的编辑页（形象、生图、声音）；「人物」末尾的虚线「＋」新建人物：填设定图、人物介绍、名称、触发词、身高和声音，点「生成形象」得到立绘和头像，再点「创建人物」；也可以在下面的「已有人物」里直接选一个。设置向导第 2 步是同一页。声音服务在基础设置「配音 ›」打开的声音设置里配。
- 工具：上传已有图片、新建人物、服装与差分用 figure-assets；应用内生图用 asset-generation（按次付费，候选只能由用户在界面里采用）；音色、参考音频和语音服务用 figure-voice。
- 常见坑：
  - 素材包是共享的：改一个包里的人物，所有用这个包的卡都会变。只想改这张卡，就改它的本卡素材包，或先复制包再改（asset-library）。
  - 触发词写 3 到 6 个正文里真会出现的短词：名字的短形式加这个人物独有的标志物，例如「林澄」「小澄」「蓝发卡」；不写长称号或「少女」「同学」这类大家共用的词。
  - 立绘要透明背景；生成的立绘带底色时重新生成。
  - 没有语音服务时人物不会说话；配好服务再给人物选音色。

## 换皮肤

- 界面：只换这张卡：进舞台后点控制栏的齿轮「设置」›「画面」›「本卡皮肤」，这个选择随卡导出。所有没指定皮肤的卡：舞台设置 › 基础设置「默认皮肤」。
- 工具：本卡皮肤写 `card` 补丁的 `defaultSkin`，默认皮肤写引擎的 `dialogueTheme`（全局，写前说明影响），见[开关与皮肤](settings.md)。可选：内置 `classic`（经典）、`crt`（显像管）、`aero`（千禧晴空），以及当前卡可用包里的皮肤条目。
- 常见坑：包里的皮肤只有在包对这张卡生效（本卡或全局）时可用；不可用时先退回默认皮肤，再退回「经典」。整个酒馆界面的 .css 界面皮肤不是舞台皮肤，改它看 tavern-plugin 的 interface-skin 参考。

## 只给这张卡开一个模组或功能

- 界面：舞台设置 ›「模组」每一行右侧的开关标签，选「本卡开启」或「本卡关闭」；基础设置里的配音、BGM、音效、环境音、物品、演出组合、入场演出用同样的标签。模组的安装和卸载在 设置 ›「舞台」›「舞台模组」。
- 工具：工具只能写基础设置的全局开关（引擎 `stageToggles`）；模组开关和本卡开关请用户在界面里选。模组的本卡设置值可以用 stage-mods 写。
- 常见坑：
  - 生效顺序是 本卡关闭 > 全局开启 > 本卡开启 > 全局关闭。在某张卡上选「全局开启 / 全局关闭」会清掉这张卡自己的选择，并改动所有卡。
  - 开关开着但本轮没有可用条目的功能不运行，也不给导演发说明；物品、计时器要先在素材包里有条目。手机、文字演出只用内置素材，开着就能用。
  - 模组的执行授权与开关无关，打开开关不会扩大权限。

## 导入 Live2D 模型

- 界面：先在 设置 ›「舞台」›「运行库」装 Live2D Cubism Core 和 `pixi-live2d-display`（点「下载并安装…」，同意许可后应用从官方下载；失败时可把官网下载的文件拖进来）。再打开人物编辑页，选中服装 › 切到「模型」视图 ›「导入模型」；或在包里「添加文件」→「导入模型…」新建人物。选模型文件夹或 ZIP，给每个差分选表情或动作。
- 工具：Live2D 模型目录可以用 figure-assets 上传并写进服装；Spine 只能在界面导入。
- 常见坑：只支持 Cubism 3 及以上的 `.model3.json`；没装运行库时舞台改用同服装的静态立绘，再退到头像；Cubism Core 适用 Live2D 专有软件许可，由用户自己下载。

## 带素材分享这张卡

- 界面：舞台设置 ›「素材包」›「导出」，勾选要带的包（本卡包默认勾上，全局包默认不勾），再点「导出」得到卡 ZIP。对方在人物卡库「导入人物卡」选这个 ZIP，看完预览点「导入」。
- 工具：card-sharing 的 `export-card` 和导入检查。
- 常见坑：这张卡用到的全局包默认不带，对方没有就看不到那些素材，需要时勾上；本卡的模组设置随卡带走，但导入不会授予模组执行权限；语音服务和密钥不随卡导出，对方要自己配。

## 设置开场画面

- 界面：设置向导第 3 步，或舞台设置末尾折叠的「开场设置」。
- 工具：见[开场画面](openings.md)。登场人物为空就是空舞台，不会自动补主角。
