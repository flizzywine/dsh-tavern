# 本机显示与阅读

这些是当前浏览器的本机偏好，不写入人物卡、存档或全局设置，工作台工具无法代为修改。回答时给出界面位置，说明需要用户自己操作；不要说"已经帮你设置好"。偏好按浏览器来源保存，换了端口或设备需要重新设置。

## 字体

每种文字独立选择，顺序是：本机选择 → 当前舞台主题或皮肤的默认 → 内置字体。

| 想改的文字 | 位置 |
| --- | --- |
| 舞台文本框、姓名牌、选项 | 舞台控制栏的齿轮「设置」›「文字」›「舞台字体」 |
| 电影模式字幕 | 同一页的「字幕字体」 |
| 普通聊天正文 | 设置 ›「外观」›「正文字体」（停用 Dream Skin 时这一行不显示） |

列表第一项"跟随样式/跟随皮肤"表示不再覆盖、恢复默认。列表只显示已安装的字体；工作台不能为用户安装或导入新字体。卡片内嵌页面（iframe）自带的排版不受这些选择影响。

## 阅读控制

| 操作 | 方式 |
| --- | --- |
| 进入/离开舞台 | F12 |
| 下一页 | 空格、回车、→、点击，或滚轮向下 |
| 上一页 | ←、PageUp、Backspace |
| 自动播放 | A；有配音的页等配音播完，无配音的页按设置的等待时间 |
| 跳过已读 | 按住 Ctrl，或点 SKIP；停在第一张未读页、已写末尾或正在生成的段落 |
| 履历（回看） | L，或滚轮向上 |
| 隐藏文本框 | H 或右键；隐藏时任何翻页输入都只会恢复文本框 |
| 重播本句配音 | V |
| 系统菜单 | Esc；菜单里的「快捷键」可再次查看全部按键 |

文字速度、自动阅读速度和等待时间在齿轮「设置」›「文字」；各类音量在「声音」；电影模式和特效画质在「画面」。

跳过时不补播一次性演出（文字演出卡片、物品展示等），已看过的演出也不会重播。用户反映"跳过后少了演出"属于正常行为。
