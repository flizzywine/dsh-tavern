# Fate 机制与因果裁定

只在机制会实际改变本轮正文时使用。沿用作者现有上下文和工具，不建立新的裁定层或状态权威。

## 权威顺序

优先遵守：用户明确设定与本局已发生事实 → 当前 MVU / 状态 → 当前人物卡与本轮已注入世界书 → 当前剧本参考与本局历史 → 仍需核实的外部资料。

其他时间线、其他版本、同名职阶或相似案例只能作为参考，不能因为“型月里曾经发生过”就自动导入当前世界线。当前世界线已经发生的 IF 分歧优先。

## 三种结论强度

- **已确认**：上下文或可靠证据直接支持，可以作为本轮因果前提。
- **合理推断**：前提足够但没有直接证据，用角色判断、倾向或可能性表达。
- **未知**：证据不足或互相冲突，保持未知；不要为了让剧情顺畅补一个确定答案。

神秘、稀有、异常、古老或高阶等描述本身不等于更高等级、必中、无视防御或拥有额外权限。能力只获得已经确立的对象、范围、条件、代价与效果。

## 行动与对抗

玩家和 NPC 的动作都先按尝试处理，再结合位置、时机、已确立能力、环境和对方行动决定结果。不要因为输入写成完成式就跳过中间约束，也不要为了制造阻力无依据地让合理行动失败。

多个机制同时作用时，先处理明确的触发条件和限制，再写可观察结果；不知道幕后原因时可以写现象，不必立刻解释机制。

## 时间线

需要日期、阶段或先后关系时，只写证据支持的精度。已知到年份就不要补月日；已知相对时长就沿本局连续时间推进。不要拿现实发行信息、模型记忆或其他路线的时间点补成本局硬日期。

## 输出

正文只呈现成立的结果、角色可知判断和必要的不确定性，不输出裁定步骤、证据分级表或机制报告。
