# 声音变体

用户要调某个人物的语速语调、开心或生气时换一种说法、改配音语言时读这篇。

## 能调什么

- **调音方案**（`variants`）：只调参数，按这份音色的来源 ID（`sources` 的键）分别写，例如来源有 `clone` 和 `online` 时写 `{"name":"轻快","tuning":{"clone":{"speed":1.15},"online":{"rate":15,"pitch":5}}}`；写了音色里没有的来源会报 `Unknown source`。参数名随服务：Fish 没有音高参数；Azure 的 rate/pitch 是百分比。方案里不能放声音编号、模型、参考音频或密钥。
- **差分对应**（绑定的 `emotionVariants`）：差分 ID → 方案 ID，没列出的差分用默认方案。
- **配音语言**（绑定的 `language`）：省略时用音色语言，都没有就是中文。正文固定用中文写；配音语言不是中文时，这个角色的对白会另带一份该语言的配音台词。
- 浏览器朗读不吃调音方案，只能调全局的「配音倍速」（见[给人物配声音](figure-voice.md)）。

界面：人物「声音」页的「调音」和「配音语言」。

## 工具

先 `tavern_voice_read figure {packId, figureId}` 读出当前绑定、音色和它的方案（找人物见[人物](figures.md)）。

- 改人物的绑定（用哪个方案、语言、差分对应）：`binding`，整份绑定写回，未改的字段带上原值。
- 改音色本身（增改调音方案）：`pack-voice {voiceId, voiceSpec, figureId?}`。音色被别的人物共用时，宿主会提示影响；用户只想改这一个人物时，先给它一份独立音色（`assign-figure`）。

## 例子

用户："大肥鱼的声音太慢了，开心的时候再快一点。"
→ 找到大肥鱼的 `packId` 和 `figureId` → `figure` 读绑定与音色 → 音色若被别的人物共用，先告诉用户并确认是否只改大肥鱼 → 调高默认方案的语速，再加一个更快的 `quick` 方案，`emotionVariants` 只把用户说的「开心」差分指向它 → 回读 `effective` 和 `issues` → 请用户在「声音」页试听。

差分到方案的对应只按用户指定写，不自己推测哪种情绪该用哪个方案。

## 完成标准

`figure` 回读的 `effective` 显示新方案和语言、`issues` 为空；用户试听或在下一句台词里听到变化。
