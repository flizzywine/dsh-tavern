# 从零开始配音

用户第一次想让角色说话、问「配音怎么开」「要不要买密钥」时读这篇。已经配过但听不到声音，读[没有声音时按顺序检查](voice-troubleshooting.md)。

## 先说清楚的三件事

- **不需要密钥也能出声。** 浏览器朗读用电脑自带的系统声音，免费。没单独配声音的角色（包括临时 NPC）默认用「通用声音」，它的默认值就是浏览器的系统默认声音。想要更好的音色时再配云服务。
- **不需要舞台模式，也不需要立绘。** 配音在对话气泡里播放，只要这张卡开了对话气泡；人物有没有图都不影响配音。
- **聊天里的整篇「朗读」是另一套。** 酒馆设置 › 酒馆插件 里的朗读声音和自动朗读只读普通聊天正文，不用舞台的声音设置。

## 最短路线

1. **开对话气泡**：舞台设置 › 基础设置「对话气泡」为「本卡开启」（还没有舞台设置的卡，页面显示「这张卡还没有舞台设置」，点「使用舞台」）。
2. **配音开关**：同一页「配音」默认是全局开启，没被改成「本卡关闭」就不用动。「配音后端」页标题旁的「启用配音」默认开着。
3. **让卡上至少一个人物有声音**：素材库里打开一个人物的「声音」，在「配音来源」里选「浏览器朗读」（马上能用，免费）。目前卡上要至少有一个人物绑定了声音，其余角色的通用声音才会出声；整张卡都没有绑定声音的人物时，所有台词都不配音（已知问题，修复中）。没有人物的卡可以按[人物](figures.md)建一个只有名字的人物再给它配声音。
4. **（可选）换更好的音色**：在「配音后端」添加语音服务并填密钥（[配音后端](voice-backend.md)），再给人物选声音（[给人物配声音](figure-voice.md)），或在 舞台设置 › 基础设置「配音 ›」里把「通用声音」换成服务里的声音。
5. **听一次**：进舞台发一轮消息，台词出现时自动配音；或在素材库人物的「声音」页点「试听」。

## 代用户做

开关和通用声音只能由用户在界面里改，工具能读开关、改人物的声音：

- 读开关：`tavern_stage_read({request:{action:'card'}})`，`bindings.effectiveStage` 里 `dialogue` 和 `voice` 都为 `true` 才会配音；`bindings.extension` 没有 `assetBindings` 时这张卡还没有舞台设置，请用户按第 1 步启用。
- 给人物配浏览器朗读：按[给人物配声音](figure-voice.md)用 `assign-figure` 写一份不带 `voiceName` 的浏览器音色。
- 通用声音、旁白的当前值工具读不到，需要时请用户看 舞台设置 › 基础设置「配音 ›」。

## 通用声音与旁白

舞台设置 › 基础设置「配音 ›」打开配音页：

- 「通用声音」：所有卡共用。没有单独指定声音的角色都用它；选项开头是「浏览器 · 系统默认」和「不配音」。
- 「旁白配音」：读气泡外的叙述，四态开关，默认全局关闭；开启后出现「旁白声音」，默认「同通用声音」，打开「本卡单独指定」才只改这张卡。
- 「配音倍速」在舞台齿轮「设置」›「声音」›「配音」组（0.8–2.0 倍），配音音量也在「声音」里，调到 0 就听不到。

## 完成标准

用户在游玩页听到台词配音，或在人物「声音」页试听成功。只完成保存时，报告「已保存，请进舞台发一轮或在声音页试听」。
