# 编写场景写作 Skill

把用户引用的写作教导整理成前台 Agent 按场景加载的独立 Skill。成品是一段自包含的场景提示词：前台先看简介判断场景是否适用，再加载完整正文照着写。

## 依据

- 新建时，根据用户明确引用的教学材料提炼方法。还没引用时，请用户在「剧本库」中引用。
- 修改已有用户 Skill 时，先用 `tavern_read_skill` 读取当前正文和参考文件。用户没有给出名称时，先列出候选 Skill，再根据请求定位。按用户提出的改动和新增材料调整。

材料缺少适用边界、前后矛盾，或存在影响取舍的用户偏好时，就这些具体点询问用户。

## 写法

- **简介**：可识别的场景触发条件（例如「战斗场面」「初次见面的对话」），加上容易误触发时的排除条件。
- **正文**：适用场景、不适用场景、写作方法、必要的正反例。方法写成前台能直接执行的描写要求，点名要避免的具体写法。
- **不拆参考文件**，也不要求前台读原素材；删掉素材后 Skill 仍然完整。
- Skill 只管表达方式。人物卡事实、玩家选择、工具权限仍按原有规则，正文里不要改动这些。

## 保存

用 `tavern_save_skill` 提交完整 `body`。

- 新建时传 `purpose: "writing"` 和 `references: []`，默认允许模型自动调用，分配给前台 Agent。
- 修改时传 `overwrite: true`。沿用参考文件时省略 `references`，沿用分配和调用配置时省略对应字段。

保存后简短告知名称、适用边界和用途。用户可以在 Skill 库查看、调整或删除它，并在本局设置里开关写作 Skill。
