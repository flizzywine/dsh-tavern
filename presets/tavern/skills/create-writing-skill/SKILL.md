# 编写场景写作 Skill

把用户引用的写作教导整理成前台 Agent 按场景加载的独立 Skill。成品是一段自包含的场景提示词：前台先看简介判断场景是否适用，再加载完整正文照着写。

## 依据

只用用户明确引用的材料。还没引用时，请用户在「剧本与素材库」中引用；导入本身只负责存储。方法必须来自材料，不自行编写教学内容。材料缺少适用边界、前后矛盾，或存在影响取舍的用户偏好时，就这些具体点询问用户；材料已经说清楚的不重复问。

## 写法

- **简介**：可识别的场景触发条件（例如「战斗场面」「初次见面的对话」），加上容易误触发时的排除条件。
- **正文**：适用场景、不适用场景、写作方法、必要的正反例。方法写成前台能直接执行的描写要求，点名要避免的具体写法。
- **不拆参考文件**，也不要求前台读原素材；删掉素材后 Skill 仍然完整。
- Skill 只管表达方式。人物卡事实、玩家选择、工具权限仍按原有规则，正文里不要改动这些。

## 保存

`tavern_save_skill`，`purpose: "writing"`，`references: []`，提交完整 `body`，默认允许模型自动调用、分配给前台 Agent（用户另有要求时再改）。修改已有写作 Skill 时，先读出它的旧参考文件，把仍有用的方法并入正文，再用空数组清掉旧参考。

保存后简短告知名称、适用边界和用途。用户可以在 Skill 库查看、调整或删除它，并在本局设置里开关写作 Skill。
