# Tavern 高级扩展

说明用户扩展放在哪里、怎样持久加载。

媒体生成、正文标记和插件按钮使用 `tavern-plugin` Skill 的公开接口；本 Skill 负责通用工具与持久加载。

## 位置

系统提示给出的资源根目录以 `resources` 结尾，它的父目录是持久数据目录：

- 自创工具和插件代码放在同级 `tools/`；
- Cordis 持久加载清单是同级 `tools.cordis.yml`；
- Skill 在同级 `skills/`，用 `tavern_save_skill` 保存，不手写目录。

这些目录不在程序安装目录里，更新不会覆盖。程序源码、内置 preset 和内置 Skill 目录属于程序自身，不在里面放用户扩展。用文件工具时从系统给出的资源根目录推出绝对路径，不猜主目录或安装位置。

## 临时与持久

- 动态加载 Cordis 插件适合临时检查或扩展当前 Runtime，进程重启后消失。
- 要在重启后保留：代码和依赖放进 `tools/`，在 `tools.cordis.yml` 追加加载条目（唯一 `id`、相对于清单的模块 `name`、`config`）。先读现有清单，只增改目标条目，保留其他条目。

## 完成标准

- 写入后检查路径、文件格式、模块入口和清单引用。
- 只有实际加载或调用成功，才能说当前 Runtime 可用。
- 只有 DSH 重启后在新工作台里看到并调用了工具，才能说已持久加载；只写了文件时，说「已保存，需重启验证」。
- 历史里的临时工具没有源码可恢复时，不声称已恢复。

报告保存位置、当前 Runtime 是否可用、重启后是否已验证。
