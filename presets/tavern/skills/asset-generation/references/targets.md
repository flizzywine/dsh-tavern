# 生成目标

目标字段以 `prepare` 的 schema 和报错为准。

| 目标 `kind` | 需要的字段 | 生成什么 |
| --- | --- | --- |
| `identity-settei` | `packId`、`figureId` | 人物设定图（长相母版）：脸、发型、体型和标志性配饰，所有服装共用 |
| `settei` | 再加 `outfitKey` | 这套服装的设定图 |
| `sprite` | 再加 `outfitKey`、`emotionId` | 某个差分的全身立绘（透明背景） |
| `avatar` | 再加 `outfitKey`、`emotionId` | 某个差分的头像 |
| `avatar-sheet` | `outfitKey`，可选 `emotionIds` | 一张 4×2 的八头像表，切成八个差分头像 |
| `background` | `packId`，可选 `assetId` | 背景；不给 `assetId` 时在采用时新建背景条目，给了则替换该背景的图 |

## 先后与参考

- 已采用的人物设定图、服装设定图和平和差分的图存在时，会自动作为参考，画出来更一致；没有也能生成，但一致性更难保证。建议顺序：人物设定图 → 服装设定图 → 首个差分立绘 → 其他差分 → 头像。
- 单个头像需要同一差分已有立绘；八头像表需要首个差分立绘或服装设定图。缺前置时 `prepare` 会报错，按报错先做前置的那一张。
- 生图会用到人物的外貌描述和服装描述；缺少时先用 figure-assets 补上（外貌只写长相，不写年龄和身体数字）。
- 用户额外参考最多 4 张：同包已入库的图（hash）或工作台里的图片文件，各自写明用途，例如"参考姿势"。
- 八头像表的八个差分要先在人物和服装里存在；用户要的差分还没有时，先用 figure-assets 声明，再生成。

## 张数与质量

`count` 为 1–4，默认 1；N 张就是 N 次单图请求，各自计费。单个头像固定高质量。

## 重画

用户对某张候选有具体意见时，用 `redrawOf`（原任务）和 `note`（这次的修改意见）重新准备；新意见替换上一次的意见，不叠加。`useCandidateReference:true` 会把原候选也作为参考（它不是权威设定）。重画是新的付费请求，同样要说明并确认。原候选保留到新候选保存成功，期间用户仍可采用原候选。

## 候选的检查提示

候选附带自动检查：缺少透明背景、空图、分辨率低、比例不符、人物碰到边缘等。这些只是提示，不代表画得好坏；把提示转告用户，由用户在界面里看图决定。立绘和头像没有透明背景时无法采用。

## 例子

用户："给大肥鱼的女仆装做一张开心的立绘。"
→ 用 `item {kind:'figures'}` 找到大肥鱼，带 `id` 读取女仆装和"开心"差分的 ID（没有该差分先声明）→ `prepare {target:{packId, kind:'sprite', figureId, outfitKey:'default', emotionId}, expectedRevision}` → 告诉用户"将发出 1 次单图请求，参考：人物设定图、女仆装设定图；外层模型可能另收文字费用，失败也不保证免费" → `generate`（宿主确认）→ `status` → 候选出来后告诉用户去素材库 › 大肥鱼 ›「生图」页采用。
