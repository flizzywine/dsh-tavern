# 舞台模组

模组是安装好的第一方扩展，由导演通过结构化命令触发演出，例如手机短信、文字演出卡片、计时器。物品已是舞台内置功能，在 舞台设置 › 基础设置「物品 ›」，不再是模组。工具：`tavern_mods_read`、`tavern_mods_patch`，上传模组文件和媒体用 `tavern_media_upload`。先用 `tavern_mods_read({request:{action:'list'}})` 看已安装哪些模组、各自的开关和授权状态。读取失败时，先告诉用户读取没有成功及错误给出的原因，再说"下面只是功能介绍，还没核实本机是否安装、是否授权、这张卡有没有可用素材"。开关和授权状态说明的是配置，模组是否演出要看导演在游玩中的实际触发。

## 调用格式

每个工具只有一个 `request` 参数。几个动作共用的字段放在外层，`action` 和这个动作其余的字段放进 `operation`，层级以工具 schema 为准；下文的 `动作 {字段}` 只列出字段。例如写本卡层设置值：

`tavern_mods_patch({request:{modId:'dsh.phone', expectedRevision:'读到的 revision', operation:{action:'config', key:'…', layer:'card', value:{…}}}})`

## 开关、授权和素材是三件事

- **开关**：四态，全局开启 / 全局关闭 / 本卡开启 / 本卡关闭，按「本卡关闭 > 全局开启 > 本卡开启 > 全局关闭」生效。开关由用户在界面里选，工具只读取状态。
- **授权**：模组的执行许可，与开关独立；开关打开不会扩大权限。授权也由用户在界面里处理。
- **素材**：计时器这类模组用素材包里的条目，和其他素材一样有包的范围和条目的蓝绿灯；一轮里没有可用条目时，那一轮不运行，也不占用导演提示词。手机和文字演出只用模组内置素材，开关生效就可用。

界面位置：舞台设置 ›「模组」里每个模组一行，右侧的开关标签展开四个选项；在卡上选「全局…」会清掉这张卡的选择并改所有卡。点行或「›」打开模组设置页，页顶「全局 | 本卡」决定设置值写在哪一层。模组的安装和卸载在 设置 ›「舞台」›「舞台模组」。

模组素材包的范围也在界面里选：把一个模组素材包只给当前卡用，请用户在模组设置页的「素材包」里把它设为「本卡」。除了本卡层的设置值，模组的写入（模组设置、模组包、全局设置值、模组媒体）都按全局写入处理：先告诉用户"这是全局设置，会影响所有卡片"和具体变化，写工具调用时宿主请用户确认。

## "只给这张卡开"

请用户在这张卡的 舞台设置 ›「模组」里把该模组选成「本卡开启」，全局保持关闭，其他卡就不会用它；反过来「本卡关闭」让全局开着的模组在这张卡上停用。这是界面操作，工具写不了，告诉用户位置即可。

- 打开后是否出现仍由导演按剧情决定；有素材条目的模组还要这张卡能用到条目（包的范围、条目灯态，见 stage-assets）。
- 可以用本卡层的设置值调这张卡的外观或强度（下文「设置值」）。

## 设置值

用 `tavern_mods_read config {modId}` 读取该模组的设置字段、全局与本卡两层的值和最终解析结果，按 [设置值与变量来源](references/mod-config.md) 写入。本卡层只放数据和展示配置，不能当作本卡开关。写入用读取到的 revision；冲突时重新读取，只重做本次修改。

各模组的特点（物品分类、手机外观、文字演出强度等）见 [第一方模组](references/first-party.md)。数据删除（`dsh.redaction`：导演把正文里的机密词盖住，玩家点三下揭开）见 [数据删除](references/redaction.md)。

## 不制造状态

物品数量、手机电量等如果要跟随剧情变化，需要卡里真的有对应的状态：MVU 变量或台账。没有时不要写固定值冒充"库存"，也不要在正文、世界书或开场白里加入模组专用的格式说明，演出只由导演触发。卡还没有 MVU 而用户需要库存时，先加载 card-to-mvu 加入变量，再回来把设置引用到变量。

模组不提供运行时命令、改写历史或往正文里插入手机消息的工具。演出由导演按剧情决定；改设置只影响之后的轮次，已经播过的演出不会重播。

## 用工具完成，按事实报告

- 模组只通过本 Skill 的工具读写。报错里的 `example` 是最小合法骨架：占位符换成读到的值，空数组只表示类型、不代表清空。工具做不到的事，说明缺什么或界面位置。
- 报告只描述工具结果里出现的事，分清：计划（还没调用写工具）、已问你（等你回复）、等待宿主批准、未获批准没有改动（照审批错误的 `message` 转述，会话策略自动拒绝不说成用户拒绝）、已保存（回执成功且回读到目标值）。

## 完成标准

写入回执 `saved`；再读 `config` 时目标字段的解析结果（`resolved`）没有错误，引用或公式算出了预期的值。模组设置和模组包改动用 `mod` 或 `packs` 回读。交付时说明哪些效果需要等导演在下一轮按剧情触发，不能立即在页面上看到。
