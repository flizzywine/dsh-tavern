# 设置值与变量来源

## 值的四种形状

| 形状 | 含义 | 例子 |
| --- | --- | --- |
| `{auto:true}` | 自动：按字段提供的自动来源（猜测 MVU/台账变量、舞台值如主角形象色），未命中用字段默认值 | 手机强调色跟随主角形象色 |
| `{fixed: 值}` | 固定值，类型必须与字段一致 | 电量固定 `80` |
| `{ref:{source, path, fields?}}` | 引用变量；`path` 是 JSON Pointer，MVU 相对 `stat_data` | 背包引用 `/背包`，并映射名称和数量字段 |
| `{formula:"表达式"}` | 公式，仅数字字段等支持 | 由多个变量算出的数值 |

一个值只能是其中一种。只有声明了自动来源的字段才适合写 `auto`；没有自动来源的字段写 `fixed`、`ref` 或 `formula`，不设置时用默认值。

## 两层

- `layer:'global'` 对所有卡生效，写入需要全局确认。
- `layer:'card'` 只对当前卡，保存在卡的素材里，随卡导出。字段声明为只允许全局时不能写本卡层。
- 某层没有设置就继承上一层；`clear-config` 删除当前层的值，恢复继承。

## 写之前先验证

- `tavern_mods_read sources` 列出当前卡可用的状态来源及不可用原因。
- `formula {formula}` 试算公式，返回结果或出错位置，不会写任何变量。
- `resolve {modId, key}` 查看单个字段最终取到的值、来自哪一层、是哪种形状。

引用路径或公式出错时，解析结果会带错误，不会悄悄改用其他来源；按错误位置修正，或改回固定值。

## 状态来源

全局设置 `dsh.state.source` 决定物品、手机和导演读取哪种状态：`auto`（卡有 MVU 就用 MVU）、`mvu`、`ledger`（台账）。明确选择后不会自动退到另一种。台账没有数据时是"不可用"，不是空背包。改这项会影响所有卡，按全局写入处理。

## 例子

用户："手机电量跟着变量'手机.电量'走。"
→ `sources` 确认这张卡的 MVU 可用 → `formula` 或 `resolve` 试读 `/手机/电量` → 用 `config` 在本卡层写 `{ref:{source:'mvu', path:'/手机/电量'}}` → 回读 `resolved` 的值和来源。如果变量还不存在，先用 card-to-mvu 加变量。
