# 数据删除 `dsh.redaction`

导演把正文里的机密词盖住：黑条（默认）或乱码。玩家在舞台文本框或履历里点三下揭开；揭开的词在这一局里一直是揭开的，换设备、刷新都还在，重新生成的那一轮重新盖上。存档、编辑和下一轮发给模型的上下文里都是原文，只在显示时盖住；配音播到被盖住的词时压低人声、换成杂音，揭开后重播才念出来。

- 不需要素材条目，开关生效就可用。适合机构、档案、调查类的卡，一般只给这张卡开（「本卡开启」）。
- 设置（全局或本卡都可以设）：
  - `kind` 默认样式：`bar` 黑条（默认）、`glitch` 乱码。导演可以对某一处另选样式。
  - `guidance` 遮挡指引：写给导演看，这张卡里什么该盖，例如「异常的真名、伤亡人数、机构内部代号」。留空时导演只盖故事本身对玩家保密的内容。正文模型看不到这段，也不知道有这个模组。
- 导演每轮按正文来标：词要和那一段原文一字不差，标错了提交工具会退回去改。导演标到之前，那几页先照常显示，标到了再盖上。
- 只在舞台上盖：聊天楼层里仍显示原文。

例子：一张调查机构题材的卡把遮挡指引写成「异常的真名与能力细节、伤亡人数、机构内部代号与楼层」，默认样式黑条。
