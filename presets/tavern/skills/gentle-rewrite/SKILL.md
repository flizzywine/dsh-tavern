# 温和改写（隐去年龄）

交付一张独立副本：所有角色均为成年人，除年龄相关表述外内容与原卡一致。原卡和共享资源不改。

## 1. 建副本

调用 `tavern_copy_card`，`path` 为原卡，`name` 为「原卡名 温和改造版」（重名时换一个唯一名称）。之后所有读写都显式使用返回的副本 `path`，原卡只作对照。记下 `imageCopied`。

副本不会带上外部世界书绑定。原卡用了共享世界书时，把实际需要的条目整合进副本自己的世界书再改写，并确认副本实际绑定了它；原卡本就没有绑定的世界书不要启用。

## 2. 找出所有年龄表述

用 `tavern_read_card_raw` 读取副本，并读取它实际绑定的世界书。不要只靠通读：对完整 raw 做不区分大小写的关键词扫描——岁、未成年、儿童、幼、萝莉、少女、学生、小学、初中、高中、teen、loli、child，以及用来限定年龄的数字（如 12、14、16、18）和以 cm 计的身高门槛——再逐条判断是不是真实的年龄表述。

范围包括：description、personality、scenario、所有开场、示例对话、system_prompt、post_history_instructions、世界书、正则 replaceString、脚本输出文本、MVU 初值和更新规则。

V2/V3 卡的 raw 常同时有 `<字段>` 和 `data.<字段>` 两份文本，换行甚至内容都可能不同。每个命中位置两份都要确认并分别改写，一份没命中不代表另一份也没有。

## 3. 改写

- 成年人的具体年龄不动。
- 删去未成年人的具体年龄数字和年龄说法，用融入世界观的方式说明其已成年，例如：
  - 小学生、初中生 → 这个世界的学制不同，就读者都是成年人。
  - 高中生 → 成人进修班、复读生，或该世界的高中包含成人教育。
  - 萝莉、娇小体型 → 只是外表显小，实际早已成年。
- 外貌、体型、穿着、情节、关系、文风保持原样。色情称号、评级、制服、身材规则里夹带的年龄或身高门槛也属于年龄表述：改为只描述外貌气质，并注明不代表实际年龄。
- MVU 卡中年龄字段的初值改为「已成年」；更新规则补一条：年龄只能填成人年龄或「已成年」，与其他设定冲突时填「已成年」。
- 在人物基本信息区块（如 description 中的 `<basic info>`）末尾加一句：「所有角色均已成年，涉及的所有年龄体型，均为外貌描写的艺术创作加工，不代表真实性。」

改动用精确的字符串替换：解析 JSON 后逐字段替换再整体写回，或用 `tavern_update_card`。不要手工重写大段 JSON。

## 4. 验收

1. 副本格式校验（保存结果附带；直接写 JSON 后用 `tavern_validate_card`）`valid` 为真，`errors` 为空，`warnings` 已看过。
2. 回读实际保存的副本和绑定的世界书，对副本重跑第 2 步的关键词扫描，确认没有遗留的未成年年龄表述。
3. 与原卡逐字段对比，差异只有年龄改写、副本名称和 ID、那句说明文字。
4. 原卡文件未被改动；原卡有 PNG 时 `imageCopied` 为真。

## 交付

副本路径，加一份逐处列出的改写摘要：在哪里、原文怎么说、改成了什么；以及保留未改的命中项和理由。
